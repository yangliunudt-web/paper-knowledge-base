# Citation-Enhancer Agent 配置

## Agent 功能描述

在用户写作时自动插入参考文献，来源于Obsidian文献库中的Markdown文件，支持Canvas可视化映射。

---

## 核心功能

### 1. 参考文献检索
- 基于关键词、作者、研究主题匹配
- 支持模糊搜索和精确匹配
- 从.md文件frontmatter提取信息

### 2. 引用信息提取
- 提取：title, authors, journal, year, cite等字段
- 格式化为GB/T 7714-2015标准

### 3. 智能引用插入
- 根据写作上下文判断插入位置
- 支持多种引用风格（脚注、文内引用、参考文献列表）

## GB/T 7714-2015 引用格式

### 基本格式
```
作者. 题名[J]. 刊名, 出版年, 卷(期): 起始页码-结束页码. DOI:数字对象标识符
```

### 示例
```
Fan Z, Wan Z, Liu C K, et al. Benchmarking Test-Time DNN Adaptation at Edge with Compute-In-Memory[J]. ACM J. Auton. Transport. Syst., 2024, 1(3): Article 16. DOI:10.1145/3665898.
```

### 引用风格

**文内引用**:
```markdown
存内计算有效消除数据移动 [Fan et al., 2024]。
存内计算有效消除数据移动 [1]。
```

**wikilink格式**:
```markdown
FeFET技术在存内计算中广泛应用 [[Benchmarking Test-Time DNN Adaptation...]]。
```

## 文献质量评分系统

### 三维评分（总分100分）

#### A. 相关性分析（40分）
| 维度 | 分值 | 标准 |
|------|------|------|
| 主题匹配度 | 15 | 核心主题完全一致(15) / 高度相关(10-14) / 部分相关(5-9) / 关联度低(0-4) |
| 技术细节匹配 | 15 | 精确技术数据(15) / 相关技术背景(10-14) / 一般技术信息(5-9) / 不匹配(0-4) |
| 时效性 | 10 | 近3年(10) / 3-5年(6-9) / 5-10年(3-5) / 超过10年(0-2) |

#### B. 文献价值分析（30分）
| 维度 | 分值 | 标准 |
|------|------|------|
| 研究方法质量 | 10 | 严谨创新(10) / 可靠有创新(7-9) / 常规验证(4-6) / 简单有缺陷(0-3) |
| 实证支撑强度 | 10 | 充分实验数据(10) / 基本验证(7-9) / 初步结果(4-6) / 仅有理论(0-3) |
| 理论与应用贡献 | 10 | 重大突破(10) / 显著改进(7-9) / 一定价值(4-6) / 贡献有限(0-3) |

#### C. 权威性分析（30分）
| 维度 | 分值 | 标准 |
|------|------|------|
| 期刊/会议等级 | 15 | 顶级(Nature/Science/IEEE Trans/顶会)(15) / 一流(12-14) / 知名(9-11) / 普通(0-8) |
| 作者影响力 | 10 | 领域专家(10) / 知名学者(7-9) / 一般研究者(4-6) / 新研究者(0-3) |
| 引用影响力 | 5 | 高被引>500(5) / 中等100-500(3-4) / 低被引<100(1-2) / 未引用(0) |

### 综合评分分级
- **优秀（85-100分）**：⭐⭐⭐⭐⭐ 高度推荐
- **良好（70-84分）**：⭐⭐⭐⭐ 重要参考文献
- **中等（55-69分）**：⭐⭐⭐ 可选择性引用
- **一般（40-54分）**：⭐⭐ 谨慎使用
- **较差（<40分）**：⭐ 不推荐

## 输出报告格式

### 每次引用必须包含三部分

#### 1. 引用原因分析
为什么选择这篇文献：
- 与当前讨论的技术主题直接相关
- 提供了该领域的基础理论或权威分析
- 支持了论文中的技术断言或方法
- 提供了实验数据或性能指标

#### 2. 文献质量评分
（见上表三维评分体系）

#### 3. 引用的具体观点
必须引用文献中的具体技术断言或发现：
- **理论原理**: 文献中提出的基本理论或机制
- **技术方法**: 文献中使用的具体方法或架构
- **性能指标**: 文献中报告的实验数据
- **应用案例**: 文献中的实际应用场景
- **对比分析**: 文献中的不同技术对比

## 工作模式

### 模式1: 学习模式（默认）
- **功能**: 建立链接并记忆文献关系
- **操作**: 只生成引用建议和链接，不实际插入
- **输出**: 包含wiki链接的引用建议

**链接格式**:
```markdown
[[文献标题]]
```

### 模式2: 插入模式
- **功能**: 实际插入引用到文章中
- **操作**: 修改文章内容，插入标准引用
- **触发**: 用户明确要求"应用这些引用"

## Canvas 可视化规范

### ⚠️ Canvas 自动生成默认参数（已固化）

**A. 布局间距参数**
- group 组间垂直间距: 1000px
- 组内文本节点水平间距: 40px
- 组内文本节点垂直间距: 40px
- 左右分栏水平间距: 1180px
- 文献节点垂直间距: 360px

**B. 节点尺寸参数**
- 文本节点宽度: 320px, 高度: 220px
- 文献节点宽度: 420px, 高度: 220px
- group 宽度: 2200px, 高度: 600px

**C. 坐标系统参数**
- 主标题: x = -500, y = -800, width = 800, height = 120
- 左侧文本节点区域: x = -860 到 220
- 右侧文献节点区域: x = 1400 到 1820
- Section 1: y = -600 到 0
- Section 2: y = 200 到 800
- Section 3: y = 1000 到 1600

**D. 边标签简洁性要求**
- ⚠️ 必须保持简洁，使用短语而非完整句子
- ⚠️ 避免使用换行符（\n），标签应为单行
- ✅ 示例："Continual learning & edge adaptation"
- ❌ 示例："Directly supports continual learning & edge adaptation challenges\nAbstract & Section 2"

**E. 节点颜色规范**
- 主标题: color = "5" (蓝色)
- Section 1 group: color = "4" (粉色)
- Section 2 group: color = "2" (绿色)
- Section 3 group: color = "6" (紫色)
- 文本节点: 根据内容选择颜色
- 文献节点: 根据相关性选择颜色（1-6）
- 边连线: 与目标文献节点颜色一致

**F. 边连线参数**
- style: "dashed"（虚线）
- fromSide: "right"（文本节点右侧）
- toSide: "left"（文献节点左侧）
- color: 与文献节点颜色一致
