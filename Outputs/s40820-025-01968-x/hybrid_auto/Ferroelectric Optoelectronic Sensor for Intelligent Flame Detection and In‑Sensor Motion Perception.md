ABSTRACT Next-generation fre safety systems demand precise detection and motion recognition of fames. In-sensor computing, which integrates sensing, memory, and processing capabilities, has emerged as a key technology in fame detection. However, the implementation of hardware-level functional demonstrations based on artifcial vision systems in the solar-blind ultraviolet (UV) band (200– 280 nm) is hindered by the weak detection capability. Here, we propose $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } / \mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ heterojunctions for the ferroelectric (abbreviation: Fe) optoelectronic sensor (abbreviation: OES) array (5 × 5 pixels), which is capable of ultraweak UV light detection with an ultrahigh detectivity through ferroelectric regulation and features in confgurable multimode

functionality. The Fe-OES array can directly sense diferent fame motions and simulate the non-spiking gradient neurons of insect visual system. Using this Fe-OES system and neuromorphic hardware, we successfully demonstrate three fame processing tasks: achieving efcient fame detection across all time periods with terminal and cloud-based alarms; fame motion recognition with a lightweight convolutional neural network achieving 96.47% accuracy; and fame light recognition with 90.51% accuracy by means of a photosensitive artifcial neural system. This work provides efective tools and approaches for addressing a variety of complex fame detection tasks.

# 1 Introduction

Fire accidents cause signifcant loss of life and property globally each year [1, 2]. Traditional fame detection systems, which rely on smoke and infrared heat sensors activated by combustion, are limited to issuing basic fame alarms or capturing spatial frames [3, 4]. These limitations make it challenging to accurately assess the intensity and spread of the fre [5, 6]. It is noted that the solar-blind UV (SBUV, 200–280 nm) rays can emit rapidly within 3 to 4 ms during material combustion, which stimulates the further research to explore the ultraviolet fame detectors with high sensitivity and fast response. To enhance fre prevention capabilities, the development of an advanced vision system is critically need, which integrates real-time monitoring of SBUV components with spatial and temporal analysis algorithms to enable early-stage fame detection and dynamic fre behavior assessment [7, 8]. Vision systems for motion recognition often employ various artifcial neural network algorithms, such as convolutional neural networks (CNN) [9–11] and spiking neural networks (SNN) [12–14], to reduce the transmission of large volumes of visual data while achieving spatiotemporal integration within computational units [15–17]. Consequently, systems that integrate sensors and external circuits to generate, collect, and process fame data present a viable approach [18, 19], signifcantly improving data processing efciency and minimizing redundant transmission [20–23]. The detection with artifcial vision systems in visible to infrared light regions has been extensively investigated, while SBUV-based artifcial vision for weak-light detection remain underdeveloped with limited hardware-level demonstrations, presenting a critical gap in fame detection technology.

As a representative SBUV detection material, ultra-wide bandgap ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ shows strong recognition and anti-interference capabilities for fame detection and missile warning [24, 25]. Nevertheless, the insufciency of weak-light detection $( \mathrm { n W ~ c m } ^ { - 2 } )$ in ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ -based detectors still hinders their commercialization [26]. Ferroelectric polarization engineering can break this dilemma via voltage-driven spontaneous polarization alignment. It is worth noting that the ferroelectric negative capacitance efect can be generated when ferroelectric material is used as gate medium of feld-efect transistor (FET). In this case, the ferroelectric polarization feld enables the suppression of dark current

and enhancement of photodetection capability, which fnally optimize the detectivity under weak illumination conditions [27]. This improvement has been widely observed in two-dimensional (2D) devices, such as ${ \mathrm { H Z O - g a t e d - M o S } } _ { 2 }$ phototransistor [27] and P(VDF-TrFE)-gated-MoTe p–n junction [28]. As a 2D van der Waals ferroelectric semiconductor, $\mathsf { { a } } \mathrm { { - } } \operatorname { I n } _ { 2 } \mathsf { S } \mathsf { e } _ { 3 }$ exhibits in-plane and out-of-plane ferroelectricity at room temperature, along with excellent ferroelectric control [29–33]. By applying a scanning voltage, the ferroelectric polarization in $\mathsf { { a } } \mathrm { - I n } _ { 2 } \mathsf { S } \mathsf { e } _ { 3 }$ can be efectively switched, enabling the ferroelectric local feld efect to selectively modulate background charge carriers [34]. This feld adjustment efectively captures more holes to enhance the optical gating efect and amplifes the ferroelectric negative capacitance efect, achieving ultrahigh photodetection rates while maintaining high responsivity and detectivity [35, 36].

Here, we present a 5 × 5 ferroelectric (abbreviation: Fe) optoelectronic sensor (abbreviation: OES) array based on $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } / \mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ heterojunctions. With its excellent device quality, the Fe-OES exhibits outstanding photoelectric response under 255 nm solar-blind UV light, enabling the detection of extremely weak fames and efciently encoding spatiotemporal information at the sensing terminal. Furthermore, with external circuit integration and sensor-intrinsic computation, we demonstrate three representative fame detection applications using the Fe-OES biomimetic vision system: low-level feature-enhanced fame detection experiments, high-level fame motion recognition simulations, and advanced hardware experiments for biomimetic fame perception. Fe-OES features manufacturing compatibility with external circuits and adjustable multimode functionalities, supporting various neural networks (e.g., CNN and SNN), thus ofering a versatile platform for artifcial vision-based fame detection systems.

# 2.1 Preparation of $\mathbf { G a } _ { 2 } \mathbf { O } _ { 3 } .$ and $\mathbf { I n } _ { 2 } \mathbf { S } \mathbf { e } _ { 3 }$

# 2.1.1 Growth of ${ \bf G } a _ { 2 } { \cal O } _ { 3 }$ Films

The synthesis of ${ \mathrm { G a } } _ { 2 } { \mathrm { O } } _ { 3 }$ thin flms was achieved through atomic layer deposition (ALD). The specific process involved the introduction of a clean and dry Si substrate, coated with a 300 nm $\mathrm { S i O } _ { 2 }$ insulating layer, into the chamber

of the ALD equipment. The substrate was subjected to oxygen plasma for a period to precondition the surface and remove contaminants from the substrate surface. Trimethylgallium was deposited for 0.1 s, followed by 20 s of argon purging, and then 10 s of oxygen exposure. The typical growth temperature is about $3 0 0 ^ { \circ } \mathrm { C } .$ .

# 2.1.2 Growth of $I n _ { 2 } S e _ { 3 }$ Films

Approximately 100 mg of $\mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ powder was placed in a quartz boat located at zone 2 of the heating area, evenly spread out. Commercial mica $( \mathrm { K M g } _ { 3 } \mathrm { A l S i } _ { 3 } \mathrm { O } _ { 1 0 } \mathrm { F } _ { 2 } )$ sheets were used as substrates, placed directly above the $\mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ powder, and the vertical distance between the source material and the substrate was controlled within a narrow range (approximately 3 mm). Prior to the reaction, the system was evacuated under preliminary vacuum, followed by maintaining a vacuum level of approximately 0.5 Pa. The target temperature of the heating zone was typically set to $8 0 0 ^ { \circ } \mathrm { C }$ . After reaching the target temperature, the holding time was typically 30 min. The heating rate was typically $3 3 ^ { \circ } \mathrm { C } \mathrm { m i n } ^ { - 1 }$ . After the reaction, the quartz boat was slowly pulled out of the heating zone using a magnet, and the product cooled down to room temperature in the furnace, resulting in a 2D $\mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ flm on the mica substrate.

# 2.1.3 Transfer Method of In ${ } _ { 2 } S e _ { 3 }$ Films

First, the surface of mica sheets grown with two-dimensional phase $\mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ flms was coated with a layer of PMMA solution using a spin coater at 2000 rpm. Subsequently, the PMMA-coated samples were baked on a hot plate at $8 0 ~ ^ { \circ } \mathrm { C }$ for 5 min to evaporate the organic solvent in the PMMA, thereby solidifying it into a flm. The samples were then surrounded with tape, immersed in deionized water, and using tweezers, the PMMA flm containing the sample was peeled of from the mica due to the surface tension of the water. Next, the PMMA flm with the sample was transferred onto $\mathrm { a G a } _ { 2 } \mathrm { O } _ { 3 }$ flm and baked at $4 5 ~ ^ { \circ } \mathrm { C }$ on a hot plate for 10 min to completely evaporate the water. After dissolving the PMMA with acetone solution, the $\mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 }$ flm was transferred onto the $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 }$ flm.

The observed reduction in the dark current of the heterojunction device can be attributed to the potential barrier at the heterointerface in Fig. S13. In the $P _ { \mathrm { d o w n } }$ state, due to the lower built-in electric feld strength/barrier height, a greater number of carriers can pass through the region of the built-in electric feld, resulting in a larger current than in the pristine state. Conversely, in the $P _ { \mathrm { u p } }$ state, the higher built-in electric feld strength/barrier height impedes the transfer of charge carriers, resulting in a smaller current. The negative capacitance efect enhances the built-in electric feld, leading to a signifcant increase in the Schottky barrier or carrier injection barrier at the metal–semiconductor interface, as

illustrated in Fig. S13a, b. This suppresses electron injection from the metal into the conduction band, thereby reducing the dark current caused by thermal excitation [27, 36]. On the other hand, it blocks leakage current paths, mitigating carrier difusion or tunneling under dark conditions, which further contributes to the suppression of dark current. Moreover, due to the amplifcation of the internal electric feld strength per unit applied voltage by negative capacitance (Fig. S13c, d), particularly within the depletion region or at heterojunction interfaces, the strengthened built-in feld promotes more efcient separation of photogenerated electron–hole pairs. This reduces the recombination rate and enhances the collection efciency of minority carriers [34, 36]. Furthermore, under weak incident light, the photocurrent induced by low-intensity illumination can be collected and amplifed more rapidly and efectively owing to the negative capacitance efect. This enables the device to achieve high photodetection performance even under extremely lowlight conditions.

We developed a Fe-OES system based on $\mathrm { G a } _ { 2 } \mathrm { O } _ { 3 } / \mathrm { I n } _ { 2 } \mathrm { S e } _ { 3 } .$ where a single device can exhibit multi-operational modes of "all-or-none" pulse characteristics and time-sum

Through low-level sensing processing, it efciently handles fame information such as noise reduction and feature enhancement, enabling efcient fame detection and alarming over the entire time frame. For advanced processing, the Fe-OES system efectively encodes temporal information via in-sensor computing, achieving accurate simulation of fame motion recognition.
