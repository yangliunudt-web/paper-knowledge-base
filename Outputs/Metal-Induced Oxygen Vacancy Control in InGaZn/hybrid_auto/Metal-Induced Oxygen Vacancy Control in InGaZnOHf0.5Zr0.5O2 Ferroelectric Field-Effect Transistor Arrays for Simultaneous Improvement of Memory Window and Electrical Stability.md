Supporting Information

ABSTRACT: Zirconium-doped HfO (HZO)-based ferroelectric field-effect transistors (FeFETs) with indium gallium zinc oxide (IGZO) channels are considered one of the key technologies for future nonvolatile memories. However, realization of the technology through a simple, industry-oriented process from single devices to array levels remains challenging. While prior studies have primarily focused on the stable ferroelectric switching of HZO, optimization of the IGZO channel is also essential to facilitate polarization switching through bound charge compensation without degrading its semiconducting properties. Herein, a co-optimization process using a W/ IGZO multilayer as a capping layer for HZO is presented to modulate the oxygen vacancy distribution in IGZO/HZO. A thermodynamically driven oxygen vacancy gradient across the IGZO/HZO stack

simultaneously facilitates the ferroelectric switching operation in HZO and stable semiconducting behavior in IGZO. By simply using W and IGZO as source/drain electrodes and channels, respectively, the resulting FeFET exhibits excellent performance, including a memory window of 4.13 V, a minimum subthreshold swing of 70 mV·dec−1 , robust endurance up to 107 cycles, and a projected retention time of 10 years. To validate array-level feasibility, a 16 × 16 FeFET array is successfully implemented based on optimized conditions, demonstrating strong potential for scalable and industry-compatible integration of oxide-semiconductor-based FeFETs into next-generation nonvolatile memory technologies.

# INTRODUCTION

Data processing in the modern era is becoming complicated and massive owing to the rapid growth in the amount of information generated by artificial intelligence, the Internet of Things, and other advanced technologies. Consequently, memory technologies are continuously evolving to address the diverse demands of modern computing and storage systems in terms of key metrics, including power efficiency, reliability, and integration compatibility. In this context, nonvolatile memory (NVM) technologies have progressed significantly since the introduction of the NAND flash memory in 1987.1 Despite its widespread use, conventional NAND flash memory has inherent limitations of retention degradation and a high operating voltage of 10−20 V, making it challenging to align it with the rapid advances in computing.2 To overcome these challenges, ferroelectric memories have emerged as promising alternatives owing to their improved reliability and low operating voltages.3−5 Among various ferroelectric materials, doped $\mathrm { H f O } _ { 2 } ,$ which was reported for the first time

in 2011, has garnered significant attention as HfO -based ferroelectric technologies can offer excellent complementary metal oxide semiconductor (CMOS)-compatibility and scalability.6 Generally, zirconium-doped HfO (HZO) is one of the most widely studied materials for ferroelectric memory devices because its ferroelectricity can be easily achieved in a simple binary structure at a back-end-of-line (BEOL) compatible temperature of approximately 400 °C.7−9

Nevertheless, IGZO-based FeFETs still face the problem that the IGZO lacks positive carriers (holes), which are

required to compensate for the negative bound charges of HZO during polarization switching. This deficiency results in incomplete ferroelectric switching, leading to the difficulty in the erase operation and MW narrowing.27,28 Although previous studies suggested inserting an interfacial layer that can offer positive charges, such approaches may cause voltage loss and require additional processing steps.29,30 Alternatively, ionized [[oxygen vacancies]] $\mathrm { \hat { ( V _ { 0 } } ^ { ~ + } ~ o r ~ V _ { 0 } } ^ { 2 + } ,$ collectively denoted as ${ \mathrm { V _ { O } } } ^ { 2 + }$ for simplicity) in IGZO can act as positive charges to compensate for the bound charges in $\mathrm { H } \mathrm { \bar { Z } O } . ^ { 3 1 }$ However, the ${ \mathrm { V _ { O } } } ^ { 2 + }$ in IGZO also acts as an electron donor; therefore, an excessive ${ \mathrm { V _ { O } } } ^ { 2 + }$ concentration increases the free electron density, which in turn causes a negative threshold voltage $( \mathrm { V } _ { \mathrm { T H } } )$ shift or even conductor-like behavior.32 Moreover, the surface ${ \mathrm { V _ { O } } } ^ { 2 + }$ states in IGZO are known to degrade the subthreshold swing (SS) and cause ambient instability, thereby deteriorating the overall device performance reliability.33 Therefore, optimizing the ${ \mathrm { V _ { O } } } ^ { 2 + }$ concentration across the IGZO channel is of critical importance to achieve an appropriate MW and reliable ferroelectric switching without compromising the semiconductor properties.

In this study, we propose a metal/IGZO multilayer capping method for HZO crystallization, which offers a viable route for the simultaneous ferroelectric phase transition of HZO and oxygen vacancy $\mathrm { ( V _ { O } ) }$ concentration modulation across the IGZO/HZO stack through a simple, integration-friendly process. In this structure, the metal and IGZO layers subsequently serve as the source/drain electrode and channel

of the FeFET, respectively. W and TiN are selected as candidate materials for the metal layers, as they are widely used in HZO-based ferroelectric technologies and highly compatible with conventional semiconductor processes.34,35 The electrical and memory characteristics of FeFETs fabricated by using W/ IGZO capping (WIC) and TiN/IGZO capping (TIC) are compared. The influence of these metal layers on the IGZO/ HZO stack during annealing is investigated by using various physical and chemical analyses. Based on the optimized capping conditions, a 16 × 16 FeFET array is fabricated and its operation is demonstrated.

# RESULTS AND DISCUSSION

# Ferroelectricity in HZO Depending on the Capping Methods

We first investigated the effect of the capping layers on the ferroelectric characteristics of HZO. 10 nm-thick HZO was deposited using the thermal atomic layer deposition (ALD) technique, and the capping layers were formed by radio frequency (RF) sputtering method. In addition to the WIC and TIC, the effect of IGZO capping (IC) was examined. The fabricated metal−ferroelectric−semiconductor−metal (MFSM) or MFS stack with identical W bottom electrode (BE) was subjected to rapid thermal annealing (RTA) at 400 $^ \circ \mathrm { C }$ for 30 s under $\Nu _ { 2 }$ atmosphere. For a straightforward comparison, a W top electrode (TE) was formed after sacrificing the capping layers to form metal−ferroelectric− metal (MFM) capacitors with the same structure, as shown in Figure 1a. (See the Experimental section for more details.)

Figure 1b presents the pristine and waken-up polarizationelectric field (P−E) hysteresis of MFM capacitors using the ${ \mathrm { I C } } ,$ WIC, and TIC methods. The P−E hysteresis was measured under a triangular voltage sweep of ±3 V at 1 kHz. Before the wake-upfield cycling, the MFM capacitor processed by IC showed antiferroelectric-like behavior, while the WIC- and TIC-processed capacitors readily exhibited ferroelectric characteristics, including clear saturation polarization with a sharp hysteresis curve. After the wake-up procedure, all three capacitors exhibited proper ferroelectric behavior, which is further corroborated by distinct peaks in the displacement current−electric field (D−E) curves, as shown in Figure S1 (Supporting Information). The remnant polarization (2Pr) values were 36.67, 36.49, and $2 8 . 7 4 \mu \mathrm { C } \cdot \mathrm { c m } ^ { - 2 }$ for the IC, WIC, and TIC, respectively. Considering that the ferroelectricity of HZO is induced by the in-plane tensile stress during the cooling step of the RTA process, the in-plane stresses applied by IC and WIC can be expected to be nearly identical, and those applied by TIC be relatively smaller. To confirm this, the residual stress $\left( \sigma _ { \mathrm { c } } \right)$ induced by IC, WIC, and TIC was calculated by measuring the curvature variation of a 100 mm Si wafer before and after RTA using the Stoney formula, which is expressed as

$$

$$

It is worth reiterating that the CTE of TiN is

larger than that of W and IGZO. Based on the residual stress measurement results, it can be concluded that TiN acted like an inhibitor by applying a relatively compressive stress, whereas W maintained the stressor effect of $\mathrm { \hat { I G Z O . } } ^ { 3 7 }$ Figure 1d illustrates the evolution of the normalized $2 \mathrm { P _ { r } }$ values relative to the fully woken-up state. The initial 2P values were 68.12%, 93.46%, and 78.27% for the fully awakened states, respectively. To obtain fully awakened ferroelectric properties, wake-up field cycles of 104 , 102 , and $1 0 ^ { 2 }$ were required for the IC, WIC, and ${ \dot { \mathrm { T I C } } } ,$ respectively. Although the IC applied the strongest stressor effect, it required the largest number of wake-up field cycles and exhibited a significant difference in 2P between the pristine and fully woken-up states. Considering that the MFM capacitors underwent the same process except for the capping method, the variation in the wake-up behavior can reasonably be attributed to differences in the top capping layers.

To confirm the influence of the top capping layers on the phase transition of HZO, GIXRD measurements were performed within the 2θ range of $2 7 ^ { \circ } - 4 3 ^ { \circ }$ . GIXRD patterns were obtained without any wake-up field cycling after removal of the capping layers following the RTA process. As shown in Figure ${ \bf l e } ,$ all three capacitors exhibited a clear (111)o/(101)t peak located at $3 0 . 5 ^ { \circ } ,$ a (002)o/(110)t peak located at $3 5 . 5 ^ { \circ } ,$ and a W- or $\mathrm { W O _ { x } }$ -related peak at approximately $4 0 ^ { \circ } . ^ { 3 8 }$ In addition, a small fraction of the (111)m peak was observed in the IC sample. It is well established that the (111)o peak near $3 0 . 5 ^ { \circ }$ is responsible for the ferroelectricity in HZO. However, distinguishing between the (111)o and (101)t phases is considerably challenging, because of their structural similarities. To resolve these peaks, the GIXRD spectra of each sample were deconvoluted into three peaks, assuming a Gaussian function centered at 30.40°, 30.80°, and $3 1 . 6 4 ^ { \circ } ,$ , as shown in Figure S2a (Supporting Information). These peaks correspond to the (111)o phase, representing noncentrosymmetric ferroelectric orthorhombic phase (space group $P c a 2 _ { 1 } ) ;$ ; the (101)t phase, representing centrosymmetric nonferroelectric tetragonal phase (space group $P 4 _ { 2 } / n m c ) _ { ; }$ ; and the (111)m phase, representing centrosymmetric nonferroelectric monoclinic phase (space group P21/c), respectively.39,40 $P 2 _ { 1 } / c )$ As summarized in Figure S2b (Supporting Information), the (111)o phase ratios for IC, WIC, and TIC were 56.63%, 68.96%, and 63.37%, respectively, indicating an incomplete ferroelectric phase transition for IC compared to WIC and TIC. The (111)m phase ratio was the highest for the IC (10.17%), whereas it was negligible for the WIC and TIC (2.04% and 1.60%, respectively). Accordingly, the peak maximum within the 2θ range of $2 9 ^ { \circ } - 3 3 ^ { \circ }$ for IC, WIC, and TIC appeared at 30.54°, 30.46°, and 30.48°, respectively, as shown in the inset of Figure 1e.

In general, Hf and $\mathrm { Z r }$ reportedly act as a strong ″oxygen getter″ from the adjacent IGZO layer based on the thermodynamic parameters. Specifically, the oxygen bond dissociation energies for In, Ga, Zn, Hf, and Zr were 346, 374, 250, 801, and 766 kJ·mol−1 , respectively, indicating that the M−O bonds in IGZO are more susceptible to dissociation than those in HZO.61,64,65 Furthermore, as shown in Table $^ { 1 , }$ the enthalpies of formation (ΔHf) per oxygen atom and the Gibbs free energies of formation (ΔGf) per oxygen atom at 600−700 K are substantially lower for HfO and $\mathrm { Z r O } _ { 2 }$ than for $\mathrm { I n } _ { 2 } \mathrm O _ { 3 } , \mathrm G a _ { 2 } \mathrm O _ { 3 } ,$ and ${ \mathrm { Z n O } } ,$ indicating that the former oxides are thermodynamically more stable and their formation is more feasible during annealing.66,67 Hence, the $\mathrm { v _ { o } }$ within the HZO bulk is likely to migrate toward the adjacent IGZO layer, leading to the chemical decomposition of M−O bonds in IGZO through a process known as “oxygen scavenging”.68 In other words, IGZO is expected to supply oxygen to HZO, compensating for $\mathrm { v _ { o } }$ in HZO near the IGZO/HZO interface during the RTA process. In this context, it is reasonable to assume that such a thermodynamic oxygen transfer occurred during the WIC process, considering that the M−O bonding fraction at the HZO surface increased to 81.0% after WIC compared with 63.9% for the as-deposited HZO film. Because the WIC process resulted in a more oxygen-rich IGZO than the TIC process (Figure 4b,d), oxygen scavenging from IGZO to HZO occurred more effectively, as oxygen-rich IGZO could provide more M−O bonds that could be chemically decomposed by the scavenging effect of HZO. Such oxygenrich IGZO is attributed to the strong oxygen-supplying capability of $\mathrm { W O } _ { \mathrm { x } }$ which is likely to be formed at the W/ IGZO metal−oxide heterojunction during annealing. Since the FeFET cells sharing the same column are controlled by a single WL, an inhibit scheme is required to selectively program the target cell without affecting the adjacent cells. In typical FeFET array architectures, the inhibit operation is implemented by applying a voltage pulse to the BL to suppress programming of unwanted cell by lowering the effective voltage difference between the WL and the channel.78,79 Accordingly, after erasing the unit cell, a program pulse $( { \mathrm { V } } _ { { \mathrm { P G M } } } )$ was applied to the ${ \mathrm { W L } } ,$ while the inhibit pulse $\mathrm { ( V _ { i n h i b i t } ) }$ was applied to the BL. The width of the applied $\mathrm { V _ { i n h i b i t } }$ was the same as that of the $\mathrm { V } _ { \mathrm { P G M } } \left( 1 0 0 \mu s \right)$ , while its amplitude was varied (1, 2, and 3 V). As shown in Figure 8a, the FeFET maintained its ERS state when a $\mathrm { V _ { i n h i b i t } }$ of 3 V was applied, confirming the proper inhibition of unwanted programming. Based on the optimized inhibit condition, two representative program−inhibit operation cases were evaluated, as illustrated in Figure 8b. The resulting heat maps of $\mathrm { I _ { D S } }$ at a $\mathrm { V _ { R E A D } }$ of 0.1 V and $\mathrm { V } _ { \mathrm { T H } }$ in Figure 8c confirm that the program−inhibit operation was successfully implemented.

Another key aspect for demonstrating practical array-level operation is the capability of multibit storage. Array-level multibit functionality is essential not merely for increasing storage density, but for enabling advanced FeFET-based inmemory computing architectures.80,81 T he multibit storage capability was evaluated using 16 cells located along a single WL. As shown in Figure $^ { 8 \mathrm { d } , }$ the intermediate (01) and (10) states were achieved by applying the write voltages $\mathrm { ( V _ { w r i t e } ) }$ of 2 and 3 V to the WL, respectively. Note that the cells were fully erased before writing the (01) and (10) states. Figure 8e shows the statistical $\mathrm { V } _ { \mathrm { T H } }$ distribution for all four states, demonstrating

clear separation with a sufficient margin. These results demonstrate the suitability of the WIC method for arraylevel FeFET integration with a simplified fabrication process without any requirements of additional processes or materials.

# CONCLUSIONS

In this study, we demonstrate a simultaneous optimization strategy for IGZO/HZO-based FeFETs by employing the WIC method, from single-device fabrication to a $1 6 \times 1 6$ array implementation. Depending on the thermodynamic properties of W, IGZO, and HZO, the $\mathrm { v _ { o } }$ distribution across the IGZO/ HZO region was effectively modulated. Structural and compositional analyses revealed that the front-channel region was reduced by the oxygen scavenging effect of HZO, whereas the back-channel region was oxidized, because of the oxygensupplying behavior of $\mathrm { W O } _ { x } .$ Consequently, positive space charge regions formed by ${ \mathrm { V } _ { 0 } } ^ { 2 + }$ + in the front-channel enabled a wide MW of 4.13 ${ \mathrm { V } } ,$ while the oxidized back-channel contributed to a low SS of ${ 7 0 \ \mathrm { m V \cdot d e c ^ { - 1 } } }$ and robust endurance and retention characteristics of $1 0 ^ { 7 }$ cycles and a projected retention time of 10 years, respectively. A comparative analysis with TIC-FeFETs suggested that W could be a particularly promising material for achieving the simultaneous optimization of the HZO ferroelectricity and IGZO semiconductor performance. Furthermore, the fabricated $1 6 ~ \times ~ 1 6$ FeFET array based on the WIC structure exhibited excellent uniformity, as well as array-level reliability such as program− inhibit operation and multibit storage. Given that the proposed method utilizes vacuum-deposited, industry-standard commercialized materials such as hafnium-based dielectric, IGZO, and W, and is fully compatible with BEOL processing temperatures below 400 ${ } ^ { \circ } \mathrm { C } ,$ it holds strong potential for practical integration of state-of-the-art performance oxide semiconductor-based FeFETs in next-generation NVM technologies.

# EXPERIMENTAL METHODS

# Fabrication of MFM Capacitors

As the BE, 50 nm-thick W was deposited using RF sputtering method at room temperature on top of a heavily boron-doped p-type silicon wafer with a thermally grown 120 nm-thick $\mathrm { S i O } _ { 2 }$ layer. For the ferroelectric layer, 10 nm-thick HZO was deposited by the ALD method using tetrakis(ethylmethylamido)hafnium (TEMAHf), tetrakis(ethylmethylamido)zirconium (TEMAZr), and $\mathrm { O } _ { 3 }$ as the hafnium precursor, zirconium precursor, and an oxidant, respectively. $\mathrm { H f O } _ { 2 }$ and $\mathrm { Z r O } _ { 2 }$ were deposited in the 1:1 ratio at the chamber temperature of 250 ${ } ^ { \circ } C ,$ and the growth per cycle of $\mathrm { H f O } _ { 2 }$ and $\mathrm { Z r O } _ { 2 }$ were maintained at 0.12 nm per cycle, respectively. Three capping layers were deposited for comparison. For all three samples, 10 nmthick IGZO was sputtered under ambient Ar using an IGZO single target consisting of $\mathrm { I n } _ { 2 } \mathrm { O } _ { 3 } ,$ Ga $\mathbf { \Omega } _ { \perp } \mathrm { O } _ { 3 } ,$ and $_ { \mathrm { Z n O } }$ in a 1:1:1 ratio. The sputtering power was 50 W, and the working pressure was kept at 1 mTorr to obtain a high-quality film. For one sample, no additional metal capping layer was deposited (IC), whereas for the other two, either 50 nm-thick W or TiN metal capping layer was sputtered on top of the IGZO layers (WIC and TIC, respectively). For TiN deposition, a reactive sputtering technique using a single Ti target with an ambient $\Nu _ { 2 }$ atmosphere was employed. Then, all three samples were subjected to RTA at 400 $^ \circ { \mathbf { C } }$ for 30 s under ambient $\Nu _ { 2 }$ for the ferroelectric phase transition of HZO. For the WIC and TIC samples, the W or TiN metal capping layer was removed via wet chemical etching using a standard clean-1 (SC-1) solution, followed by IGZO removal via wet etching using a diluted HCl solution. The SC-1 solution was synthesized using one scoop of diluted $\mathrm { N H _ { 4 } O H } ,$ two scoops of $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$ and five scoops of H O. For the IC sample, the IGZO capping layer was removed by using the same diluted HCl

solution to form an identical HZO/W stack. Finally, W was sputtered and patterned via photolithography and etching using the same SC-1 solution to form a top metal contact.

# Fabrication of FeFET Single Transistor and Array

Single FeFETs were fabricated with an inverted staggered structure. A 50 nm-thick W gate electrode was deposited via RF sputtering and patterned via photolithography and etching. Subsequently, HZO and IGZO were deposited as the GI and channel layers using ALD and RF sputtering, respectively. The IGZO layer was patterned to define the active channels. For the WIC and TIC samples, W or TiN TEs were deposited via sputtering. The resulting device stacks were IGZO/ HZO/W (IC), W/IGZO/HZO/W (WIC), and TiN/IGZO/HZO/ W (TIC), all of which were annealed under the same RTA conditions used for MFM capacitor fabrication. In the WIC and TIC samples, the metal capping layers also served as source/drain electrodes, as defined by photolithography and etching. For the IC device, the source/drain electrodes were formed by patterning an additional W layer using the same process. The channel length and width were 10 and 100 μm, respectively. A 16 × 16 FeFET array was fabricated by using the same WIC-FeFET process flow, with the only difference being the photomask layout to define the array structure.

# Measurement and Characterization

The electrical characteristics of the MFM capacitors, FeFETs, and FeFET arrays were measured at room temperature in the dark using a parameter analyzer (4200A, Keithley Instruments, USA). For the MFM capacitors, a voltage pulse was applied to the top W or TiN electrode, while the bottom W electrode was grounded. Highresolution wafer curvature scanning (MOS UltraScan, k-Space Associates, USA) was performed to obtain residual stress by comparing the variation in the 100 mm wafer curvature before and after annealing. XRD measurement (SmartLab, Rigaku, Japan) was conducted to confirm the crystalline phase of the HZO film. The incident X-ray was Cu Kα1 with a wavelength of 1.54056 Å. The surface morphology of the BCE surface of the FeFETs was characterized using AFM (NX-10, Park Systems, Republic of Korea) in the noncontact mode. The Hall mobility, carrier concentration, and sheet resistance of the IGZO films were measured by using a Hall effect measurement system (HMS-3000, ECOPIA, Republic of Korea). XPS depth profiling (K-alpha, Thermo Fisher Scientific, UK) was conducted to quantitatively investigate the chemical stoichiometry. For depth profiling, the surface was sequentially etched for 30 s intervals at an ${ \bf A } \bar { \bf r ^ { + } }$ ion energy of 500 eV and analyzed in repeated cycles to obtain compositional variation through the film. The microstructure, crystallinity, and elemental analysis in the IGZO/HZO films were analyzed using HR-TEM (JEM-ARM 200F, JEOL, Japan) equipped with an EDS line scan and mapping system. Cross-sectional HR-TEM samples were processed using focused ion beam equipment (crossbeam350, ZEISS, Germany). The optical images of the 16 × 16 FeFET array were obtained using DM (VHX-7000, Keyence Corporation, Japan).
