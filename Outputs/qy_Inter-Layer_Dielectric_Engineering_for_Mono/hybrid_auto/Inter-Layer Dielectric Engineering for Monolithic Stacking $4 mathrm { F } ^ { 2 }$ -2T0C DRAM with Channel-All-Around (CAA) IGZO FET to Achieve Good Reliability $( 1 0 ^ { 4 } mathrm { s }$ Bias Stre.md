Chuanke Chen, Xinlv Duan, Guanhua Yang, Congyan Lu, Di Geng*, Ling Li* and Ming Liu Key Laboratory of Microelectronics Devices and Integrated Technology, Institute of Microelectronics of the Chinese Academy of Sciences, Beijing, China. *email: digeng@ime.ac.cn, lingli@ime.ac.cn

Abstract—To address the stacking requirement of 4F2 2T0C DRAM with vertical channel-all-around (CAA) IGZO FETs, for the first time, the effect of inter-layer dielectric (ILD) on CAA-IGZO FETs has been studied by varying dielectric material and process. By using optimized ILD and IGZO deposition cycle ratio, CAA-IGZO FET with high reliability is obtained. The optimized device exhibits a $\mathrm { V _ { t h } }$ shift of less than 25 mV after $1 0 ^ { 4 } \mathrm { s }$ bias stress and no significant degradation after $1 0 ^ { 1 2 }$ cycles endurance. Our results provide an important reference for facilitating the monolithic stacking of multilayer IGZO FETs to realize 3D DRAM.

# I. INTRODUCTION

In recent years, monolithic 3D DRAM has attracted extensive attention due to the growing demand for DRAM capacity in the industry. IGZO-based capacitor-less DRAM has shown its promising characteristic such as BEOL compatibility and ultra-long retention time owing to the ultralow off-state current of IGZO FETs. Our previous works have proposed channel-all-around (CAA) IGZO FET structure and demonstrated its scaling capability [1-2], revealing its potential to form $4 \mathrm { F } ^ { 2 }$ 2T0C-bit-cell for high-density DRAM applications. However, in order to fabricate a functional 4F2 2T0C-bit-cell or memory array, the first layer of CAA-IGZO FETs needs to be insulated before stacking the second layer of devices, as shown in Fig. 1. Therefore, the effect of inter-layer dielectric (ILD) on the first-layer FETs needs to be studied. In this work, we investigate the influences of different ILD materials and deposition processes on CAA-IGZO FETs, combined with the modulation of IGZO-deposition cycle ratio, resulting in optimized CAA-IGZO FETs with ILD.

Fig. 2 shows the structure diagram of a CAA-IGZO FET, including a 3D diagram (Fig. 2(a)), a top-down view (Fig. 2(b)) and a cross-sectional view (Fig. 2(c)). The diameter of the channel-hole region is defined as the critical dimension (CD) of the device, and the perimeter of the hole is the channel width (W). The channel length (L) is determined by the distance between two S/D layers along the vertical channel direction.

# II. FABRICATION

The fabrication process flow of a CAA-IGZO FET is shown in Fig. 3. A TiN layer is deposited by PVD and patterned as the bottom S/D electrode. Then, a SiO-spacer layer and a top TiN layer are sequentially deposited by PVD, and the top TiN is patterned as the top S/D electrode, forming the metal/insulator/metal (MIM) structure. The vertical channel region is obtained by etching the MIM structure using dry etching process. A channel layer (IGZO), a gate insulator layer (HfOx) and a gate electrode layer (IZO) are then sequentially deposited by plasma-enhanced atomic layer deposition (PEALD) at 250℃. ALD process has excellent trench coverage and film uniformity, making it ideal for depositing films in the vertical channel region of CAA structure. O2 plasma is chosen as the oxidant during the ALD process to avoid the influence of hydrogen on the IGZO film. Dry etching process is used to patterned the gate stack films $\mathrm { ( I G Z O / H f O _ { \mathrm { { x } } } / I Z O ) }$ for device isolation. After the isolation, the ILD deposition is performed. In order to investigate the effect of different dielectrics on the device performance of CAA-IGZO FETs, different insulating materials and different deposition processes have been tried in this work. Finally, the ILD is patterned by dry etching process to expose the device electrodes, and CAA-IGZO FETs with inter-layer dielectric are obtained.

# III. OPTIMIZATION

Fig. 4(a) shows the changes in the transfer characteristics of CAA-IGZO FETs before and after the deposition of different ILDs, and Fig. 4(b) is the statistical result of threshold voltage (Vth) shift after the ILDs deposition. Both $_ { \mathrm { A L D - A l } _ { 2 } \mathrm { O } _ { 3 } }$ and chemical vapor deposition (CVD)-SiO deposited at 250℃ lead to a negative shift in the threshold voltage of FETs, while SiO with O2 plasma $( ( \mathrm { O } _ { 2 }$ plasma)-SiO) causes a positive shift in threshold voltage. The mechanism of $\mathrm { V _ { t h } }$ shifts after depositing different ILDs is shown in Fig. 4(c)- (f). When depositing the ILD, different reactants and deposition processes will result in different contents of elements (such as hydrogen and oxygen) in the deposition environment, and excess hydrogen or oxygen will cause

changes in the properties of IGZO films. Excess hydrogen can easily diffuse into the IGZO film, breaking the metal-oxygen covalent bonds, resulting in the formation of hydroxide and oxygen vacancies $\mathrm { ( V _ { O } ) }$ [3], as shown in Fig. 4(c). Conversely, excess oxygen can fill the oxygen vacancies to form metaloxygen bonds and suppress $\mathrm { V _ { O } }$ formation, as shown in Fig. 4(d). $\mathrm { V _ { O } }$ is generally considered as donor that supplies electron carrier in IGZO [4], so the increase or decrease of $\mathrm { V _ { O } }$ concentration can lead to a negative $_ \mathrm { o r }$ positive shift of threshold voltage, respectively. Therefore, the excess hydrogen doping during $_ { \mathrm { A L D - A l } _ { 2 } \mathrm { O } _ { 3 } }$ deposition and CVD-SiO deposition may cause the negative shift of $\mathrm { V _ { t h } , }$ while the oxygen plasma treatment during $( \mathrm { O } _ { 2 }$ plasma)-SiO deposition may be responsible for the positive shift of $\mathrm { V _ { t h } , }$ as shown in Fig. 4(e) and Fig. 4(f), respectively.

During PEALD-IGZO deposition process, three kinds of precursors are used to deposit $\mathrm { I n O } _ { \mathrm { x } } ,$ GaOx and $Z _ { \mathrm { n O _ { x } } }$ layers, respectively. By adjusting the deposition sequence and cycle ratio of these three oxide layers, IGZO film properties can be effectively tuned, and the transfer characteristics of IGZO FETs will be changed accordingly [1]. Fig. 5(a) shows the schematic of the cycle ratio. In each super cycle, InOx, GaOx and $Z \mathrm { n O _ { x } }$ are sequentially deposited with a cycle ratio of x:y:z, and IGZO film is obtained after N times of super cycles. The transfer characteristics of CAA-IGZO FETs with cycle ratios of 6:1:1 and 3:1:1 are shown in Fig. 5(b), and the cycle ratio effects on $\mathrm { V _ { t h } }$ and $\mathrm { I _ { o n } }$ are shown in Fig. 6. Due to the smaller operating voltage, 3:1:1 is chosen as the optimized cycle ratio in this work. Median $\mathrm { I _ { o n } }$ of the optimized devices is about 4.07 μA/μm. Transfer and output characteristics of the optimized CAA-IGZO FETs with $( \mathrm { O } _ { 2 }$ plasma)-SiO ILD and 3:1:1 cycle ratio are shown in Fig. 7(a) and Fig. 7(b). The transfer curves exhibit a drain-induced-barrier-lowering (DIBL) of about 56 mV/V, and the output curves show good contact behavior. Fig. 7(c) shows the statistical result of subthreshold swing (SS). Fig. 8(a) and Fig. 8(b) show the cross-sectional TEM images and Fig. 8(c) shows the element mapping of the optimized CAA-IGZO FET with 50 nm channel length, 550 nm CD and 50 nm (O2 plasma)-SiO ILD. The good conformal covering of $\mathrm { I G Z O / H f O _ { \mathrm { { x } } } / I Z O }$ film deposited by PEALD and uniform distribution of element can be seen in TEM image and element mapping.

# IV. RELIABILITY AND RETENTION

Fig. 9(a) shows the transfer characteristics of the optimized CAA FET under negative bias stress (NBS), where the gate bias stress was set at $- 2 \mathrm { V }$ and S/D was set to 0V. The extracted $\mathrm { V _ { t h } }$ shift $\left( \Delta \mathrm { V } _ { \mathrm { t h } } \right)$ , SS and $\mathrm { I _ { o n } }$ (at $\mathrm { V } _ { \mathrm { t h } } { + } 1 \mathrm { V } )$ are shown in Fig. 9(b). It shows no obvious degradation after 104s NBS, and $\mathrm { V _ { t h } }$ negatively shifts about 25 mV. Fig. 10(a) shows the transfer characteristics of CAA FET with 550nm CD under $1 0 ^ { 4 } \mathrm { s }$ positive bias stress (PBS). During the stress test, the gate bias stress was set at 2V and the S/D was set to 0V. The extracted $\Delta \mathrm { V } _ { \mathrm { t h } } ,$ SS and $\mathrm { I _ { o n } }$ (at $\mathrm { V } _ { \mathrm { t h } } { + } 1 \mathrm { V } )$ are plotted in Fig. 10(b). The negative shift after PBS may be due to the effect of hydrogen from GI, which is released and migrates into IGZO under the PBS condition. The $\Delta \mathrm { V } _ { \mathrm { t h } }$ comparison of the CAA-

IGZO FETs with different IGZO cycle ratio under 104s PBS is shown in Fig. 11. CAA device with 3:1:1 cycle ratio exhibits less $\mathrm { V _ { t h } }$ shift than the device with 6:1:1 cycle ratio, which may be attributed to the less interface defects in the devices with 3:1:1 cycle ratio. These stress results show that the optimized CAA-IGZO FETs exhibit excellent stability without degradation under 104s PBS and NBS condition.

The retention characteristics of the optimized CAA-IGZO FETs are also studied. The 2T0C bit-cell is formed by connecting two CAA-IGZO FETs in the same layer, as shown in Fig. $\mathbf { 1 } 2 ( \mathbf { a } )$ . WBL, WWL are set at 1V, 0.5V during write operation and at 0V, -2V during read operation, respectively. Fig. 12(c) depicts the corresponding timing diagram for write $^ { \ 6 \ } 1 ^ { \dag }$ and read “1” operations. During the read operation, IRBL is recorded and the corresponding voltage at signal node $( \mathrm { V } _ { \mathrm { S N } } )$ is extracted from the $\mathrm { V _ { S N }  – I _ { r e a d } }$ curve in Fig. 12(d). The $\mathrm { V } _ { \mathrm { S N } }$ over time is plotted in Fig. 12(e). The retention time at state $^ { 6 6 } 1 ^ { , 5 }$ is defined as the time that VSN decreased by 0.1 V, which reaches about 190 s. The gate leakage current may be an importance factor affecting the retention time, which can be further improved by gate stack optimization. The endurance characteristics of CAA FET with 550nm CD are tested by applying continuous write and erase operation pulse cycles between 1V and -1V to the gate electrode of read transistor (Tr). Fig. 13(a) shows the transfer curves of $\cdot _ { \mathrm { ~ T ~ } _ { \mathrm { ~ r ~ } } }$ after $1 0 ^ { 1 2 }$ continuous pulse cycles, which shows no significant degradation. The read current $\left( \mathrm { I } _ { \mathrm { r e a d } } \right)$ and off-current (Ioff) of $\mathrm { T _ { r } }$ during the pulse cycles are extracted at $\mathrm { V _ { D } } = 0 . 1 \mathrm { V } , \mathrm { V _ { G } } = 1 \mathrm { V }$ and $\mathrm { V _ { D } } = 0 . 1 \mathrm { V }$ , $\mathrm { V _ { G } } = - 1 \mathrm { V }$ , respectively. The actual $\mathrm { I _ { o f f } }$ is less than the test limit, so the ratio between $\mathrm { { I } _ { r e a d } }$ and $\mathrm { I _ { o f f } }$ maintains larger than $1 0 ^ { 6 }$ after $1 0 ^ { 1 2 }$ pulse cycles, as shown in Fig. 13(b). These test results indicate that the fabricated CAA-IGZO FETs are reliable for 2T0C DRAM application. # V. CONCLUSION

Inter-layer dielectric engineering has been performed for future stacking of the second-layer CAA-IGZO FETs. Different insulating materials and deposition processes for ILD deposition and their effect on CAA-IGZO FETs have been investigated. Together with the tuning of the IGZOdeposition cycle ratio, the optimized CAA-IGZO FETs show excellent reliability, including ${ > } 1 0 ^ { 4 } \mathrm { s }$ bias stress (both PBS and NBS) and ${ \mathrm { > } } 1 0 ^ { 1 \bar { 2 } }$ cycles endurance. This work helps to facilitate the realization of stacked 2T0C IGZO DRAM.
