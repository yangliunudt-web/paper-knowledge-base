# ABSTRACT

Hafnia-based ferroelectric thin-film transistors (FeTFTs) are regarded as promising candidates for future nonvolatile memory devices owing to their low power consumption, high operational speed, and complementary metal–oxide–semiconductor compatibility. However, the scalability of hafnia-based materials and the feasibility of three-dimensional (3D) device fabrication should be confirmed for ultrahigh-density memory applications. In this work, we demonstrate that FeTFTs can be scaled down to a 10-nm dimension using the vertical structure with a hafnia-based ferroelectric gate insulating layer and an oxide semiconductor channel. We show that such vertical FeTFTs can be operated with an effective device size of 0.005 lm2 , a fast operation speed of <100 ns, and a high endurance of 108 cycles. Additionally, the string-level NAND operation is demonstrated using the vertical FeTFT array. Finally, device simulation confirms the possibility of ultrahigh-density 3D ferroelectric NAND with 200 gate stacks. These results demonstrate the ultrahigh scalability of FeTFTs as a promising candidate for nextgeneration 3D nonvolatile memory.

As planar NAND devices have reached their scaling limits, vertically stacked three-dimensional (3D) NAND technologies have been proposed to realize continuous memory density and cost scaling of NAND devices.1,2 Currently, the scaling of 3D NAND is done by stacking the word-line (WL) layers. However, achieving ultrahigh memory density through WL stacking alone is considered challenging because the elongated physical height of a vertical NAND string increases the process cost for stacking and the difficulty of etching.3 The physical height of a string is expected to exceed 100 lm if the number of WL layers reaches a few thousand.3 Moreover, the string current decreases as the physical height of the string increases, making the sensing operation rather difficult.2,3 Emerging technologies should be further demonstrated for continuous scaling of 3D NAND devices. Hafnia-based ferroelectric materials have attracted research interest owing to their complementary metal–oxide–semiconductor (CMOS) compatibility, low power consumption, high scalability, and fast switching speed.4–8 As a result of these advantages, hafnia-based ferroelectric materials have been adopted in ferroelectric transistors, negative capacitance field-effect transistors, ferroelectric tunneling

junctions, and artificial synapses.9–17 Compared with conventional ferroelectrics that show small coercive fields (-0.1 MV/cm), the large coercive field (-1 MV/cm) of hafnia-based ferroelectric materials can lead to large memory windows with highly scalable thicknesses.18 Furthermore, the fast switching speed of hafnia-based ferroelectric materials can result in fast and energy-efficient operation. 19,20

Ferroelectric transistors using hafnia-based materials are thus considered promising candidates for next-generation high-density memory device s.16,21 The high scalability of hafnia-based ferroelectrics may be advantageous for 3D memory applications. Recent research demonstrated the possibility that hafnia-based ferroelectrics could be operated in the nanometer scale.5,6,8 As current charge-trap 3D NAND flash memories have a gate length of -40 nm and an effective device size of 0.007 lm2 , the implementation of hafnia-based ferroelectric transistors will enable continuous scaling of 3D NAND flash memory technologies when device operation with a smaller device size than current flash memory and integration strategy are being provided.22,23

In this study, we show that a hafnia-based ferroelectric thin-film transistor (FeTFT) can be operated with a gate length of 10 nm in

vertical structures. Our fabricated devices show stable transfer characteristics and a fast operation speed of <100 ns with an effective device size of 0.005 $\mu \mathrm { m } ^ { 2 }$ . Using an oxide semiconductor channel, the growth of unintentional interfacial oxide layers is constrained, resulting in a high endurance of ${ 1 0 } ^ { 8 }$ cycles. The low device-to-device variation of vertical FeTFTs and the string-level operation of 3D ferroelectric NAND string are demonstrated. Finally, the possibility of ultrahighdensity 3D ferroelectric NAND with 200 WL stacks is confirmed. The results show the high scalability of vertical ferroelectric transistors and the feasibility of using 3D ferroelectric NAND for next-generation memory devices.

Vertical FeTFTs were fabricated on a $\mathrm { S i O } _ { 2 } / \mathrm { S i }$ substrate using photolithography and a liftoff process. First, a 10-nm-thick TiN WL and the 50-nm-thick $\mathrm { S i O } _ { 2 }$ layers were alternately deposited on the substrate. $\mathrm { T i N } / \mathrm { S i O } _ { 2 }$ multi-stack layers were partially etched using the dryetch process to form a vertical structure. Then, a 24-nm-thick HfZrOx layer and the Mo source/bit lines (SLs/BLs) were deposited using the atomic layer deposition (ALD) and evaporation method, respectively. Finally, a 20-nm-thick $\mathrm { I n Z n O _ { x } }$ channel layer was deposited using

ALD. Thus, TiN, $\mathrm { H f Z r O _ { x } , I n Z n O _ { x } , }$ and Mo were used as the WL, ferroelectric gate insulator, semiconductor channel, and SL/BL, respectively [Figs. 1(a) and 1(b)]. The device had three WLs, and all WLs shared the same SL and BL, which was structurally similar to a single string of 3D NAND. The thickness of the TiN gate electrode and the width of the $\mathrm { I n Z n O _ { x } }$ channel were 10 and 500 nm, respectively, resulting in an effective device size of $0 . 0 0 5 \ \mu \mathrm { m } ^ { 2 }$ . The electrical characteristics of the vertical FeTFT were investigated under ambient conditions. The vertical FeTFT located at the middle $( \mathrm { W L } _ { 2 } )$ was selected. By sweeping the WL voltage $( V _ { \mathrm { W L } } )$ between –4 and 4 V to the selected cell while applying a pass voltage $( V _ { \mathrm { P A S S } } )$ of 2 V to the WLs of unselected cells, an n-type transfer characteristic with anticlockwise hysteresis was observed [Fig. 1(c)]. This anticlockwise hysteresis under a $V _ { \mathrm { W L } }$ is from the switching of ferroelectric polarization of the $\mathrm { H f Z r O _ { x } }$ layer.12,22 The vertical FeTFT was programmed and erased using voltage pulses [Fig. 1(d)]. Voltage pulses of (4 V, 100 ls) for program and $( - 5 \mathrm { V } ,$ , 100 ls) for erase operations were applied to the selected WL. Various memory characteristics of nanoscale vertical FeTFTs were investigated. The switching characteristics of vertical FeTFTs were further verified by applying voltage pulses with different widths to the selected WL while applying a $V _ { \mathrm { P A S S } } = 2 \mathrm { V }$ to unselected WLs. With a pulse amplitude of 4 V, the threshold voltage $( V _ { \mathrm { t h } } )$ of the device was changed with increasing pulse width [Fig. 2(a)]. With an amplitude of $6 { \bar { \mathrm { V } } } ,$ the device showed a clear $V _ { \mathrm { t h } }$ shift with a pulse width of 50 ns, and a memory window of 1 V could be achieved with a pulse width of 100 ns. In addition, for an erase operation, a memory window of 1 V could be achieved with a pulse width of 500 ns using a pulse amplitude of –6 V [Fig. 2(b)]. The endurance characteristics of the device were investigated by applying a triangular program (4 V, 500 ns) and erase (–4 V, 500 ns) pulses. After each program, erase pulse was applied, and the $I _ { \mathrm { B L } }$ at $V _ { \mathrm { W L } } = - 1 \mathrm { V }$ and $V _ { \mathrm { P A S S } } = 2 \mathrm { V }$ was measured to confirm its state. The device showed stable switching characteristics for ${ 1 0 } ^ { 8 }$ cycles with an I of ${ \sim } 1 0 ^ { - 8 } \mathrm { ~ A ~ }$ and ${ \sim } 1 0 ^ { - 1 0 } \mathrm { ~ A ~ }$ at the programmed and erased states, respectively $\left[ \mathrm { F i g . } \ 2 ( \mathrm { c } ) \right]$ . These results confirm the high operation speed and operational stability of nanoscale vertical FeTFTs. The high endurance characteristics of our FeTFTs are thought to be due to the use of an oxide semiconductor channel. As suggested in previous reports, limited endurance in ferroelectric transistors is thought to be due to the degradation of the interfacial layer formed between $\mathrm { H f Z r O _ { x } }$ and the channel layer.16,24,25 The use of oxide semiconductor $\mathrm { I n Z n O _ { 3 } }$ channels can lead to interfacial layer-free channel/ $\mathrm { \ddot { H } Z r O _ { x } }$ stack, which can improve the reliability of the FeTFTs.

To estimate the feasibility of employing FeTFTs for future 3D FeNAND, the string-level operation was demonstrated using the fabricated device. Prior to the demonstration of string-level operation, transfer characteristics of fabricated nanoscale vertical FeTFTs were measured [Fig. 3(a)]. All three vertical FeTFTs in the same string showed similar transfer characteristics with a memory window of ${ \sim } 2 \mathrm { v }$ and operated without failure. To demonstrate string-level NAND operations, four different cases of NAND strings (all programmed cells, one erased cell and all other programmed cells, two erased cells and one programmed cell, and all erased cells) were used [Fig. 3(b)]. The readout current $\left( I _ { \mathrm { r e a d o u t } } \right)$ of the string was measured at all cases under $V _ { \mathrm { W L } } = - 1 \mathrm { V } .$ The NAND string showed on-state only when all FeTFTs were at the programmed state and showed off-state at all other cases. These results confirmed that NAND memory operated in a vertical array of FeTFTs.

We confirmed that the highly scalable vertical FeTFTs could be operated with a gate length and an effective device size of 10 nm and 0.005 lm2 , respectively. Vertical FeTFTs with a gate length of 10 nm showed stable memory characteristics and a fast operation speed. The devices located in the same string showed similar transfer characteristics, and string-level NAND operations were demonstrated.

Furthermore, through experimental results and a TCAD tool, we showed that our suggested vertical FeTFTs could be directly implemented to 3D FeNAND cells with ultrahigh density. The program and program-inhibited operations in 3D FeNAND with 200 WL stacks were confirmed. Our results provide an approach for realizing highly scaled ferroelectric transistors for next-generation memory devices.
