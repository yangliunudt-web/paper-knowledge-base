This not only requires extremely energy-e"cient architecture (such as in-memory computing) but also memory hardware with tunable properties to simultaneously meet the demand for training and inference. Simulations show that the proposed device architecture could achieve the same level of performance as a graphics processing unit under notably improved energy e"ciency. Our device core can be combined with silicon circuitry through three-dimensional heterogeneous integration to give a hardware solution towards general edge intelligence.

For example, typical edge training scenarios involve over 1012 multiply-and-accumulate operations per second under milliwatt power, which far exceed the capability of existing hardware technologies4 . Recently, in-memory computing (IMC) based on non-volatile memories (NVMs) has emerged as a promising solution for EI4,5,7–14. However, using a single NVM technology to perform simultaneous training and inference has been challenging5–7 . This is because training and inference take different aspects of memory properties5 . In particular, training involves abundant data; therefore, it requires good endurance, speed and energy efficiency. On the other hand, inference relies on prestored cell weights, and hence, retention is critical. In both scenarios, analogue capability is desirable to improve the accuracy and energy efficiency of neural networks5 . Unfortunately, most NVMs

lack large tunability in-memory properties, preventing a universal IMC architecture that simultaneously satisfies the requirements for training and inference.

Ferroelectrics were proposed as a NVM in the 1950s and recently became technologically promising after the discovery of ferroelectricity in binary fluorite oxides (HfO2 and ZrO2) down to the thickness limit15–19. As the basic device building block for IMC, a ferroelectric field-effect transistor (FeFET) has been demonstrated on various channel materials, delivering some of the most promising characteristics for edge computing20–28. Among the channel materials, two-dimensional (2D) semiconductors (such as transition metal dichalcogenides) are especially appealing because of the following reasons: (1) they have atomic thickness and therefore low power consumption through leakage at scaled device dimension29–31; (2) reduced screening allows the

reduction in gate voltage and expands the design margin for analogue computing32,33; (3) they are back-end-of-line compatible with complementary metal–oxide–semiconductors and can be integrated with peripheral circuitry34, although some challenges regarding material, device and integration need to be addressed35,36; (4) they offer a variety of sensory properties to facilitate the fusion of sensors with computing23,37,38.

Here we combined a FeFET with a monolayer ${ \mathsf { M o S } } _ { 2 }$ channel and devised a duplex device structure for in situ machine learning. The duplex structure comprised a split-gate FeFET with different ferroelectric (FE)/dielectric (DE) capacitance ratios $( C _ { \mathrm { F E } } / C _ { \mathrm { D E } } )$ optimized for training and inference, respectively. The duplex structure simultaneously exhibited excellent endurance $\mathrm { ( > 1 0 ^ { 1 3 } ) }$ , retention (>10 years), speed (4.8 ns) and energy consumption (22.7 fJ bit– $^ { 1 }  { \mu \mathrm { m } ^ { - 2 } } )$ to meet the requirement for edge training and inference. A multilayer neural network was implemented with an array of two-transistors-one-duplex (2T1D) cells and achieved 99.86% accuracy in nonlinear localization using in situ trained weights and all-analogue computing. Our results suggest that combining 2D materials with FEs is a promising hardware solution for EI.

# Duplex FeFET device structure

We exploited the tunability of FeFET by engineering the FE energy landscape in the metal–FE–metal–insulator–semiconductor (MFMIS) device structure. Figure 1b shows the schematic of a duplex device structure consisting of two split gates with different $C _ { \mathrm { F E } }$ values sharing the same ${ \mathsf { M o S } } _ { 2 }$ channel. The metal layer between FE and DE acts as a floating gate (FG) in-memory operation. The potential drop across the FE is expressed as

$$
V _ {\mathrm {F E}} = V _ {\mathrm {g}} \times \frac {C _ {\mathrm {D E}}}{C _ {\mathrm {D E}} + C _ {\mathrm {F E}}}, \tag {1}
$$

where $V _ { \mathrm { g } }$ is the gate voltage and $C _ { \mathrm { F E } }$ and $C _ { \mathrm { D E } }$ represent the capacitance of the FE and DE layer, respectively. The Gibbs free energy of the FE–DE system is expressed as $G _ { \mathrm { { F E } } } t _ { \mathrm { { F E } } } + G _ { \mathrm { { D E } } } t _ { \mathrm { { D E } } }$ , where $G _ { \mathrm { { F E } } } ( G _ { \mathrm { { D E } } } )$ and $t _ { \mathrm { F E } } ( t _ { \mathrm { D E } } )$ are the free energy and thickness of the FE (DE) layer, respectively. By changing the $C _ { \mathrm { F E } } / C _ { \mathrm { D F } }$ E ratio, the FeFET can evolve from being FE-like to DE-like as a result of the evolving FE energy landscape, leading to continuously tunable memory characteristics (Extended Data Fig. 1). Specifically, when operating on the gate with small (large) $C _ { \mathrm { F E } } ,$ , the duplex FeFET is FE-like (DE-like), which is more suitable for inference (training). In the extreme case of infinite $C _ { \mathrm { F E } } / C _ { \mathrm { D E } }$ (without FE), the device is pure DE and can serve as a selector transistor in a crossbar array.

Figure 1c displays an optical micrograph of a 2T1D duplex cell, where the two split gates of the duplex FeFET are connected to training (T) and inference (I) selectors through vertical vias. Figure 1d illustrates the programming sequence during the in situ machine learning process. The T and I word line, which is the gate voltage of the corresponding selector, is used to select the T-type and I-type synapse during training and inference, respectively. During in situ training, multiple weight-tuning pulses are applied on the T-type synapses through the bit line. After the network has been trained, the weights are transferred to I-type synapses through the same bit line, which are stored there and used for inference. The $V _ { \mathrm { i n } }$ value, which is the drain voltage of the FeFET, acted as the weight read for backpropagation during training as well as the data voltage input for feedforward during inference.

# Device performance of duplex FeFET

All the devices in this work used chemical-vapour-deposited monolayer MoS as the channel39 and local backgate (BG) structure consisting of two dielectric layers (16 nm $\mathsf { H f } _ { x } Z \mathsf { r } _ { 1 - x } \mathbf { O } _ { 2 }$ FE and 12 nm ${ \mathrm { H f } } 0 _ { 2 }$ DE with permittivity of 18 and 19, respectively) and three metal layers (BG, FG and source/drain (S/D)) (Fig. 2a; Methods provides the fabrication details). All the detailed geometric device parameters can be found in

Supplementary Table 1. The temperature of the entire $\mathbf { M o S } _ { 2 }$ transfer and device fabrication process was kept below $4 5 0 ^ { \circ } \mathrm { C }$ . We first studied the memory properties of the FeFET as a function of $C _ { \mathrm { F E } } / C _ { \mathrm { D E } } .$ To this end, we fabricated a test structure with the FE/DE area ratio $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ ranging from 0.007 to 2.667. Figure 2b plots the double-sweep $ { I _ { \mathrm { d s } } } ^ { \mathrm { ~ } }$ – $V _ { \mathrm { g } }$ characteristics of the FeFET as a function of $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ . As expected, the memory window progressively narrowed with $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ due to the increasing DE contribution in the gate stack (Extended Data Fig. 1). In the pure DE case (by shorting the FG and BG), the device returned to the transistor behaviour with negligible hysteresis (Fig. 2b, black line).

The retention and endurance characteristics of the FeFET are summarized in Fig. 2c,d and Extended Data Figs. 2 and 3. In contrast to binary memory in logic circuits, multibit data retention is desirable for inference using IMC. We performed an accelerated retention test of 16 states in an I-type FeFET $( A _ { \mathrm { F E } } / A _ { \mathrm { D E } } { = } 0 . 0 5 3 )$ under $8 5 ^ { \circ } \mathrm { C }$ before (Fig. 2c) and after (Extended Data Fig. 3h) endurance cycling. For the fresh device and the device that underwent $1 0 ^ { 5 }$ endurance cycles, the conductance of the states was well separated and did not show obvious degradation up to $1 0 ^ { 3 } s$ . More remarkably, even under a $1 2 5 ^ { \circ } \mathrm { C }$ accelerated $\mathrm { \ t e s t ^ { 4 0 } }$ , we could still extrapolate the ten-year retention in the I-type FeFET with an on/off ratio of $1 0 ^ { 6 }$ (Extended Data Fig. 3f). To evaluate endurance, we continuously applied programming and erase voltage pulses with a period of 20 ns and measured the transfer curve to extract $I _ { \mathrm { o n } }$ and $\boldsymbol { I } _ { \mathrm { o f f } }$ at intervals of several cycles41 (Fig. 2d (inset); Methods provides more details). Figure 2d and Supplementary Fig. 1 show the endurance of a T-type FeFET $( A _ { \mathrm { F E } } / A _ { \mathrm { D E } } { = } 0 . 6 7 )$ . The devices survived $1 0 ^ { 1 3 }$ cycles without breaking, whereas the on/off ratio of 105 was adequate for memory operations. We measured the endurance for a range of $A _ { \mathrm { F E } } / A _ { \mathrm { D I } }$ E values and observed a trade-off behaviour with retention, which was consistent with the transition from FE-like to DE-like behaviour (Extended Data Figs. 1 and 2a). Nevertheless, the endurance exceeded the requirement for edge training $( 1 0 ^ { 9 } )$ ) and even cloud training $( 1 0 ^ { 1 2 } )$ in a wide range of $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ values7,42, providing a large design space for different applications. To experimentally evaluate the scaling potential of device metrics, we fabricated and measured scaled devices with different channel lengths. We found that even for a channel length down to 85 nm, the strong $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ dependence, high retention of DE-like devices and high endurance of FE-like devices maintained high consistency with long-channel devices (Supplementary Note 5 and Extended Data Fig. 2).

We further performed benchmark tests with existing memory technologies, including flash, resistive-random access memory, phase-change RAM, magnetoresistive RAM, ferroelectric tunnel junction and ferroelectric RAM (Fig. 2f and Supplementary Tables 2 and 3). As a building block for IMC, our duplex FeFET structure simultaneously demonstrated good endurance and retention characteristics. It is worth noting that the degenerated endurance of Hf-based FeFET originates from numerous factors, such as a high coercive field for saturation polarization, imprint induced by interfacial traps or defects, uncompensated charge by metal-ferroelectric-insulator-semiconductor (MFIS) structure and so on. Compared with the MFIS structure, the MFMIS structure releases interfacial voltage stress and reduces trap and defect generation20 as well as embraces symmetrical electrodes and compensated charge. Moreover, benefitting from the strong gate dependence of atomic ${ \bf M o S } _ { 2 } ,$ , the reduced $V _ { \mathrm { F E } }$ value with unsaturated polarization can still achieve multibit storage required for training (more flattened E–P relationship; Extended Data Fig. 1), thereby effectively improving endurance. As a result, our devices improved the endurance over existing Si- and $\mathbf { M o S } _ { 2 }$ -based FeFETs by $1 0 ^ { 2 }$ and 108 , respectively.

Memory speed and energy consumption were also critical for training with massive data. We characterized the switching speed and read speed by ultrafast pulse measurements and read-after-write measurements (Extended Data Fig. 4). Extended Data Fig. 6a–c shows the 7-bit (128-state) output characteristics and the corresponding potentiation/depression process of a T-type FeFET $( A _ { \mathrm { F E } } / A _ { \mathrm { D E } } { = } 0 . 4 3 ;$ ; Methods provides the measurement details). The reliable multilevel performance is attributed to the dangling-bond-free interface of MoS2, which could potentially overcome the trap-induced performance degradation in Si-based FeFETs33. # Hardware implementation of in situ learning

To demonstrate the potential of the duplex FeFET architecture towards in situ learning, we built an artificial neural network (ANN) (Fig. 3a) containing three neuron layers (input, hidden and output) and solved the localization problem in 2D space (Fig. 3b), which is a higher-order classification problem that cannot be implemented by single-layer or binary network (Supplementary Note 3). The neural network was physically implemented by an 8 % 3 array of 2T1D TIIO cells (Fig. 1c). Two 7-bit cells were combined together to realize positive and negative weights to imitate excitation and inhibition in biology. Therefore, sizes of the L1 synapse (connecting the input and hidden layer) and L2 synapse (connecting the hidden and output layer) are 2 % 4 and 4 % 1, respectively, with 8-bit precision. Within each cell, the T-type and I-type synapse shared the MoS channel with $A _ { \mathrm { F E } } / A _ { \mathrm { D E } }$ values of 0.430 and 0.053, respectively. In this pseudo-crossbar array, training and inference functions were performed as the voltage sequence operation described in Fig. 1d. The datasets were imported as a voltage sequence to $V _ { \mathrm { i n } }$ without any encoding (Extended Data Fig. 6d). The weight was stored by FE polarization and translated as the channel conductance of FeFET and output $I _ { \mathrm { d s } }$ was summed over each column according to Kirchhoff’s law. Owing to the linear $I _ { \mathrm { d s } } - V _ { \mathrm { d s } }$ curve and long data retention, high-fidelity analogue output waveforms were achieved. The measurement setup, software and interfaces were customized to facilitate the hardware test flow (Methods and Extended Data Fig. 7).

Monocular depth estimation, on the other hand, is attractive for computer vision due to the reduced hardware volume and computational resources46 (Fig. 4a). However, monocular depth estimation is like seeing three-dimensional space with one eye, which requires repeated data training to adapt the foreshortening effects and therefore extremely high energy efficiency.

A widely adopted approach for monocular depth estimation is the encoder–decoder architecture (Fig. 4b). The encoder part uses massive pretrained weights through transfer learning47 but minimal weight update, which requires long data retention (corresponding to the I-type synapse). On the contrary, the decoder part focused on feature extraction from training with abundant data (corresponding to the T-type synapse). Here a 15-block U-Net48 with 178 layers was simulated using the duplex architecture, where I-type (T-type) synapses were used in a nine-block encoder (six-block decoder) with all the device parameters derived from experiments (Methods and Extended Data Fig. 9). Two variation models were constructed for training and inference to ensure simulation reliability (Methods). The simulated chip consisted of 128 % 128 2T1D cells with a peripheral analogue-to-digital converter (ADC), sample-and-hold circuit multiplexer, controller and

driver (Fig. 4c, inset). Figure 4d and Extended Data Fig. 10e show several street scenes during autonomous driving. Our duplex TIIO chip successfully identified all the features and captured their relative depth with a comparable convergence rate as the graphics processing unit (GPU) (Fig. 4c). The recognition accuracy (3σ level of threshold) and root mean square error reached 96.85% and 6.31%, respectively (Extended Data Fig. 10a,c). Compared with the GPU, the convolution circuit of the duplex TIIO exhibits better energy efficiency as well as maintains equivalent computing accuracy. We designed rigorous scaling rules based on International Technology Roadmap for Semiconductors reports and cell layout with appraised parasitic parameters to perform energy efficiency projection for our TIIO cell at advanced 22-nm-node technology (Supplementary Note 6). For the training (inference) process, the pre- and post-simulation of the projected cell energy efficiency is 2,110 (111.86) and 1,151 (111.86) tera-operations per second per watt. We noticed that the reduced energy efficiency in post-simulation is induced by the larger operating voltage of the bit line, which also leads to a further drop in energy efficiency as the array scale increases. Therefore, reducing the thickness of $\mathrm { \ddot { H } } _ { 0 . 5 } Z _ { 0 . 5 } 0 _ { 2 . 0 }$ (HZO) and realizing the integration of more advanced technology node will be crucial to improving the chip-level energy efficiency. Owing

to the back-end-of-line advantages of 2D materials and FE HZO, the neuromorphic computing cores can be the monolithically integrated with other necessary functional blocks of pooling, activation, routing and buffering in the future, and further improving the overall energy efficiency.

# Conclusions

In this work, we have shown the large tunability of memory metrics by device architecture design, which is lacking for most NVM technologies. We demonstrated an IMC architecture that can complete in situ machine learning, using unitary device technology. By integrating split FE capacitors with complementary characteristics in the same memory cell, the proposed duplex architecture solves the problem of conflicting memory requirements for training and inference, which has long plagued EI applications. It not only simplifies the hardware fabrication process but also merges the training and inference process in one memory building block. Such a compact design can improve parallel computation and thus deliver higher energy efficiency. Based on 22-nm-node technology, our architecture shows a post-simulation projected energy efficiency for training of 1,151 tera-operations per second per watt using a single TIIO cell. It is, however, worth noting that the projection here is somewhat overestimated because the contribution of the necessary peripheral circuitry is not included. Compared with previous work that focused on training and inference, we use the non-volatile multibit characteristics for both learning and inference on a single device, and demonstrate a 2D localization task on a small-scale hardware circuit, which maintains high area efficiency and energy efficiency for IMC applications. Our design also embraces transfer learning that is widely applied in image processing, natural language processing and emotion recognition, thus will probably become a key component in lifelong learning applications.

# Methods

# Fabrication of duplex FeFET/TIIO array

On a p-type silicon substrate with 275 nm $\mathrm { S i O } _ { 2 } , \mathrm { : }$ a BG (M1) was defined by electron-beam lithography (EBL), and 3 nm Ti/9 nm Pt was deposited by an electron-beam evaporator. A 16 nm HZO film was deposited at $2 0 0 { } ^ { \circ } \mathrm { C }$ by atomic layer deposition using TDMA-Hf and TDMA-Zr precursors, and water as the oxygen source. Next, an FG was defined by EBL, and 14 nm Pt was evaporated using the electron-beam evaporator. With the FG metal covered, the crystallization of FE HZO was realized by rapid thermal annealing at $4 5 0 ^ { \circ } \mathrm { C }$ in a $\mathsf { N } _ { 2 }$ atmosphere for 30 s. A 12 nm HfO2 film was deposited at 150 °C by atomic layer deposition using TEMA-Hf precursor and O plasma as the oxygen source.

There are slight differences for the fabrication of a TIIO array. During substrate fabrication, the input line and output line were made with M1 metal. The training/inference word line was made with M2 metal. The bit line and hidden nodes were made with M3 metal. An interconnection via was defined by EBL and etched using BCl /Ar by a GSE C200 Series plasma etcher, with Pt as the etch stop after M1, M2 and dielectric. There were four different via types in the TIIO array: M1–M3, the input line in connection with the drain of the FeFET; M1–M3, the bottom metal in connection with a source of selector field-effect transistor; M1, for probing the input line and output line; M2, for probing the training/ inference word line. The size and distribution of pads were specially designed for customized probe cards.

Single-crystalline monolayer ${ \mathsf { M o S } } _ { 2 }$ films were grown on customdesigned C/A-plane sapphire wafers in a home-made chemical vapour deposition furnace. Assisted by 35 nm flat Au films, the MoS2 film was transferred to the target substrate by polymethyl methacrylate and polydimethylsiloxane. The polydimethylsiloxane/polymethyl methacrylate/Au stack was laminated on fresh new MoS /sapphire. Next, MoS was dry delaminated from the sapphire and transferred onto substrates with prepatterned gate layout in a glovebox. Then, the unnecessary Au/MoS2 (defined by EBL) was removed by sequential Au etching (using Transene TFA) and ${ \mathsf { M o S } } _ { 2 }$ etching (using $\mathsf { S F } _ { 6 }$ and ${ \bf O } _ { 2 }$ plasma in a reactive ion etcher). The last step of EBL defined the S/D pattern, and M3 metal of 10 nm Ti/35 nm Pd/10 nm Ti were deposited by the electron-beam evaporator. Finally, a self-aligned etch was performed to open a channel via the S/D metal mask using Transene TFA. Annealing $( 2 0 0 ^ { \circ } \mathrm { C } )$ was performed to remove the adsorbates and improve contact with a base pressure a $: \sim 1 0 ^ { - 6 }$ Pa in a vacuum atmosphere.

# Electrical measurement of duplex FeFET

We developed a home-made system for the various in situ measurements of the FeFET and TIIO array. The system contained a Keithley 4200 semiconductor characterization system with four source measure units for the d.c. test and 4225 remote pulse and switch module for pulse test, a National Instruments PXIe-2532B matrix switch (with an 8 % 64 terminal block), PXIe-5433 arbitrary waveform generator (AWG) and Keysight MSOX6004A oscilloscope.

The transfer and output characteristics were measured by source measure units with a preamplifier, which enable a current resolution of 0.1 fA. Regarding data retention, the FeFET was programmed to the on state or erased to the off state and then a d.c. sampling test ran for thousands of seconds. In addition, we measured retention at temperatures of 85 and $1 2 5 ^ { \circ } \mathrm { C }$ in a vacuum atmosphere in a Lake Shore CRX-VF probe station. We extrapolated the high-temperature ten-year retention by linear fitting.

In the multistate test, potentiation and degression were realized by positive and negative pulses, generated by the 4225 remote pulse and switch modules. Pulses were applied at the gate, and the drain and source of the field-effect transistor were grounded. Once the pulse finished, we grounded the gate and applied $V _ { \mathrm { d s } }$ to read the conductance of the FeFET. For a shorter pulse width in the speed test, we switched to the National Instruments PXIe-5433 AWG, which can generate pulses with amplitudes up to 10 V and pulse widths as small as 4.8 ns. A Keysight

MSOX6004A oscilloscope was used here to collect the real-time pulse amplitude and width. The mode of the AWG was set to a user-defined waveform, list output and immediate trigger. The duration was carefully set to ensure that only one pulse was generated for every output. In the endurance test, based on the AWG, we changed the duration to output a sequence of identical pulses, with different number of cycles, namely, $1 , 1 \dot { 0 } , 1 \times 1 0 ^ { 3 } , 1 \times 1 0 ^ { 4 } , . . . . , \dot { 1 } \times 1 0 ^ { 1 3 }$ . At the very end of one sequence, we check the transfer curve of the FeFET to monitor performance degradation. Considering that the time spent was very large for 1 $\times 1 0 ^ { 1 2 }$ and $1 \times 1 0 ^ { 1 3 }$ cycling, we measured $I _ { \mathrm { o n } }$ and $I _ { \mathrm { o f f } }$ for discrete cycles rather than every cycle.

# Hardware in situ machine learning on TIIO array

In the array measurement, we modified the vacuum probe station to meet the special requirements. The National Instruments PXIe-2532B matrix switch, in the 8 % 64 terminal setup, helped connect the source measure unit/phasor measurement unit test sources with the device under test. We loaded two customized probe cards (12 pins for A and 15 pins for B) on the original arms in the probe station. These probe cards were electrically connected with flexible flat cables, adapters, cable hub (48 line feedthrough), and in the end, the test instruments outside. All the tests were performed in a vacuum environment.

For the training process, we added one PC connected with the Keithley 4200 semiconductor characterization system for running the program codes, which defined the initial parameters and hyperparameters, flow of ANN training, interfaces for software–hardware interaction and related data processing. On the level of hardware, two selectors share one drain in one 2T1D cell; thus, the operation mode depends on which word line (T or I type) accesses the duplex FeFET. A typical process is mode transferring from training to inference, which means resetting the T-type capacitor, switching to the I-word line and programming the I-type capacitor to a well-trained weight. More details about the algorithm can be found in Supplementary Note 4.

# Device modelling and hardware evolution

Based on the measuring results of duplex FeFET devices (Supplementary Figs. 6 and 7), we constructed two variation models for inference and training. Without the loss of generality, random variables sampled from the Gaussian distribution with zero mean and σ2 variance are used to simulate the inference and training variation. A linear variation model is used in this work.

$$
W _ {\mathrm {w} / \text {n o i s e}} = W _ {\mathrm {w} / \mathrm {o} \text {n o i s e}} + W _ {\mathrm {w} / \mathrm {o} \text {n o i s e}} \times \text {N o i s e} _ {\text {w e i g h t s}}, \tag {2}
$$

$$
\operatorname {N o i s e} _ {\text {w e i g h t s}} \sim N \left(0, \sigma_ {\text {w e i g h t s}} ^ {2}\right). \tag {3}
$$

The standard deviation $\sigma _ { \mathrm { w e i g h t s } }$ is $0 . 0 5 6 \mu \mathrm { S }$ (channel length, 3 µm) and 0.040 µS (scaled device with a channel length of 85 nm).

Similar to inference variation, a similar linear model is used to simulate the training variation:

$$
V _ {\text {u p d a t e w / n o i s e}} = V _ {\text {u p d a t e w / o n o i s e}} + V _ {\text {u p d a t e w / o n o i s e}} \times \text {N o i s e} _ {\text {u p d a t e}}, \tag {4}
$$

$$
\operatorname {N o i s e} _ {\text {u p d a t e}} \sim N \left(0, \sigma_ {\text {u p d a t e}} ^ {2}\right). \tag {5}
$$

Standard deviation $\sigma _ { \mathrm { u p d a t e } }$ is 0.043 µS (channel length, 3 µm) and 0.017 µS (scaled device with a channel length of 85 nm).

# Dataset and neural network structure in monocular depth estimation

We evaluated our devices on a monocular pixel-level-depth prediction task based on a subset of the KITTI dataset. The data in the KITTI dataset are captured by driving around in rural areas and on highways

in the midsized city of Karlsruhe. The dataset comprises stereo and optical flow image pairs, stereo visual odometry sequences and object annotations captured scenarios49. In this work, we tried to predict the depth of each pixel in raw RGB images from a monocular camera. We randomly selected 2,802 images for training and 608 images for testing.

We simulated a transfer learning algorithm to demonstrate the superiority of the TIIO architecture in both inference and training. The neural network adopts the U-Net structure, which consists of the encoder and decoder47,48. The encoder is realized by a 169-layer DenseNet50 with four dense blocks and four transition blocks. The decoder is realized by a convolutional layer and five upsampling blocks. Each upsampling block contains a bilinear upsampling layer and two convolutional layers with Leaky ReLU activations. The four dense blocks in the encoder are connected to the first four upsampling blocks. The whole network configuration is shown in Supplementary Table 9. The encoder is pretrained on an ImageNet classification task50,51. The decoder is randomly initialized using a uniform model and trained for this depth prediction task with the encoder together.

# Training details in monocular depth estimation

The loss function with L1-norm loss and structural similarity index measure (SSIM) loss52 is used:

$$
\operatorname {L o s s} = \lambda L _ {1} (y, \hat {y}) + L _ {\text {S S I M}} (y, \hat {y}), \tag {6}
$$

where y indicates the predicted image and y indicates the ground truth. ̂ The pixel-wise L1-norm loss is defined as

$$
L _ {1} (y, \hat {y}) = \frac {1}{n} \sum_ {p} ^ {n} \left| y _ {p} - \hat {y} _ {p} \right|. \tag {7}
$$

The SSIM loss is defined as

$$
L _ {\text {S S I M}} (y, \hat {y}) = \frac {1 - \text {S S I M} (y , \hat {y})}{2}. \tag {8}
$$

In this work, λ is set to 0.1.

To update the weights according to the gradients, a series of identical pulses are applied on duplex FeFET devices and the without-verify strategy is used in this simulation. When the gradient is less than a quarter of the average change in one pulse, the devices will not be changed.

The other parameter settings of the training are listed in Supplementary Table 10.

# Evaluation of predicted depth

We evaluated the accuracy of the predicted depth with different tolerance levels $( \delta _ { 1 } , \delta _ { 2 } , \delta _ { 3 } )$ , the absolute relative depth error (abs Rel.), the root mean square error of depth (r.m.s.) and the log mean absolute error (log MAE)53 of our duplex FeFET in situ training algorithm. The predicted depth of a pixel is considered correct with tolerance level δ depending on whether the relative error between the predicted depth and ground truth is smaller than δ.

$$
\max  \left(\frac {\text {d e p t h} _ {\text {p r e d}}}{\text {d e p t h} _ {\text {g t}}}, \frac {\text {d e p t h} _ {\text {g t}}}{\text {d e p t h} _ {\text {p r e d}}}\right) <   \delta . \tag {9}
$$

The tolerance levels used in this work are 1.25, 1.252 and 1.253 . The other evaluation indicators are calculated as follows:

$$
\text {a b s} \operatorname {R e l.} = \frac {1}{n} \sum \frac {\left| y _ {\text {p r e d}} - y _ {\text {g t}} \right|}{y _ {\text {g t}}}, \tag {10}
$$

$$
\mathrm {r . m . s .} = \sqrt {\frac {1}{n} \left| y _ {\mathrm {p r e d}} - y _ {\mathrm {g t}} \right| ^ {2}}, \tag {11}
$$

$$
\log \mathrm {M A E} = \frac {1}{n} \sum \left| \log \left(y _ {\text {p r e d}}\right) - \log \left(y _ {\mathrm {g t}}\right) \right|. \tag {12}
$$
