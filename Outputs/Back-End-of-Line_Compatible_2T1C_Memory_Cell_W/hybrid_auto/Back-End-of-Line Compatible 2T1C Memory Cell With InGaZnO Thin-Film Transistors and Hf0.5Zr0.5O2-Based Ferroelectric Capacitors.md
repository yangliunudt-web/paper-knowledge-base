# Back-End-of-Line Compatible 2T1C Memory Cell With InGaZnO Thin-Film Transistors and Hf0.5Zr0.5O2-Based Ferroelectric Capacitors

Yize Sun , Shucheng Zhang , Qihan Liu, Member, IEEE, Yu Li , Member, IEEE, Haoyu Lu Xumeng Zhang , Member, IEEE, Yingfen Wei , Member, IEEE, Mengwei Si , Member, IEEE, Hao Jiang , Member, IEEE, and Qi Liu , Member, IEEE

Abstract— Back-end-of-line (BEOL) compatible and high-performance thin-film transistors (TFTs) and emerging memory devices trigger significant interest in their integration into 3-D computing and memory systems. In this work, we demonstrate, for the first time, the fully integrated 2T1C memory cells with InGaZnO TFTs and $\mathsf { H f } _ { 0 . 5 } \mathsf { Z r } _ { 0 . 5 } \mathsf { O } _ { 2 }$ (HZO)-based ferroelectric capacitors (FeCaps). The write and read operations of this recently proposed ferroelectric memory structure were systematically studied. The impacts of critical parameters on device performances were elucidated, including 1) applied voltage; 2) ferroelectric remnant polarization (Pr); 3) transistor threshold voltage $( V _ { \mathrm { f h } } ) ;$ and 4) area ratio (AR) between the FeCap and the MOS capacitor of the Read transistor. The device with an AR of 1:8 can be operated with low voltages of 2 V for write and 2.5 V for read. Finally, the reliabilities of our fabricated 2T1C memory cells including retention $( \geq 1 0 ^ { 5 }$ s) and endurance $( \geq 1 0 ^ { 7 }$ cycles) were experimentally characterized.

Index Terms— 2T1C structure, back-end-of-line (BEOL)- compatible, ferroelectric memory, $\mathsf { H f } _ { 0 . 5 } \mathsf { Z r } _ { 0 . 5 } \mathsf { O } _ { 2 }$ (HZO), indium gallium zinc oxide (IGZO) transistor.

# II. EXPERIMENT

The device structure and the fabrication process flow of our 2T1C cell are shown in Fig. 1(b) and (c). We started with the fabrication of the W/HZO/W FeCap: a 30-nm W bottom electrode, 10-nm HZO film, and 30-nm W top/gate electrode were sequentially deposited and patterned, followed by rapid thermal annealing (RTA) at $4 0 0 ~ ^ { \circ } \mathrm { C }$ for 600 s in an ${ \Nu } _ { 2 }$ environment. Especially, in the 2T1C structure, a high ON-current for the WT is associated with a lower ON-state channel resistance. This subsequently suppresses the line RC effect, enabling faster polarization switching in the FeCap, and consequently, reducing write operation latency. Since the write voltage is directly applied to the FeCap, a lower amplitude is expected compared to FeFET [15]. This voltage can be further reduced by utilizing a thinner HZO layer.

During the read operation [Fig. 4(a)], the WT is turned off with both WL and BL grounded to zero. When a positive voltage is applied to PL, the switching from up-polarization state to down-polarization state in the FeCap leads to a charge accumulation at the SN node. Consequently, a high $V _ { \mathrm { S N } }$ value is maintained even after the PL returns to zero. This enables the sensing of different $I _ { \mathrm { d s } }$ values from the RT when reading the $" 1 "$ and $\ " 0 \ "$ states of the 2T1C device. As this read scheme is destructive, similar to the FeRAM, an additional write back operation is necessary to restore the same state to the FeCap. Otherwise, the transconductance readout method releases the demand of large polarization charge and FeCap area. Compared to 1T1C FeRAM, better scalability and low-power consumption can be achieved [5]. Based on the characteristics of the 2T1C devices, we propose two distinct read schemes [Fig. 4(b)]. To thoroughly investigate the read performance under different FeCap or thin-film transistor (TFT) characteristics, we develop a compact model for 2T1C devices based on HSPICE. The response of ferroelectric polarization to the electric field is described by a hyperbolic tangent function [18]. In the IGZO TFT model, the drain current is developed based on the framework established for amorphous silicon TFTs, and the capacitance–voltage relationship is analogous to that described in [19]. Moreover, the models of FeCap and IGZO TFT are all calibrated by experimental results. The AR of the simulated device in Fig. 6(a) and (b) are both 1:8. The simulated MW is defined as the difference in $V _ { \mathrm { g } }$ between $" 1 "$ and $\ " 0 \ "$ states when $I _ { \mathrm { d } }$ reaches 1 nA. Fig. 6(a) shows the simulated $I _ { \mathrm { d } } { - } V _ { \mathrm { g } }$ curves with various $P _ { \mathrm { r } } .$ The $I _ { \mathrm { d } } { - } V _ { \mathrm { g } }$ curves remain almost unchanged when reading the $\mathbf { \vec { \Delta } } ^ { 6 } 0 ^ { 9 }$ state due to the suppressed polarization switching in the FeCap. However, the increasing $P _ { \mathrm { r } }$ value leads to larger effective capacitance and stronger depolarizing field. The former one suppresses the voltage division across the FeCap, preventing it from complete polarization switching when $V _ { \mathrm { g } }$ is applied. The latter one triggers a substantial backswitching of polarization when $V _ { \mathrm { g } }$ returns to zero. The combined effect causes the effective $P _ { \mathrm { r } }$ value that affects the transistor gate to reach a saturated value. When the polarization switching process is accompanied by the opening of the RT channel, the increased effective capacitance of FeCaps induces a higher voltage drop across the RT, resulting in a reduction of the effective subthreshold swing (SS), as shown by the green and blue curves in Fig. 6(b). It can be observed that as the $V _ { \mathrm { t h } }$ increases, the read scheme I becomes more favored. More ferroelectric polarization switching is involved during the read $" 1 "$ operation, leading to a higher “1”/“0” current ratio and greater distinction between the forward $V _ { \mathrm { t h } }$ of the $" 1 "$ state and the $\mathbf { \vec { \Delta } } ^ { 6 } 0 ^ { 9 }$ state. As a result, the degradation in the MW resulting from the possible electrical-stress-induced $V _ { \mathrm { t h } }$ shift of IGZO transistors [23] can be effectively suppressed by optimizing the parameters of RTs and FeCaps. During the retention test, the voltage amplitude and pulsewidth are adequate for saturating the charging process, and the SN voltage can be precisely obtained from the SL current. Fig. 7(c) shows the endurance measurement of a 2T1C cell. The FeCap was electrically cycled under ±2 V pulses with a pulsewidth $( \boldsymbol { t } _ { \mathrm { p w } } )$ of 1 $\mu \mathrm { s }$ and a rising/falling time $\left( t _ { r / f } \right)$ of $0 . 5 \ \mu \mathrm { s } ,$ , identified as a tolerable measurement time. Despite the fact that a higher $V _ { \mathrm { P L } }$ is employed during the read operation compared to the write operation, the voltage drop across the FeCap should be smaller than $V _ { \mathrm { P L } }$ due to the series connection of the FeCap with the MOS capacitor of RT. This effectively mitigates the electric stress applied to the FeCap during the read operation. Furthermore, according to our simulation results [Fig. 6(a)], the Pr of our FeCap exceeds the threshold required to saturate the MW. Therefore, despite a reduction in the switchable polarization $( P _ { \mathrm { S W } } )$ of the FeCap after $1 0 ^ { 7 }$ switching cycles due to fatigue, our 2T1C device can maintain a similar MW both before and after the endurance test at a 0.5 V readout voltage under 1 kHz triangular pulses [Fig. 7(d)]. Therefore, by linearly extrapolating the endurance performance of the FeCap in our case, it can be estimated that the MW will start to degrade after $4 \times 1 0 ^ { 8 }$ cycles and sustain ∼0.6 V even after $6 ~ \times ~ 1 0 ^ { 1 0 }$ cycles. Meanwhile, the endurance of HZO-based FeCaps up to $1 0 ^ { 1 2 }$ cycles has been reported [28], [29], [30]. By employing careful device engineering techniques, including the damascene process which effectively eliminates the overstriding step around the electrode edge [31], the endurance of the 2T1C memory cell can be further enhanced. In addition, the proposed memory cell can be operated in the 2T0C-DRAM mode when frequent data addressing and programming are needed, potentially reducing the endurance demands on the FeCap.

Table I benchmarks our 2T1C memory with various advanced BEOL-compatible memories, such as FeFET [7], FeRAM [31], 2T0C-DRAM [32], and 1T-1RRAM [33]. The considerable MW superior to FeFET and 1T-1RRAM is attributed to the effective modulation of the transistor channel

by the electric field from ferroelectric polarization, and can be further enhanced by optimizing manufacturing processes [25], [26], [27]. Although the endurance of our existing 2T1C is not optimal, feasible pathways to achieve 1012 cycles have been confirmed in [28] and [29], offering a promising prospect for endurance that could compete with FeFET and 1T-1RRAM. Our 2T1C device also exhibits improved retention surpassing other devices, especially FeFET and 2T0C-DRAM, owing to the suppressed depolarization field and the nonvolatile characteristic of FeCap. The transconductance readout method through RT of the 2T1C device helps in reducing the area demand of FeCap, performing better than FeRAM in this aspect. It is also worth mentioning that the cell area of 2T1C can be further minimized through advancements in M3D integration technology. Extreme performances of speed and power consumption are comparable for all 2T1C, 2T0C-DRAM, FeFET, FeRAM, and RRAM technologies after device optimization or scaling [34], [35], [36], [37]. Specifically, at the 28 nm node, the power consumption and access time for 2T1C are estimated to be ∼1 fJ and <10 ns, respectively, with the potential for further improvements as process nodes continue to advance [11].

We envision 2T1C memory serving as a complement to DRAM across various application scenarios, rather than a direct competitor to DRAM or Flash. Our proposed 2T1C memory eliminates the requirement for high-aspect-ratio 3-D capacitors, which is promising for applications requiring low-power consumption and simple fabrication process. The compatibility with BEOL processes and the feasibility of M3D integration enable broader design flexibility and higher density. Additionally, its nonvolatile nature avoids continuous refresh cycles, making it suitable for scenarios with infrequent operations that necessitate long data-retention. Overall, our 2T1C device integrates the promising features among various proposed memory candidates, presenting a compelling solution in the landscape of BEOL-compatible memories.

# IV. CONCLUSION

In summary, we experimentally demonstrated, for the first time, a fully integrated 2T1C memory cell with BEOLcompatible IGZO TFTs and HZO-based FeCaps. The working principles and performance metrics, including MW, retention, and endurance were systematically studied and discussed, through both experimental characterizations and compactmodel simulations. Our work paves the way for 2T1C ferroelectric devices as a viable option among low-power memory technologies that can be monolithically integrated into 3-D systems.
