# Roadmap for Ferroelectric Memory: Challenges and Opportunities for IMC Applications

Sourav De, Maximilian Lederer, Yannick Raffel, Franz Müller, Konrad Seidel and Thomas Kämpfe

Center Nanoelectronic Technologies, Fraunhofer-Institut für Photonische Mikrosysteme
  - "[[FeFET]]"

An d. Bartlake 5, 01109 Dresden, Germany, email: sourav.de@ipms.fraunhofer.de

Abstract: CMOS compatibility and the low process temperature of hafnium oxide(HfO2) make HfO2-based ferroelectric FETs an excellent candidate for logic, memory, and neuromorphic devices. This article discusses the challenges and opportunities of using hafnium oxide-basedferroelectric memory for in-memorycomputing applications. Finally, we try to draw the roadmap for them.

Keywords: FeFET, Fe-finFET, FeTFT, Memory Array, Neural Network.

# I. Introduction

INSTIGATED by the plethora of data generated by edge devices and IoT devices, machine learning has become the de facto choice of everyone for solving many tasks. Applications such as intelligent healthcare monitoring systems, smartwatches, orautomatic cars require real-time processing of the data or image, which is done by machine learning algorithms with higher efficiency than humans. The standard software-based neural networks implemented in Von-Neumann computing systems, where the memory and computation parts are segregated, suffer from severe latency with an increasing number of edge devices. However, the multitude of edge devices used in our daily life imposes strict restrictions on latency, device area, and power consumption for hardware. Therefore, we need to take the route beyond the CMOS-based mixed-signal implementation of neural networks, where the quintessential Von-Neumann architecture does not limit the memory bandwidth. CMOS compatibility of $H f O _ { 2 } ,$ , along with further factors like endurance, latency, and negligible impact from random telegraph noise (RTN), enable HfO2-based ferroelectric memories, especially the Fe-FETs, as a prospective candidate for next-generation in-memory-computing (IMC) applications [1-7]. Despite having several advantages over other types of non-volatile memories, some pivotal issues hinder the system-level implementation of ferroelectric memories.

# II. Challenges and Roadmap for Hafnium Oxide-Based Ferroelectric Memory

Recent research on 28nm high-k metal gate (HKMG) Fe-FETs, and Fe-finFETs have enabled the use of deeply scaled memory devices for analogue computing-in-memory (CIM) applications. Fig.1 demonstrates a schematic overview of the FeFET and FeRAM-based CIM architecture. However, deviceto-device (D2D) variations in deeply scaled Fe-FETs pose a severe threat to accurately executing analogue vector-matrix multiplication operations. Numerous efforts have been made to improve the ill-impact D2D deviations in Fe-FETs, especially for computing-in-memory applications. One approach is to run online training of NNs with Fe-FETs as synapses due to their noise-tolerant nature. Still, this method requires a very high endurance [1,2]. Fig.1 shows the online training accuracy for recognising different data sets with various neural network

architectures. Simpler neural networks like multi-layer perceptron can achieve high training accuracy for small data-sets like MNIST even with 1bit/cell precision of synapses. However, training complicated neural networks with larger data sets requires higher precision of synaptic weights, which necessitates multilevel coding (MLC) capability in Fe-FET/FeRAM cells. Table:I shows the present state-of-art ferroelectric memory devices. Although most of the planar devices demonstrate MLC characteristics, the deeply scaled devices are limited to only 1bit/cell precision. Therefore, the roadmap of ferroelectric memory should involve implementing MLC operation along with transitioning towards the advanced technology node.

# III. Conclusion

The performance of a neuromorphic system is the result of combined performance from device, circuit and algorithm. Therefore, the roadmap of ferroelectric memory is multifaceted, which involves finding the compatibility with advanced technology nodes, increasing the endurance and establishing MLC (Fig.2).
