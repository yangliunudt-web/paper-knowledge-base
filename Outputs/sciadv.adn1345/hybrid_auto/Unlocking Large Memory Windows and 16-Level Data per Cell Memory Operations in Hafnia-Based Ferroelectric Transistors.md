# M AT E R I A L S S C I E N C E

# Unlocking large memory windows and 16-level data per cell memory operations in hafnia-based ferroelectric transistors

Ik-Jyae Kim and Jang-Sik Lee*

Ferroelectric transistors based on hafnia-based ferroelectrics exhibit tremendous potential as next-generation memories owing to their high-speed operation and low power consumption. Nevertheless, these transistors face limitations in terms of memory window, which directly affects their ability to support multilevel characteristics in memory devices. Furthermore, the absence of an efficient operational technique capable of achieving multilevel characteristics has hindered their development. To address these challenges, we present a gate stack engineering method and an efficient operational approach for ferroelectric transistors to achieve 16-level data per cell operation. By using the suggested engineering method, we demonstrate the attainment of a substantial memory window of 10 V without increasing the device area. Additionally, we propose a displacement current control method, facilitating one-shot programming to the desired state. Remarkably, we suggest the compatibility of these proposed methods with three-dimensional (3D) structures. This study underscores the potential of ferroelectric transistors for next-generation 3D memory applications.

# INTRODUCTION

Hafnia-based ferroelectric materials have gained research interest owing to their complementary metal-oxide semiconductor (CMOS) compatibility, high scalability, low power consumption, and fast switching speed (1–7). Because of these advantages, ferroelectric transistors using hafnia-based ferroelectric materials are considered promising candidates for high-density three-dimensional (3D) memory devices, such as 3D NAND flash memory, because they can be deposited conformally on vertical structures using atomic layer deposition (ALD) (8–13). However, to achieve ferroelectric memories with high memory density, the memory window of ferroelectric transistors must be increased. The memory window of a ferroelectric transistor can be defined by the thickness and coercive electric field of the ferroelectric layer; thus, it is comparably smaller than those of conventional high-density memories such as 3D NAND flash memory (9–11, 14–16). In previous reports, diverse structures such as metal-ferroelectric-metal-insulator-semiconductor (MFMIS) gate stacks and double-gate structures were suggested; however, these methods usually require an increase in the device area, which increases the process complexity in high-density 3D memory applications (17–23). Therefore, it is essential to refine the device structure without increasing its footprint. Additionally, an optimized multilevel operation method for ferroelectric transistors needs to be developed. For now, the multilevel characteristics of ferroelectric transistors are usually demonstrated by using the incremental step-pulse programming (ISPP) method, which is used in conventional NAND flash memories (9, 21, 24–28). To realize multilevel characteristics using the ISPP method, voltage pulses with an increasing amplitude are applied to the device to tune the threshold voltage (Vth) of the device (24, 29–31). However, these methods are not optimized with the partial polarization switching characteristics of the ferroelectric layer; hence, the threshold voltage of the ferroelectric transistor shows a nonlinear relationship with increasing

pulse amplitudes (32). Thus, the development of a multilevel operation method that is optimized for ferroelectric transistors is required.

Here, we present an approach for achieving quadruple-level-cell (QLC) characteristics in oxide semiconductor-based ferroelectric thin-film transistors (FeTFTs) through gate stack engineering and optimized operation methods. By controlling the capacitance ratio using the thickness rather than the area of ferroelectric layers within the gate stack, we demonstrate the attainment of a large memory window of 10 V without the need to increase the device area. Additionally, we introduce a method termed displacement current control (DCC) for reliable, one-shot programming of ferroelectric transistors in QLC operations. This method is more efficient compared to current ISPP methods as it is tailored to the ferroelectric polarization switching phenomena. Our work elucidates the design strategy and multilevel operation method of ferroelectric transistors, offering the potential for high-density memory applications.

# RESULTS

# Gate stack engineering of MFMFS-structured FeTFT

FeTFTs with a metal-ferroelectric-metal-ferroelectric-semiconductor (MFMFS) gate stack structure were fabricated using a CMOScompatible process (fig. S1). TiN was used for the control gate (CG) and internal gate (IG). HfAlO layers with a thickness of 24 and 2 nm were used for ferroelectric gate-insulating layers over the CG and IG, respectively. Mo and InZnOx were used for source/drain electrodes and the channel, respectively. The ratio of the IG area (AMFS) to the CG area (AMFM) of 1 and 5 was fabricated (Fig. 1A). After the fabrication, the structure of the ferroelectric transistor with MFMFS gate stack was confirmed using the transmission and scanning electron microscope (TEM and SEM). By the cross-sectional TEM images, the MFMFS gate stack, which included a 100-nm-thick TiN CG, 24-nm-thick HfAlOx layer, 50-nm-thick TiN IG, 2-nm-thick HfAlOx layer, and 20-nm-thick InZnOx layer, was confirmed (fig. S2). Furthermore, to validate the formation of each layer, energy-dispersive x-ray spectroscopy (EDS) mapping was performed for Ti, N, Hf, Al, In, and Zn elements. The mapping results confirmed the correct

formation of each layer (fig. S3). The ferroelectricity of the HfAlOx layer was confirmed by measuring polarization-voltage (P-V) characteristics with a capacitor structure comprising TiN CG and IG. The 24-nm-thick $\mathrm { H f A l { \bar { O } } } _ { x }$ demonstrated positive and negative remnant polarizations of approximately $\pm 2 4 \mu \mathrm { C } / \mathrm { c m } ^ { 2 }$ , with a coercive voltage $( 2 V _ { \mathrm { c } } )$ of approximately 8.5 V (fig. S4).

In previous studies, the memory window of the ferroelectric transistor with an MFMIS gate stack was increased by controlling the area ratio between $A _ { \mathrm { M F M } }$ and $A _ { \mathrm { M F S } } \left( 2 0 , 2 1 \right)$ . Increasing $A _ { \mathrm { M F S } }$ can widen the memory window characteristics because it increases the amount of charge injection from the gate (20, 21). Thus, a large AMFS/AMFM ratio was used to achieve large memory windows in ferroelectric transistors with an MFMIS stack. However, a large AMFS value is disadvantageous in terms of the device area. Moreover, the demonstration of 3D ferroelectric NAND (FeNAND) with an MFMIS stack is challenging because a large AMFS/AMFM ratio is difficult to achieve in a confined 3D structure (21). Before investigating the electrical characteristics of gate stack-engineered devices, we initially investigated ferroelectric transistors with a metal-ferroelectricsemiconductor (MFS) gate stack (fig. S5). The ferroelectric transistor without an IG electrode exhibited n-type transfer characteristics with a memory window of approximately 2.5 V. While oxide semiconductor–based channels offer advantages for ferroelectric transistors in terms of endurance by suppressing the growth of unwanted interfacial layers between the ferroelectric layer and the channel, they tend to have small memory windows (10, 11, 13, 26, 28). This limitation originates from the small hole concentration of n-type oxide semiconductor materials, which restricts the effective application of an electric potential to the hafnia layer during erase operations (i.e., polarization switching). Additionally, the large bandgap of oxide semiconductor materials (>3 eV) results in a high holeinjection barrier through the source and drain terminals (33).

To address these challenges, our work proposes a gate stack engineering method aimed at improving the memory window of

ferroelectric transistors. To achieve the large memory window in a minimized device area $( \mathrm { i . e . , ~ } A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } } = 1 )$ , we investigated the effect of the capacitance ratio of the MFS region $( C _ { \mathrm { M F S } } )$ to the MFM region $\left( { \cal C } _ { \mathrm { M F M } } \right)$ on the memory window in ferroelectric transistors with an MFMFS gate stack. The effect of capacitance ratios on the memory window of ferroelectric transistors was investigated by fabricating ferroelectric transistors with different thicknesses of $\mathrm { H f A l O } _ { x }$ layers at an $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ ratio of 1 and 5. The thickness of the $\mathrm { H f A l O } _ { x }$ layer in the MFM region $( d _ { \mathrm { M F M } } )$ was kept to 24 nm, whereas that in the MFS region $\left( d _ { \mathrm { M F S } } \right)$ was changed from 2 to 16 nm. The transfer characteristic of the fabricated FeTFT was investigated by sweeping CG voltage $( V _ { \mathrm { C G } } )$ between −10 V and 10 V at a sourcedrain voltage $( V _ { \mathrm { D S } } )$ of $0 . 5 \mathrm { V } ,$ and memory windows were extracted by calculating the difference between the threshold voltages (Fig. 1B). Here, we applied $V _ { \mathrm { C G } }$ of 10 V to analyze the memory window that can be achieved in the ferroelectric transistor. The fabricated FeTFT exhibited n-type transfer characteristics with a memory window of 10 V when the $d _ { \mathrm { M F S } }$ of 2 nm and $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ of 1 were used (Fig. 1C). All ferroelectric transistors with different capacitance ratios showed anticlockwise hysteresis, which originated from the polarization switching of ferroelectric HfAlOx (fig. S6). When $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ was 1, the memory window decreased when the $d _ { \mathrm { M F S } }$ increased. With $d _ { \mathrm { M F S } }$ of 2 nm, 10 V of memory window was observed, but when $d _ { \mathrm { M F S } }$ was increased to 16 nm, the memory window of the ferroelectric transistor was decreased to 3.8 V. Compared with the case when $A _ { \mathrm { M F S } } / A$ MFM was 1, only a small change in the memory window was observed when $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ was 5. To determine the cause of the memory window changes with different capacitance ratios, the relationship between $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ and the memory window was investigated. As the capacitance can be calculated using $C = \varepsilon _ { 0 } \varepsilon _ { \mathrm { r } } A / d$ (where C, ε0, $\varepsilon _ { \mathrm { { r } } } ,$ A, and d denote capacitance, the permittivity of vacuum, relative dielectric constant, area, and thickness, respectively), the capacitance ratio $( C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } } )$ can be calculated as follows.

When $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ increased to about 15, a marked increase in the memory window was observed. However, a small increase in the memory window was observed when $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ was larger than 15. The reason for this is that as the higher capacitance ratio of the ferroelectric layer in the MFM region is used, polarization switching occurs more prominently but saturates after a certain level. Therefore, to achieve a large memory window with a minimized device area, adjusting the appropriate area and capacitance ratio is essential.

The electrical characteristics and working mechanism of the MFMFS-structured FeTFT were confirmed using the technology computer-aided design (TCAD) tool (Fig.  2A). To confirm the working mechanism, first, the MFMFS-structured FeTFT was simulated with the same dimension that was used for the experiments. Both $\mathrm { H f A l O } _ { x }$ layers inserted in the MFM and MFS regions were considered as the ferroelectric layer. In the simulated device, the distribution of electrostatic potential in the MFMFS gate stack during program operation was investigated (Fig.  2B). With increasing $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } } ,$ the potential drop in the ferroelectric layer in the MFM region was increased. The relationship between the potential drop in the ferroelectric layer and $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ was similar to that between the memory window and $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ , which can be considered as the mechanism of memory window enhancement in the MFMFS gate stack with the designed $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ (Fig. 2C). The increase in

switched polarization correlated with ratios of $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } } ,$ thereby confirming the enhancement of the memory window (Fig. 2D).

The MFMFS gate stack proposed in this work also shows advantages in terms of device scaling compared with conventional MFMIS gate stack structures. To compare the electrical characteristics of the MFMFS and MFMIS structures, ferroelectric transistors with both gate stack structures were simulated (fig. S7A). The electrostatic potential drop in the MFM region was lower in the MFMIS gate stack structure than in the MFMFS gate stack structure. Owing to the difference in the electrostatic potential drop in the gate stacks, the electric field induced to the MFM and MFS (MIS) gate stacks showed different values. In particular, achieving polarization switching in the ferroelectric layer was more challenging within the MFMIS structure compared to the MFMFS structure (fig. S7B). Thus, considerably higher $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ was required for the MFMIS gate stack to achieve sufficient polarization switching in the MFMIS gate stack compared with the MFMFS gate stack. The electric field induced to the MIS gate stack in the MFMIS structure was larger than that in the MFMFS gate stack structure (fig. S7C). It is expected that this phenomenon arises from differences in the band structure between the MFMIS and MFMFS structures. In the proposed strategy, there could be an issue with leakage current flowing through the MFS region due to the utilization of a very thin layer of $\mathrm { H f A l O } _ { x } .$ To analyze the leakage properties, the leakage current density of the 2-nm $\mathrm { H f A l O } _ { x }$ layer was measured (fig.  S8). Given that the maximum electric field induced to the MFS-HfAlOx system is anticipated to be below 3 MV/cm (fig. S7C), the $\mathrm { H f A l O } _ { x }$ layer demonstrated a stable leakage current density across the range of −2 to 2 V, without experiencing any breakdown. This leakage current characteristic of the 2-nm-thick HfAlOx layer is found to be comparable to that of $\mathrm { H f O } _ { 2 } ,$ commonly used in the current transistor fabrication process (13).

Here, it is noted that the operation mechanism can be affected by the presence of ferroelectricity of the $\mathrm { H f A l O } _ { x }$ layer in the MFS region. The details about the ferroelectric properties and their effect on the operational mechanism will be further investigated.

As a result, the MFMFS gate stack can attain good scalability without experiencing substantial degradation from leakage currents, making it advantageous for integration into 3D structures. The proposed gate-stack engineering method offers benefits for 3D FeNAND applications. Achieving a large area ratio in 3D FeNAND applications poses challenges with the conventional gate-stack engineering method, as it involves controlling the area ratio within confined structures (20, 21). However, the MFMFS gate stack with an area ratio of 1 can be used in 3D FeNAND applications without escalating process complexity or necessitating structural alterations, as it does not rely on a large channel area. In this proposed design, the capacitance ratio between the MFM and MFS regions is regulated by adjusting the thickness of the $\mathrm { H f A l O } _ { x }$ layer in each region, facilitating a substantial memory window within a minimized device footprint.

# Multilevel operation methods for FeTFTs

As the memory window of the fabricated device is similar to or larger than those of conventional memories such as NAND flash memory, the multilevel characteristics comparable to those of conventional memories can be achieved. The multilevel characteristics of the ferroelectric transistor were initially explored using the ISPP method, commonly used in NAND flash memories (24, 25, 34). In the ISPP method, programming voltage pulses with an increasing amplitude are applied to the gate of the device (24). After the application of programming voltage pulses, read operations are performed to identify the states of the device (fig. S9A). To use the ISPP method in the fabricated ferroelectric transistor, program voltages from 4 to 6.1 V with an increment of 0.15 V were applied to the $\mathrm { C G } ,$ and the threshold voltage was confirmed by sweeping $V _ { \mathrm { C G } }$ after applying each program voltage. The threshold voltage was shifted to a negative direction when the voltage amplitude was increased, showing that the ferroelectric transistor could be programmed to multilevel states using the ISPP method (fig.  S9B). Each state of the ferroelectric transistor was distinguishable, which implied that the fabricated ferroelectric transistor could show multilevel characteristics with 16 states $( \mathrm { i . e . } ,$ , QLC operation) using the ISPP method. However, the threshold voltage of the ferroelectric transistor shows a nonlinear relationship with an increasing pulse amplitude because the polarization switching of ferroelectric materials mostly occurs near the coercive electric field (32). Hence, there is a need to develop a multilevel operational method that is optimized for the polarization switching mechanism in ferroelectric transistors.

Although the use of the ISPP method can achieve QLC characteristics in ferroelectric transistors, the threshold voltage change is not linear owing to the nonlinear change in polarization near the coercive electric field. Thus, to achieve reliable QLC characteristics using the ISPP method, driver circuits with ultrahigh resolution are needed, which can complicate the array and circuit designs. To achieve linear threshold voltage change, we suggest the DCC method for ferroelectric transistors. In principle, intermediate polarization states can be achieved by adjusting the ratio of domains with upward and downward polarization states (35–37). Thus, intermediate polarization states with the desired polarization value should be achieved through precise control of the amplitude or width of

voltage pulses, which is challenging in high-density memory applications (32, 38, 39). In the DCC method, we can limit the current flowing through the CG and IG generated by the polarization switching to control the amount of polarization change (Fig. 3A) (37). To limit the current flow through the CG and IG, we applied a compliance current at the IG, which can limit the polarization switching of the $\mathrm { H f A l O } _ { x }$ layer between the IG and the CG (Fig. 3B). To confirm the multilevel operation method using compliance current, the effect of compliance currents on the polarization switching characteristics of ${ \mathrm { \ddot { H f A l O } } } _ { x }$ layer and threshold voltage tuning characteristics of ferroelectric transistors were investigated. In a capacitor structure composed of $\mathrm { \Delta T G / H f A l O _ { \it x } / C G }$ , polarization switching characteristics under different compliance currents were observed by applying compliance currents with varying amplitudes ranging from 0.6 to 4 μA and a width of 10 ms to the IG. Concurrently, a program pulse with an amplitude of 6.1 V and a width of 10 μs was applied to the CG. By controlling the compliance current (i.e., displacement current limit), linear polarization switching can be achieved (fig. S10). Furthermore, observations of program characteristics under different compliance currents showed that the change of threshold voltage is controlled, even when program pulses with long durations were applied (Fig. 3C). When a large compliance current (4 μA) was applied to the IG, the polarization switching was not suppressed and the threshold voltage of the FeTFT was changed to that of erased state. However, when the compliance current was decreased, the change of threshold voltage was limited even when program pulses with long durations were applied, which confirmed that the polarization switching was limited by the compliance current. These findings demonstrate that the DCC method can control the threshold voltage by the compliance current, eliminating the need

for fine-tuning of pulse amplitudes and/or widths as required in the ISPP method. The displacement current limit was changed from 0.6 to 4 μA to achieve multilevel characteristics with 16 states. The programming voltage was applied to the CG, and its amplitude was kept at 6.1 V. The device was erased before applying each programming pulse with a different displacement current limit. The amplitude of the programming voltage does not need to be changed because the amount of switched polarization is controlled by the displacement current limit, which is applied to the IG (Fig. 3D). The device could be programmed to 16 distinct states with different threshold voltages by controlling the displacement current limit (Fig.  3E). The uniformity of threshold voltages was also investigated for 20 QLC programming cycles (Fig. 3F). Each state was distinguishable, which showed the reliability of QLC operation in the suggested DCC method. Compared with the ISPP method, the DCC method can be realized with a single programming voltage pulse. The ISPP method requires multiple programming voltages with different amplitudes to achieve a specific threshold voltage (24, 25). For the DCC method, a single programming bias pulse is needed because the threshold voltage is controlled by the displacement current limits (37).

With the DCC method, a memory cell can be programmed by implementing a single program operation (i.e., one-shot programming); thereby, it is possible to increase the operation speed of ferroelectric transistors. For the ISPP method, the specific threshold voltage is achieved by applying programming voltages with incremental voltage amplitudes (Fig. 4). After the programming voltages are applied, the program verification operation should be done to identify the threshold voltage of the ferroelectric transistor and update the amplitude of programming voltage pulses (25). Compared with the ISPP method, one-shot programming to a specific threshold

voltage can be achieved without applying multiple pulses in the DCC method. As the displacement current limit can define the amount of switched polarization, a single programming pulse with a designed displacement current limit for a specific polarization state is required. Thus, when the DCC method is used for multilevel programming of ferroelectric transistors, fast programming operation with a small distribution can be achieved, which is also beneficial for next-generation memory devices with high memory density and neuromorphic applications (40–44). Here, it should be noted that displacement current limit was applied as a form of compliance current, but in real cases, other circuit components such as bipolar junction transistor (BJT) or n- or p-MOS can be used to limit the current flowing through the IG and CG (37). When using the BJT, the application of a base current to the BJT can restrict the current flowing through IG and CG. The magnitude of the base current can then regulate the displacement current limit.

To investigate the reliability of the DCC method, data retention and endurance characteristics were investigated. To characterize the data retention of each level, multiple verification processes were used (14). Initially, a $V _ { \mathrm { r e a d } }$ of 0.1 V was applied to determine the first bit. Subsequently, for the “1xxx” and “0xxx” groups, $V _ { \mathrm { r e a d } }$ values of −2.8 and 2.8 V were applied to determine the second bit, respectively. Finally, $V _ { \mathrm { r e a d } }$ values $\bar { \mathrm { o f } } - 3 . 5 , - 0 . 5 , 2$ , and 4.5 V were applied to “11xx,” “10xx,” $^ { \alpha } 0 1 x x _ { 3 } ^ { \prime \prime }$ and $^ { \mathfrak { \omega } } 0 0 x x ^ { \mathfrak { \gamma } }$ to determine the third and final bits, respectively. Using the multiple verification process, which is commonly used in commercialized memory devices, all 16 levels were distinguishable for ${ { 1 0 } ^ { 4 } } \ s$ (fig. S11). Also, the endurance characteristics of the ferroelectric transistor were investigated using four different memory states “0000,” “0010,” “1000,” and “1111.” All four states were distinguishable for 106  cycles, without breakdown (fig. S12).

# Implementation in the 3D FeNAND structure

Although the MFMIS structure with a large $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ is challenging to be implemented in the 3D structure due to its confined and limited area, the capacitance ratio–engineered MFMFS structure proposed in this work can be implemented into the 3D structure.

The single string of 3D FeNAND with an MFMFS-structured ferroelectric memory cell can be fabricated using the conventional gate replacement process of the 3D NAND flash memory (Fig. 5A) (45– 48). For the simulation, first, the MFMFS-structured FeTFT was simulated with the same dimension that was used for the experiments, and the ferroelectric parameters were used from the experimental P-V curve of the ferroelectric capacitor. For the 3D FeNAND simulation, we simulated the structure of 3D FeNAND by the following steps. First, 80-nm-thick sacrificial nitride and 20-nm-thick oxide layers are sequentially deposited on the p-type (100) Si substrate, in which n-well, p-well, and source were formed by implantation of phosphorus of $\dot { 1 0 } ^ { 1 3 } \mathrm { c m } ^ { - 3 }$ , boron of $1 0 ^ { 1 3 } \mathrm { c m } ^ { - 3 }$ , and arsenic of $1 0 ^ { 1 6 } \mathrm { c m } ^ { - 3 }$ , respectively. Then, a channel hole was etched and a ferroelectric layer was deposited. A 20-nm-thick oxide semiconductor channel was deposited inside the channel hole, and the channel hole was filled with $\mathrm { S i O } _ { 2 } .$ Sacrificial nitrides were removed, and the IG was conformally deposited inside the etched area. Finally, an additional ferroelectric gate insulator and the CG are deposited. The proposed process was similar to that of 3D charge-trap flash NAND with a gate replacement process. The gate replacement process can form the 3D FeNAND with MFMFS-structured ferroelectric memory cells. The advantage of the suggested 3D structure is its ability to achieve MFMFS structure in confined areas. When the $d _ { \mathrm { M F M } }$ is fixed and the dMFS decreases, there will be no change in the resulting $A _ { \mathrm { M F S } } / A _ { \mathrm { M F M } }$ value, but the corresponding $C _ { \mathrm { M F S } } / C _ { \mathrm { M F M } }$ ratio can be increased (Fig. 5B). In this 3D structure, it should be noted that the geometrical design of the staircases and/or the sidewall thickness can also affect the capacitance in MFM and MFS regions, which should be considered for designing the 3D FeNAND. The memory window of 3D FeNAND with the MFMFS-structured memory cell with $d _ { \mathrm { M F M } }$ of 24 nm and $d _ { \mathrm { M F S } }$ of 2 nm was investigated. The memory window of the MFMFS-structured memory cell in 3D FeNAND was 7 V (Fig. 5C). These results show that the gate stack engineering method suggested in this work is also viable for 3D structures. The DCC method can be used to achieve uniform multilevel characteristics in the suggested 3D structure (fig.  S13). After the cells are

formed, a staircase etching process can be implemented to form contacts for each IG and CG. The IG contacts can be connected to the BJT or n- or p-MOS inside the peripheral circuits, limiting the current flowing through the IG and CG (Fig. 5D) (37). Exploring alternative structures for 3D FeNAND with MFMFS-structured memory cells could enhance the capacitance ratio in confined spaces. Consequently, leveraging the proposed fabrication method for 3D FeNAND with MFMFS-structured ferroelectric memory cells and integrating the DCC method can enable high-density 3D FeNAND with QLC operations.

# DISCUSSION

Here, we present a gate stack engineering method for ferroelectric transistors aimed at achieving a sizable memory window without enlarging the device area. We demonstrate that manipulating the capacitance ratio between the gate stack layers by varying the thickness of two ferroelectric layers, rather than altering the area ratio, can result in a substantial memory window of 10 V without increasing the device footprint. We also provide the design guideline of the capacitance ratio for ferroelectric transistors with large memory windows. Using the fabricated device, we demonstrate the DCC method for the QLC operation, which is based on limiting the amount of switched polarization. The ferroelectric transistor can be programmed to the desired state by using one-shot programming with the DCC method, which can be used for more efficient, faster, and reliable multilevel operations. Finally, we show that the gate stack engineering method and multilevel operation method (DCC) can be used in the 3D FeNAND structure. The suggested gate stack design strategy and multilevel operation method enable multilevel data storage in ferroelectric transistors for high-density memory applications.

# MATERIALS AND METHODS

# Materials

$\mathrm { H f [ N ( C _ { 2 } H _ { 5 } ) C H _ { 3 } ] _ { 4 } }$ [tetrakis(ethylmethylamido)hafnium (TEMAH)] and Al(CH3)3 [trimethylaluminum (TMA)] were purchased from UP Chemical, Korea. $\mathrm { C _ { 1 0 } H _ { 2 8 } N S i _ { 2 } I n _ { 4 } }$ [bis(trimethylsilyl)amidodiethyl indium (INCA-1)] and ${ \mathrm { Z n } } ( { \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 5 } ) _ { 2 }$ [diethylzinc (DEZ)] were purchased from iChems, Korea. Si wafers with 100-nm-thick thermally grown $\mathrm { S i O } _ { 2 }$ were used as substrates.

# Device fabrication

The devices were fabricated on the $\mathrm { S i O } _ { 2 } / \mathrm { S i }$ substrate. The photolithography was done using a mask aligner (MDA-400LJ, Midas System). For the fabrication of ferroelectric transistors, a 100-nm-thick TiN CG was deposited using the DC sputtering. The TiN CG was patterned using a lift-off method. Then, 24-nm-thick HfAlOx film was deposited on $\mathrm { T i N } / \mathrm { S i O } _ { 2 } / \mathrm { S i }$ using TEMAH, TMA, and $\mathrm { O } _ { 3 }$ as the Hf precursor, Al precursor, and oxygen source, respectively. During the deposition of $\mathrm { H f A l O } _ { x } ,$ the ALD cycle ratio for $\mathrm { H f O } _ { 2 }$ and ${ \mathrm { A l } } _ { 2 } { \mathrm { O } } _ { 3 }$ was 25:1. Next, 50-nm-thick TiN IG and $\mathrm { H f A l O } _ { x }$ layer with various thicknesses (2 to 16 nm) were deposited using DC sputtering and ALD, respectively. Mo source and drain electrodes were deposited using the electron beam evaporator. A 20-nm-thick IZO film was deposited at 150°C using INCA-1, DEZ, and ozone as the indium precursor, zinc precursor, and oxygen source, respectively. The IZO layer was patterned using a combination of lithography and wet

etching. The channel length and width were 10 and 100 μm, respectively. Then, the devices were annealed at 900°C for 1 min in an $\Nu _ { 2 }$ environment.

# Characterizations

All electrical properties were measured under ambient conditions and at room temperature. The cross-sectional TEM images and EDS mapping results of the devices were obtained using a high-resolution TEM (JEM-2200FS with image Cs corrector, JEOL). Before TEM observations, the samples were prepared using a focused ion beam (SII SMI3050SE, SII). The top-view SEM images were obtained using a SEM (JSM-7800F Prime, JEOL). The electrical characteristics were measured using a semiconductor parameter analyzer (4200A-SCS, Keithley Instruments) and a pulse measurement unit (4225- PMU, Keithley Instruments). Sentaurus TCAD (Synopsys Inc.) software was used for the simulation.
