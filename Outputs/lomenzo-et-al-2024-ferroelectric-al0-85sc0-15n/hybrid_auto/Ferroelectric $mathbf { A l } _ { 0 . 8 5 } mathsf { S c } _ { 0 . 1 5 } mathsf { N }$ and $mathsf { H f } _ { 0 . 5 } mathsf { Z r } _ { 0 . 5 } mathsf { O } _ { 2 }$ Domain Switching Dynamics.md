ABSTRACT: The capability to reliably program partial polarization states with nanosecond programming speed and femtojoule energies per bit in ferroelectrics makes them an ideal candidate to realize multibit memory elements for high-density crossbar arrays, which could enable neural network models with a large number of parameters at the edge. However, a thorough understanding of the domain switching dynamics involved in the polarization reversal is required to achieve full control of the multibit capability. Transient current integration measurements are adopted to investigate the domain dynamics in aluminum scandium nitride $( \mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } )$ and hafnium

zirconium oxide $\left( \mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } \right)$ . The switching dynamics are correlated to the crystal structure of the films. The contributions of domain nucleation and domain wall motion are decoupled by analyzing the rate of change of the time-dependent normalized switched polarization. Thermally activated creep domain wall motion characterizes the $\bar { \mathrm { A l } } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ switching dynamics. The statistics of independently nucleating domains and the domain wall creep motion in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ are associated with the spatially inhomogeneous distribution of local switching field due to polymorphism, absence of preferential crystallite orientation, as well as defects and charges that can be located at the grain boundaries. The c-axis texture, single-phase nature, and strong likelihood of less fabrication process-induced defects contribute to the homogeneity of the local switching field in $\begin{array} { r } { \mathbb { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } . } \end{array}$ . Nonetheless, defects generated and redistributed upon bipolar electric field switching cycling result in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { \bar { S } c _ { 0 . 1 5 } N }$ domain wall pinning. The wake-up effect in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ is explained thorough the continuous addition of switchable regions associated with two independent distributions of characteristic switching times.

KEYWORDS: ferroelectrics, switching kinetics, domain nucleation, domain wall motion, aluminum scandium nitride, hafnium zirconium oxide

# 1. INTRODUCTION

The growing computing workloads and expanding functionalities of the Internet of Things (IoT) is increasing demand for edge intelligence, which will facilitate the ability to make decisions autonomously based on collected data at the edge in real time.1 Edge intelligence requires implementing efficient neural network (NN) models locally at the data collection point to overcome the unsustainable latency and power consumption associated with data exchange between IoT devices and the cloud.1 Executing NN models on large sets of data with high energy efficiency while maintaining high throughput requires shifting from the classical von Neumann architecture to the in-memory computing paradigm, in which the necessary vector−matrix multiplication operations for each NN layer are performed directly in a crossbar subarray of memory elements that map the NN weights. −3

Static random-access memory (SRAM) is the commercial foundry available charge-based technology to store the weights of the NN models at the most advanced technology node.1,3 However, the inherently volatile nature, relatively large cell layout area, support of only single-bit storage per cell, and poor

standby energy efficiency of SRAM technology introduce performance limitations for standby-frequent applications such as IoT.1,3 Alternative memory technologies which can combine nonvolatility, high-density integration, and fast and low-energy programming with advanced complementary metal−oxide− semiconductor processing compatibility are under investigation to meet the requirements of edge intelligence.1,3,4

Among emerging memory technologies, ferroelectrics are an ideal candidate for realizing NN memory elements because of the intrinsic nonvolatile property of the polarization and the nanosecond programming potential with femtojoule energies per bit.1,2,4,5 The breakthrough discoveries of ferroelectricity in fluorite- and wurtzite-structured ferroelectrics open up opportunities for integrating ferroelectric functionalities with

scaled logic transistors beyond the 130 nm technology node limit of perovskite-structured ferroelectrics.2,4,6 The capability of ferroelectrics to achieve partial polarization states draws significant attention because this can allow the storage of multiple bits in a single memory element.1,4−9 Multibit storage would result in higher crossbar integration density compared to SRAM, thus facilitating NN models with a large number of parameters at the edge where the chip area is limited.1,3

The field-driven configurations of ferroelectric domains and dynamics control the number of achievable partial polarization states and can affect data storage reliability as well as the speed of the state update.2,6−10 Hence, a thorough understanding of the domain switching dynamics involved in the polarization reversal mechanism is required to achieve full control of the multibit capability and understand reliability performances, such as the retention of the intermediate polarization states. In ferroelectrics, polarization reversal relies on the complex interplay between domain nucleation and domain wall motion.6,11−15 Several phenomenological theories have been developed to predict the time-dependent evolution of the switched polarization.15−18 Nonetheless, phenomenological theories do not account explicitly for the correlation between domain dynamics and the crystal structure of the film. Understanding the influence of the crystal structure on the switching kinetics in thin films is crucial for applicationoriented material optimization toward a large number of reliable partial polarization states programmable at high speed with limited device-to-device variability.2,6,14,19 Given the significant crystallographic differences between wurtzite- and fluorite-structured ferroelectrics, the comparison of these two material systems can provide important insights in under-

standing the influence of the material crystal structure on the domain dynamics.

In this work, transient current integration measurements are adopted to investigate the time-dependent normalized switched polarization by applying voltage pulses with increasing width for different applied electric field magnitudes. From these measurements the domain switching dynamics in two of the most technologically relevant ferroelectric solid solution thin films, namely aluminum scandium nitride $\left( \mathrm { A l } _ { 1 - x } \mathrm { S c } _ { x } \mathrm { N } , \right.$ , with $\begin{array} { l } { x } \end{array} \approx \begin{array} { l } { 0 . 1 5 } \end{array}$ in this work) and hafnium zirconium oxide $\left( \mathrm { H f } _ { 1 - x } \mathrm { Z r } _ { x } \mathrm { O } _ { 2 } , \right.$ with $x \approx 0 . 5$ in this work), are compared in terms of domain nucleation and domain wall motion contributions where the results are correlated to the crystal structure of the films. The relative contributions of domain nucleation and domain wall motion are decoupled by analyzing the rate of change of the time-dependent normalized switched polarization.

The ferroelectric properties, such as coercive field and saturated polarization, have been shown to possibly vary upon electric field cycling in both wurtzite- and fluorite-structured ferroelectrics.20−26 The domain dynamics in both $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ can change upon bipolar electric field cycling, for instance, due to defects generated and redistributed by the electric field-driven polarization switching process.20,21 The variation in domain dynamics upon bipolar electric field switching cycling is undesirable for multibit memories that must be programmed several times and would require the implementation of program-verify schemes to ensure the memory state is programmed correctly.3 Thus, in this study, the variation in domain dynamics upon bipolar electric field

switching cycling is studied in both $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { \bar { O } } _ { 2 }$ films.

The present investigation on ferroelectric domain dynamics provides a basis to understand the effects that influence the polarization reversal process in wurtzite- and fluoritestructured ferroelectric thin films, which is of the utmost importance for controlling the multibit property in these materials and enabling high-density crossbar arrays for edge intelligence.

# 2. RESULTS AND DISCUSSION

2.1. Kinetics of Polarization Reversal. The complex extrinsic nature of the ferroelectric switching process involving domain nucleation and domain wall motion is widely accepted.6,11−15 The switching kinetics in ferroelectrics are determined by the relative contributions of domain nucleation and domain wall motion. When unrestricted sideways expansion of ferroelectric domains can be achieved after nucleation, the time-dependent normalized switched polarization follows the Kolmogorov−Avrami−Ishibashi (KAI) model16

For both KAI and NLS models, n = 2 is usually assumed considering a significantly faster forward domain growth compared to the sideways domain wall propagation in both wurtzite- and fluorite-structured ferroelectric thin films.12,13

The pre-cycling step was performed to compare $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ when they can both reach a saturated polarization value close to the maximum achievable for each ferroelectric material. As discussed in Subsection 2.4, the saturated polarization in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ increases upon electric field cycling. The number of cycles in the pre-cycling step for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ was chosen as a trade-off between the saturation polarization achieved and the capacitor endurance. On the other hand, the saturation polarization reaches its maximum in the very first switching cycle for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ . However, 30 pre-switching cycles were performed to remove the initial built-in bias field in the capacitor stack.20 A similarly higher number of pre-switching cycles like for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ could not be performed due to the limited endurance of the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ capacitors.

The KAI and NLS models adequately represent the timedependent normalized switched polarization in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ respectively. In $\bar { \mathrm { A l } } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } ,$ , full polarization reversal can be induced for all applied electric field magnitudes in the time window investigated, as shown in Figure 1a. The complete polarization reversal with sufficient time independently on the applied electric field magnitude in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ agrees with the assumption of unrestricted domain growth in the KAI model. In contrast to $\begin{array} { r } { { \cal A } \mathrm { l } _ { 0 . 8 5 } { \cal S } \mathrm { c } _ { 0 . 1 5 } { \mathrm { N } } , } \end{array}$ , sideways domain wall motion is limited in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ and the polarization reversal process is controlled by the statistics of independently nucleating domains.13 Below 2.6 MV $\mathrm { c m } ^ { - 1 } .$ , a dependence of the maximum amount of switched polarization on the applied electric field magnitude emerges from Figure 1b for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ for pulse widths up to 40 s. Instead, more than 90% of polarization reversal is achieved in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ for electric field magnitudes above $2 . 6 ~ \mathrm { M V ~ c m ^ { - 1 } }$ when the electric field is applied for shorter pulse widths than 40 s. Hence, the number of regions contributing to the polarization reversal increases with the applied electric field magnitudes. However, the limited sideways domain expansion in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ may not hold for large applied electric field magnitudes, as discussed in Subsection 2.2.

Considering the electric field magnitude of 3 MV $\mathrm { c m } ^ { - 1 } ,$ , it emerges that ferroelectric switching is orders of magnitude faster in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ compared to $\mathrm { \bar { A l } } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ . Nonetheless, the comparison of the switching kinetics at this electric field magnitude corresponds to a more than three times higher applied electric field to coercive field ratio for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ with respect to $\begin{array} { r } { \mathbb { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } , } \end{array}$ , when one extracts the coercive field from positive-up−negative-down measurements (Section S2, Supporting Information). Hence, comparably faster ferroelectric switching in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ could be achieved by increasing the magnitude of the electric field applied to the film. On the other hand, the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film thickness must be scaled down to reduce the programming energy when such large electric field magnitudes are applied. Thus, a significantly thinner $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film which can withstand larger applied electric field magnitudes compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ would be required for fast and low-energy programming applications.

Additional differences in the domain dynamics between ferroelectric $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ thin films emerge when comparing the rate of change of $\Delta P _ { \mathrm { n o r m } } ,$ shown in Figure 1c for $\mathrm { A } \bar { \mathrm { l } } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and Figure 1d (and Figure S5) for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ A mathematical overview on the rate of change of the time-dependent normalized switched polarization for both

KAI and NLS models is presented in Section S3 of the Supporting Information.

In $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ only a rigid shift of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ along the time axis toward shorter time scales is observed upon increasing the applied electric field magnitude, whereas both the maximum rate of change of $\Delta P _ { \mathrm { n o r m } }$ and the full-width at half-maximum remain constant. The full-width at half-maximum of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ equals 0.53 for all investigated electric field magnitudes. For the KAI model, the abscissa of the maximum rate of change of $\Delta P _ { \mathrm { n o r m } }$ corresponds to the characteristic switching time whereas the Avrami exponent influences the maximum rate of change of $\Delta P _ { \mathrm { n o r m } }$ and full-width at half-maximum (Figure S3). Both an increase in maximum value and a narrowing of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ would be observed if the Avrami exponent for the KAI model increases. As reported by Yazawa et al.,15 the increase in the Avrami exponent beyond 4 defies physical interpretation based on the KAI model and would actually correspond to the simultaneous occurrence of domain nucleation and domain wall motion. Thus, the invariant maximum rate of change of $\Delta P _ { \mathrm { n o r m } }$ and full-width at halfmaximum in Figure 1c imply a constant domain nucleation contribution to the switching kinetics among all studied electric field magnitudes. The rigid shift of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ toward shorter time scales, and hence the reduction in characteristic switching time for the KAI model with increasing applied electric field magnitudes, reflects the progressively faster domain wall motion in $\begin{array} { r } { \mathbb { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } . } \end{array}$ However, we note that the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ time-dependent normalized switched polarization was not measured for applied electric field magnitudes above the coercive field due to limitations in the electrical setup. Therefore, the reported conclusion of constant domain nucleation contribution to the switching kinetics is valid for the electric field magnitudes applied in this study but likely does not hold for applied electric field magnitudes above the coercive field. The simultaneous occurrence of domain wall motion and domain nucleation, whose contribution would increase proportionally to the applied electric field magnitude, is expected in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ when larger electric field magnitudes than the coercive field are applied.15

In the investigated electric field range for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ the maximum rate of change of $\Delta P _ { \mathrm { n o r m } }$ increases upon increasing the applied electric field magnitude, meaning that ferroelectric switching becomes progressively more abrupt. The rate of change of $\Delta P _ { \mathrm { n o r m } }$ for $\mathrm { \bar { H f } } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ mirrors the Lorentzian distribution of the logarithm of the characteristic switching times (Section S3, Supporting Information). Increasing the applied electric field magnitude, both a reduction in central value of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ and a reduction in halfwidth at half-maximum are observed. The central value of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ corresponds to the mean logarithm of the characteristic switching time. Hence, increasing the applied electric field magnitude, the polarization reversal process becomes progressively faster. The decrease in half-width at half-maximum corresponds to a more homogeneous distribution of characteristic switching times, implying that the number of domain nucleation events occurring closer in time increases with the applied electric field magnitudes.

Despite the implication of restricted domain growth coming from the NLS model, it was proposed by first-principle

calculations that domain wall motion is feasible in fluoritestructured ferroelectrics.30 Quantification of the domain wall velocity in fluorite-structured ferroelectrics by piezoresponse force microscopy (PFM) was also reported.13,14 For instance, a domain wall velocity in the order 0.1 m $\mathbf { s } ^ { - 1 }$ was measured by PFM for a 4 MV $\mathrm { c m } ^ { - 1 }$ electric field applied on a 10 nm thick polycrystalline lanthanum-doped hafnium oxide film.13 Buragohain et al.14 reported on the convergence of NLS and KAI model fits of the time-dependent normalized switched polarization for both epitaxial and polycrystalline yttriumdoped hafnium oxide ferroelectric thin films when sufficiently large electric field magnitudes were applied.

It is reasonable to assume that when a sufficiently large electric field magnitude is applied, the restricted domain growth hypothesis of the NLS model does not hold anymore, and lateral domain wall propagation can occur in fluoritestructured ferroelectrics. According to this hypothesis, under sufficiently large electric field magnitudes, ferroelectric switching in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ should get faster with increasing applied electric field magnitudes without the distribution of characteristic switching times becoming narrower. We note that this hypothesis is consistent with the first formulation of the NLS theory by Tagantsev et al.17 because, similarly to the effect of the macroscopic domain wall motion in the KAI model, the local fluctuations in domain dynamics reflected in the halfwidth at half-maximum of the Lorentzian distribution of the logarithm of characteristic switching times should average out when large electric field magnitudes are applied.

switching times in Figure 1d averages about $0 . 2 6 \pm 0 . 0 7$ when electric field magnitudes above 2.6 MV $\mathrm { c m } ^ { - 1 }$ are applied (shaded region in Figure 2b). The inverse of the characteristic switching time associated with the mean value of the Lorentzian distribution for the NLS model in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ 2 follows the dependence on the applied electric field magnitude expected for domain wall motion in the creep regime (shaded region in Figure 2c). Hence, in the studied electric field range domain wall motion can be described in the creep regime for both $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ (from 3.0 to 5.0 MV cm−1 ) and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ (from 2.6 to 4.2 MV cm−1 ) thin films, and no clear transition to the flow regime (i.e., domain wall velocity is linearly proportional to the applied electric field magnitude) is observed as opposed to PZT.27

Domain wall motion in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ can be compared using the linear fits in Figures 2a and 2c. The intercept α of the linear fit is correlated to the intrinsic limit of domain wall motion. In ferroelectrics the domain wall velocity is limited by the speed of sound in the material.11 In this regard, $\alpha _ { \mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N } } / \alpha _ { \mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } } \approx 1 . 7$ agrees with the longitudinal speed of sound ratio obtained using literature values for $ { \mathrm { A l } _ { 0 . 8 5 } }  { \mathrm { S c } _ { 0 . 1 5 } }  { \mathrm { N } }$ (≈10132 m $\mathbf { s } ^ { - 1 } )$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ (≈5984 m $\mathbf { s } ^ { - 1 } ) . ^ { 3 1 , 3 2 }$ Despite the intrinsically faster domain wall motion achievable in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ the effective activation field in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ is 1 order of magnitude larger than that in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ Because of the macroscopic nature of the transient current integration measurements from which the effective activation field for domain wall motion is extracted, the larger $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ activation field is suggestive of a lower mobility and/or density of domain walls in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } . \mathrm { ~ A ~ }$ lower mobility and/ or density of domain walls in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to

$\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ could be related to the different applied electric field to coercive field ratio at which the effective activation field is extracted. However, the lower irreversible Rayleigh coefficient in wurtzite- compared to fluorite-structured ferroelectrics suggests that mobility and/or density of domain walls are/is intrinsically different for films that belong to these two material classes.22,33

A unitary dynamical exponent is extracted for both $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \hat { \mathrm { O } } _ { 2 }$ fits in Figures 2a and ${ 2 \mathsf { c } } ,$ similarly to previous reports for PZT in which it was explained by disorder-induced pinning of the domain walls.27,28 Creep domain wall motion with unitary dynamical exponent implies strong stability of the ferroelectric domains due to the exponentially decreasing domain wall velocity when the applied electric field magnitude approaches zero.28 Consequently, both $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\bar { \mathrm { H f _ { 0 . 5 } } } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ are suitable ferroelectric thin films to store multiple distinct polarization states steadily over time. From an application perspective, the retention of the intermediate polarization states is crucial to avoid drift in the stored NN weights.2 Due to the larger effective activation field, intermediate polarization states have likely longer retention times in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f _ { 0 . 5 } Z r _ { 0 . 5 } } \bar { \mathrm { O _ { 2 } } }$ but require longer times to be programmed under an equivalent applied electric field.

2.3. Role of Film Crystal Structure on Domain Dynamics. Domain nucleation and domain wall motion directly imply transformations in the crystal structure of the ferroelectric material. Therefore, the material crystal structure can influence the local switching field by facilitating, slowing down or even impeding the domain nucleation and domain wall motion processes involved in the polarization reversal mechanism. Polymorphism, namely the presence of multiple crystallographic phases associated with the same chemical formula, is a likely source of disorder in fluorite-structured ferroelectrics.6 Polymorphs with different relative permittivity can coexist even within single grains in fluorite-structured polycrystalline thin films due to the low activation barriers for phase transition s.6,34,35 The crystallographic phases in fluoritestructured polycrystalline thin films are mainly categorized as tetragonal (space group P42/nmc), orthorhombic (space group Pca21, Pbca, etc.), monoclinic (space group $P 2 _ { \mathrm { 1 } } / c ) _ { \mathrm { \downarrow } }$ , and cubic (space group Fm-3m) phases.6 Among these crystallographic structures, the polar orthorhombic phase (space group Pca21) is widely accepted as the origin of ferroelectric switching in polycrystalline thin films, whereas the other phases are centrosymmetric and therefore nonpolar.6,34−36 The phase distribution in the fluorite-structured ferroelectric thin films influences the volume fraction of switchable material as well as the domain dynamics in terms of both domain nucleation and domain wall motion. Local changes in the relative permittivity associated with the local phase composition may result in variations in the local switching field distribution. Domain wall pinning can be influenced by some interphase boundaries, which are likely immobile due to geometric constraints imposed by electrodes and/or neighboring grains.34

Grazing incident X-ray diffraction (GIXRD) reveals the coexistence of polar orthorhombic and small monoclinic phase fractions in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ (Figure 3b). Nonetheless, the presence of tetragonal phase regions in the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ film cannot be excluded from Figure 3b. Electron backscatter diffraction (EBSD) confirmed the existence of regions with the monoclinic phase in the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ film, although the EBSD pattern quality was not sufficient to distinguish the minor

atomic displacement differences between tetragonal and orthorhombic phases (experimental Kikuchi patterns are reported in Section S4, Supporting Information). The presence of different crystallographic phases, some of which are nonpolar, in $\mathrm { H f _ { 0 . 5 } Z r _ { 0 . 5 } O _ { 2 } }$ contributes to explain the limited domain expansion. On the other hand, the single-phase nature of the wurtzite-type hexagonal structure (space group $P 6 _ { 3 } m c )$ can be evinced from XRD for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ (Figure 3a). Thus, the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film should not contain any nonpolar phase that can impede the sideways domain wall propagation after nucleation, and the complete polarization reversal can be achieved even for applied electric fields below the measured coercive field by applying the electric field for a sufficient time.

A spatially inhomogeneous distribution in the local switching field can originate from inhomogeneity in the film texture, ultimately resulting in device-to-device variability.6 The film texture can be accounted for by using pole figures. The $ { \mathrm { A l } _ { 0 . 8 5 } }  { \mathrm { S c } _ { 0 . 1 5 } }  { \mathrm { N } }$ film shows c-axis texture with no preferential crystallite orientation in-plane (Figure 3c). Since the electric field is applied in the out-of-plane direction of the film growth, the distribution of characteristic switching times among the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ domains is expected to be extremely narrow. In contrast, pole figures for the tetragonal/orthorhombic phase in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ show absence of texture with randomly distributed crystallite orientations (Figure 3d). Therefore, the absence of texture along the direction of the applied electric field in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ is expected to be one of the contributing factors for the appearance of a broader distribution of characteristic switching times compared to $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ . Indeed, Kim et al.37 reported on the much narrower local electric field distribution in $\mathrm { A l } _ { 0 . 7 } \mathrm { S c } _ { 0 . 3 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ .

We note that even if not discussed explicitly in the present analysis, grain boundaries represent another possible source of domain wall pinning and, hence, domain wall creep motion. PFM studies showed that ferroelectric domains in fluorite- and wurtzite-structured thin films encounter several grain boundaries during their sideways expansion and that larger lateral domain wall velocities can be achieved by increasing the grain size in fluorite-structured ferroelectric s.12−14 The character of the grain boundary, and hence the crystalline regularity between neighboring grains, affects the way in which domain walls move.38 In contrast to $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ in which the grains have a similar crystallite orientation along the direction of the applied field, the different crystallite orientations between neighboring $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ grains may significantly slow down or even impede the domain wall motion for subcoercive applied electric field magnitudes. Moreover, grain boundaries can act as domain wall pinning centers because they may host large concentrations of defects and charges which can alter the local electric field distribution.6,21 Nonetheless, the initial defect concentration between wurtzite- and fluorite-structured ferroelectrics may be different. Defects such as oxygen vacancies can already exist in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ after the fabrication of the capacitor structure. The titanium nitride top electrode tends to scavenge oxygen from the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ film during top electrode deposition and post-metallization annealing steps, strongly impacting both oxygen vacancies content and crystallographic phase formation within the film. 21,39 Defects can also originate from the elastic interactions during the postmetallization annealing step, which was performed above the Curie temperature of $\mathrm { H f _ { 1 - x } } \mathrm { Z r } _ { x } \mathrm { O } _ { 2 } ( \approx 4 6 0 \mathrm { ^ { \circ } C ) } . \mathrm { ^ { 3 5 } }$ On the other hand, the $\hat { \mathrm { A l } } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film in this investigation is grown below the Curie temperature (>600 °C) without any subsequent

annealing after deposition.40 Thus, an initially lower defect concentration is expected in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ .

In the present study, scaling the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ thickness down to 10 nm, like for the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ film, was not possible due to endurance limitations for the capacitors embedding such a thinner $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film. However, the different thicknesses between the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ films must be considered regarding the influence of the crystal structure on domain dynamics. Thinner films usually possess smaller grain sizes, larger residual stresses, and greater defect concentrations which can slow down the mobility of the domain walls compared to the case of thicker films.41 Since a larger effective activation field for domain wall motion was extracted for 30 nm thick $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to 10 nm thick $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ the low mobility and/or density of domain walls in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ should persist while scaling the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ thickness. On the other hand, it cannot be excluded that the NLS model may become more appropriate than the KAI model to describe the $ { \mathrm { A l } _ { 0 . 8 5 } }  { \mathrm { S c } _ { 0 . 1 5 } }  { \mathrm { N } }$ domain dynamics when the film thickness is scaled down to 10 nm.

2.4. Influence of Bipolar Electric Field Switching Cycling on Domain Dynamics. Increasing the number of pre-switching cycles from 30 to 500 causes a slope decrease in the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ time-dependent normalized switched polarization curve as well as fatigue (Figure 4a). The fatigue effect

corresponds to the reduction in saturated polarization of the film, which can be caused by an excessive energetically costly ferroelectric domain nucleation and/or domain wall motion for the applied electric field due to charge trapping by defects.21

The time-dependent normalized switched polarization after 500 pre-switching cycles was unable to be adequately fit solely using the KAI or NLS model (Figure S7). The slope decrease upon cycling for $\Delta P _ { \mathrm { n o r m } }$ cannot be described in the framework of the simultaneous non-linear nucleation and growth model, which extends the KAI model to account for large abruptness in the time-dependent normalized switched polarization.15 Actually, a discrepancy between the KAI model fit and the time-dependent normalized switched polarization is observable after 30 pre-switching cycles for pulse widths shorter than ≈60 μs (Figure S8).

The change in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ domain dynamics can be studied through the rate of change of $\Delta P _ { \mathrm { n o r m } }$ because the mechanism responsible for the observed switched polarization behavior reflects in a slope variation. The rate of change of $\Delta P _ { \mathrm { n o r m } }$ is analyzed by considering the contributions from inhomogeneous domain nucleation with limited domain growth (NLS contribution) and unrestricted sideways domain wall motion (KAI contribution). From the cumulative fit of rate of change of $\Delta P _ { \mathrm { n o r m } }$ obtained by the linear superposition of the NLS and KAI contributions (Section S6, Supporting Information), the time-dependent normalized switched polarization in Figure 4a

can be adequately represented after both 30 and 500 preswitching cycles.

Coherently with the KAI model fit reported in Figure 1a, the NLS contribution is relatively small compared to the KAI contribution after 30 cycles (Figure 4b); thus, the switching process mainly proceeds through unrestricted sideways domain expansion. The area ratio between the two contributions in the time range of the fit $\left( { A _ { \mathrm { K A I } } } / { A _ { \mathrm { N L S } } } \right)$ decreases by a factor of 3 when $\mathrm { A l } _ { 0 . 8 5 } ^ { - } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ is pre-cycled 500 times (Figure 4c). The larger NLS contribution upon bipolar electric field switching cycling for shorter pulse widths indicates a restricted domain growth when the electric field is applied for such short times. Increasing the number of bipolar electric field switching cycles during the pre-cycling step can generate a greater defect concentration in the film.20 Coherently with the expected increasing defect concentration in the film upon bipolar electric field switching cycling, the leakage current is found to increase after 500 pre-switching cycles compared to 30 preswitching cycles (Section S7, Supporting Information). The generated defects would act as domain wall pinning centers and reduce the domain wall mobility. However, when the electric field is applied for sufficiently long times, the domain wall pinning effect can be overcome, and the KAI contribution emerges. Hence, the transition between a more NLS to a more KAI regime with pulse width is likely to be ascribed to the energy required for domain wall movement due to domain wall pinning. Nonetheless, a fatigue effect is observed because, for the electric field magnitude applied, some domain walls may experience an excessive pinning due to the generated and redistributed defects.20,23

Nevertheless, the macroscopic nature of the transient current integration measurements performed in this study only allows one to consider an average collective behavior of the domain dynamics across the capacitor area. The existence of distinct $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ regions that switch according to the NLS model, while other regions of the film follow the KAI model, cannot be excluded by the available experimental evidence up to this point. To investigate the existence of separate regions in the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film that follows the NLS or KAI model, the time-dependent normalized switched polarization was studied starting from four distinct preswitched polarization states up to 64% of the saturation polarization value in the absence of fatigue. A larger $A _ { \mathrm { K A I } } / A _ { \mathrm { N L S } }$ would be expected upon increasing the fraction of pre-switched polarization if some $ { \mathrm { A l } _ { 0 . 8 5 } }  { \mathrm { S c } _ { 0 . 1 5 } }  { \mathrm { N } }$ film regions switch through NLS behavior whereas other regions follow the KAI model, since the NLS contribution precedes the KAI contribution in time. From the cumulative fit of the rate of change of $\Delta P _ { \mathrm { n o r m } } ,$ the time-dependent normalized switched polarization in Figure 4a can be adequately represented for all pre-switched polarization states investigated. The cumulative fit of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ is shown in Figure 4d−g for all preswitched polarization states. The linear superposition of the NLS and KAI contributions accounts for the fraction of polarization switchable after pre-switching since fewer $\mathrm { \bar { A l } _ { 0 . 8 5 } S c _ { 0 . 1 5 } N }$ regions participate to the polarization reversal with increasing pre-switched polarization magnitude (Section S6, Supporting Information). Figure 4c−g shows that the NLS contribution precedes the KAI contribution in time and the ratio between the KAI and NLS contributions remains independent of the fraction of the pre-switched polarization $( \mathrm { i . e . , \ } A _ { \mathrm { K A I } } / A _ { \mathrm { N L S } } \approx 2 . 6 )$ . Therefore, the existence of distinct $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ regions that switch according to the NLS model,

while other regions of the film follow the KAI model, is unlikely. Instead, the switching process is dominated by the sideways domain wall motion, which is limited when the electric field is applied for short times and becomes unrestricted for longer pulse widths. The ratio between the KAI and NLS contributions is hence a measure of the degree of domain wall pinning: a larger $A _ { \mathrm { K A I } } / A _ { \mathrm { N L S } }$ relates to a lower pinning effect. Since the defect concentration in the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film is not altered by the amount of pre-switched polarization of the capacitor but only by the number of switching cycles, $A _ { \mathrm { K A I } } / A _ { \mathrm { N L S } }$ is constant among Figure 4c−g. From an application perspective toward multibit storage, the invariant domain dynamics in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ with the amount of pre-switched polarization is encouraging since it implies an easier and more uniform control on the update of the memory state.

In $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } ,$ a continuous increase in the saturated polarization, namely wake-up effect, is observed in the timedependent normalized switched polarization by increasing the number of pre-switching cycles from 10 to 105 (Figure 4h) as well as from positive-up−negative-down (PUND) measurements upon bipolar electric field switching cycling (Section S8, Supporting Information).

The cumulative fit of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ (Figure $4 \mathrm { i - m } )$ is used to analyze the change in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ domain dynamics upon bipolar electric field switching cycling. The rate of change of $\Delta P _ { \mathrm { n o r m } }$ was unable to be adequately fit solely using the NLS model when more than $1 0 ^ { 3 }$ pre-switching cycles were performed. For instance, the single NLS model fit does not allow to properly follow the variation of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ around its maximum or when the normalized switched polarization gets close to the saturation value (Figure S11). The linear superposition of NLS and KAI contributions was also proven to be inadequate to capture all the features of the rate of change of $\Delta P _ { \mathrm { n o r m } }$ (Figure S12). On the other hand, a linear superposition of two NLS contributions (NLS and NLS2) is a suitable approach to fit the rate of change of $\Delta P _ { \mathrm { n o r m } }$ (Figure 4i−m) and the time-dependent normalized switched polarization (Figure 4h).

The area obtained summing those of the two NLS contributions in Figure 4i−m increases with the number of pre-switching cycles; thus, the wake-up effect consists in the progressive increase of the number of regions participating to the polarization reversal. After $1 0 ^ { 5 }$ bipolar electric field switching cycles, the remnant polarization is found to be ≈25 $\mu \mathrm { C } \mathrm { c m } ^ { - 2 }$ (Figure S10e), which is close to the value expected for the polar orthorhombic phase in the presence of randomly distributed crystallite orientations.42

The area of the ${ \mathrm { N L S } } _ { 1 }$ contribution is found to increase until $1 0 ^ { 3 }$ pre-switching cycles are applied, whereas the ${ \mathrm { N L S } } _ { 2 }$ contribution appears after $1 0 ^ { 2 }$ pre-switching cycles and its area continuously increases upon bipolar electric field switching cycling. The area ratio between the two NLS contributions in the time range of the fit $\left( { \cal A } _ { \mathrm { N L S 2 } } / { \cal A } _ { \mathrm { N L S 1 } } \right)$ is also found to increase upon bipolar electric field switching cycling. The appearance of a NLS contribution with a longer characteristic switching time compared to the ${ \mathrm { N L S } } _ { 1 }$ contribution, and the $A _ { \mathrm { N L S 2 } } / A _ { \mathrm { N L S 1 } }$ increase, are consistent with the coercive field increase (Figure S10a) or switching current peak shift toward longer times (Figure $\mathrm { S 1 0 c , d ) }$ observed in the PUND measurements upon bipolar electric field switching cycling. Nonetheless, we note that a double switching current peak cannot be observed during the PUND measurements

because the full-width at half-maximum of the switching current peak is a few microseconds long and, therefore, too wide to capture the ≈300 ns characteristic switching time difference between the two NLS contributions.

The increasing number of $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ regions contributing to the polarization reversal process can be explained through the movement of defects and/or charges within the film that can facilitate the ferroelectric switching in some domains, ferroelastic switching $( \mathrm { i . e . , }$ , translation of $9 0 ^ { \circ }$ to $1 8 0 ^ { \circ }$ domain walls), and/or phase transformations, likely accompanied by strain relaxations .13,21,24−26,34,43−46 The existence of two independent distributions of characteristic switching times relates to the local coercive field of the switchable $\mathrm { H f _ { 0 . 5 } Z r _ { 0 . 5 } O _ { 2 } }$ regions, with a larger local coercive field for the domains involved in the $\mathrm { N L } \bar { S } _ { 2 }$ contribution. Switching domains would get involved in the NLS1 or ${ \mathrm { N L S } } _ { 2 }$ contribution according to local conditions for polarization reversal, such as microstrain, phase composition, crystallographic orientation, and/or defect concentration, all of which could influence the pinning potential. The stronger local constraints and pinning potential for polarization reversal would define the later characteristic switching time of the ${ \mathrm { N L S } } _ { 2 }$ domains. $1 0 ^ { 4 }$ pre-switching cycles are needed to clearly identify the ${ \mathrm { N L S } } _ { 2 }$ contribution in the rate of change of $\Delta P _ { \mathrm { n o r m } } ,$ suggesting that these domains require a larger amount of energy to be provided through the applied electric field to contribute to the switched polarization compared to the NLS1 domains, which is suggestive of microstructural changes likely facilitated by electromigration of charged defects, such as oxygen vacancies, under the electric field-driven polarization switching.

# 3. CONCLUSION

Domain dynamics in wurtzite- and fluorite-structured ferroelectric thin films were compared using $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ as respective representatives of the two material classes. Thermally activated creep domain wall motion characterizes the domain dynamics in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ for all studied electric field magnitudes $( \leq 5 . 0 \ \mathrm { M V \ c m ^ { - 1 } ) }$ . In contrast, the kinetics of polarization reversal in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ involves the statistics of independently nucleating domains.

For applied electric field magnitudes above 2.6 MV $\mathrm { c m } ^ { - 1 } ,$ , domain wall motion in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ can be described in the creep regime. The unitary dynamical exponent for the creep regime in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ suggests that both wurtzite- and fluorite-structured ferroelectric thin films are suitable to store multiple distinct polarization states steadily over time. The larger effective activation field in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f _ { 0 . 5 } Z r _ { 0 . 5 } O _ { 2 } }$ implies that intermediate polarization states have likely longer retention times in the wurtzitecompared to fluorite-structured thin films but require longer times to be programmed under an equivalent applied electric field. Thus, the requirements in terms of thickness scaling and breakdown field are much more stringent for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ compared to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ for applications relying on fast and low-energy programming.

The statistics of independently nucleating domains and the domain wall creep motion in ferroelectric $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ thin films are associated with the spatially inhomogeneous distribution in local switching field due to a combination of likely factors including polymorphism, absence of preferential crystallite orientation, as well as defects and charges that can be located at the grain boundaries. Instead, the c-axis texture, single-phase nature, and strong likelihood of less fabrication

process-induced defects mitigate the local switching field inhomogeneity in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ in comparison to $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ .

The present investigation shows that the contributions coming from inhomogeneous domain nucleation with limited domain growth and unrestricted sideways domain wall motion can be decoupled by analyzing the rate of change of the timedependent normalized switched polarization. Using this approach, it is shown that defects generated and redistributed upon bipolar electric field switching cycling increase the degree of domain wall pinning in $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and that the wake-up effect in $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ relates to the evolution of two independent distributions of characteristic switching times associated with the continuously increasing number of domains that contribute to the polarization reversal process.

Finally, by illustrating the applicability of the cumulative fit of the rate of change to predict the time-dependent normalized switched polarization starting from distinct pre-switched polarization states, our findings can lead to new strategies to control the field-driven domain configurations and their dynamics, which govern the multibit property of ferroelectrics.

# 4. METHODS

4.1. Sample Fabrication. The ferroelectric capacitor stacks were deposited on p-type silicon substrates. The fabrication of $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ capacitors started with depositing 55 nm thick titanium and 3 nm thick tungsten films as the bottom electrode by direct current sputtering at room temperature. A 30 nm thick $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ film was then deposited by radio frequency co-sputtering from aluminum and scandium targets at ${ 3 0 0 ~ ^ { \circ } C }$ using a 2:1 nitrogen to argon flow rate ratio with a pressure of 0.7 μbar. A 25 nm thick titanium nitride film was deposited by direct current sputtering at room temperature as the top electrode.

To fabricate the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ capacitors, 30 nm thick tungsten and 10 nm thick titanium nitride films were deposited by direct current sputtering at room temperature as the bottom electrode. A 10 nm thick $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ was deposited by atomic layer deposition (ALD) at 280 $^ \circ \mathrm { C }$ using $\mathrm { C p - Z r [ N ( C H _ { 3 } ) _ { 2 } ] _ { 3 } }$ and $\mathrm { C p - H f [ N ( \bar { C H } _ { 3 } ) _ { 2 } ] _ { 3 } }$ as metal− organic precursors with a 1:1 cycle ratio and ozone as oxidizing agent. The $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ was deposited using an Oxford Instruments OpAL ALD tool. A 10 nm thick titanium nitride film was deposited by direct current sputtering at room temperature as the top electrode. All sputtering processes were performed in an ultra-high vacuum sputter cluster tool from Bestec GmbH without breaking the vacuum condition between consecutive depositions. The post-metallization annealing step used to crystallize the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ film was performed in a nitrogen atmosphere at 500 °C for 20 s using an AS-Master 2000 rapid thermal processing tool from Annealsys.

A lithographic step (Heidelberg Instruments $\mu \mathrm { P G }$ 101 laser lithography tool), followed by deposition of 10 nm thick titanium and platinum (20 nm thick for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ capacitors and 40 nm thick for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ capacitors) films by electron-beam evaporation (Bestec GmbH tool), lift-off in acetone and ultrasonic bath, and inductively coupled plasma etching (Plasmalab System133 from Oxford Instruments) were performed to structure the capacitors.

4.2. Characterization. Electrical measurements were performed using Keithley 4225 pulse measurement units controlled with a Keithley 4200A-SCS parameter analyzer at room temperature on a Cascade Microtech probe station. Voltage pulses were applied to the top electrode while the bottom electrode was grounded in all measurements. The contact to the bottom electrode was achieved thorough electrical breakdown of one capacitor. The pre-cycling step was performed by applying a voltage signal consisting of ±4 V square pulses at a frequency of 10 kHz to the $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ capacitors or ±17 V square pulses at a frequency of 15.6 kHz to the $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ capacitors. A different capacitor was tested for each transient current integration measurement sequence. Before starting the transient current integration measurement sequence, a negative voltage pulse

with the same characteristics of the pre-cycling step pulses was applied to program the capacitor in the initial polarization state. In all figures, spontaneous polarization used to normalize the switched polarization was 130 $\mu \mathrm { C } \mathrm { \bar { c m } } ^ { - 2 }$ for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ and $2 3 \ \mu \mathrm { C } \ \mathrm { c m } ^ { - 2 }$ for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 } .$ .

XRD measurements were performed with copper X-ray source operated at 40 mA and 40 kV in a D8 Discover diffractometer from Bruker Corporation. The symmetric θ−2θ XRD scan was performed inserting a 2-bounce germanium (220) monochromator at the incident side with a nickel filter (optic thickness of 0.012 mm) and 0.2° Soller slit at the detector side. GIXRD scans were performed with 0.2° slit placed at the incident side and a 0.2° Soller slit at the detector one. The incidence angle in GIXRD was fixed to 0.45°. Both symmetric θ−2θ XRD and GIXRD scans were performed with step of 0.05° and integration time of 10 s per step. Indexing of the Bragg reflections was done using the powder diffraction file cards from the international center for diffraction data (00-025-1133 for AlN, 00- 044-1294 for Ti, 00-038-1420 for TiN, and 00-004-0806 for W) and the simulated-XRD spectra by Kersch et al.47 for hafnium oxide crystal phases.

EBSD was performed on the bare ferroelectric film surface in a ZEISS LEO 1560 scanning electron microscope equipped with a Symmetry S2 detector from Oxford Instruments. The beam aperture was fixed to 60 $\mu \mathrm { m } ,$ and the acceleration voltage was 8 kV for $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ and 6 kV for $\mathrm { A l } _ { 0 . 8 5 } \mathrm { S c } _ { 0 . 1 5 } \mathrm { N }$ . Pole figures were generated using the software AZtec from Oxford Instruments.
