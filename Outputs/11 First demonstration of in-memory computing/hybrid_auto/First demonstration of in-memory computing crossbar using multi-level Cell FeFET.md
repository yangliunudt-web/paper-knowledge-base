This work demonstrates the first in-memory computing crossbar using multi-level cell FeFETs, enabling vector-matrix multiplication operations with multi-bit precision. The 1FeFET-1R cell structure achieves hand-written digit recognition with 96.6% accuracy and an energy efficiency of 885.4 TOPS/W."
