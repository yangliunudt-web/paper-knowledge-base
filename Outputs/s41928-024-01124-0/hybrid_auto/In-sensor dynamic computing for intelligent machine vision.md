# In-sensor dynamic computing for intelligent machine vision

Received: 20 July 2022

Accepted: 16 January 2024

Published online: 8 February 2024

Check for updates

Yuekun Yang  1,4, Chen Pan2,4, Yixiang Li  1,4, Xingjian Yangdong1 , Pengfei Wang  1 , Zhu-An Li1 , Shuang Wang1 , Wentao Yu2 , Guanyu Liu3 , Bin Cheng  2 , Zengfeng Di  3 , Shi-Jun Liang  1 & Feng Miao  1

Accurate detection and tracking of targets in low-light and complex scenarios is essential for the development of intelligent machine vision. However, such capabilities are difcult to achieve using conventional static optoelectronic convolutional processing. Here we show that in-sensor dynamic computing can be used for accurate detection and robust tracking of dim targets. The approach uses multiple-terminal mixed-dimensional graphene–germanium heterostructure device arrays and relies on the dynamic correlation of adjacent optoelectronic devices in the array. The photoresponse of the devices can range from positive to negative depending on the drain–source voltage polarity and can be further tailored using the back-gate and top-gate voltage. The correlation characteristic of the device array can be used to selectively amplify small diferences in light intensity and to accurately extract edge features of dim targets. We show that the approach can provide robust tracking of dim targets in complex environments.

The detection and tracking of dim targets in complex environments relies on the accurate extraction of key features such as edges and corners1 . Traditional image sensors, which are based on complementary metal–oxide–semiconductor (CMOS) technology, cannot directly extract key edge features of dim targets because these optoelectronic devices are operated independently and therefore cannot capture the spatial correlation characteristics of edge features. This limits their potential application in intelligent machine vision applications (such as precise guidance, intelligent surveillance or early warning)2,3 , which can require accurate processing and robust tracking and recognition of dim targets in situations where the contrast between the target and the background varies.

Intelligent machine vision applications4–11 therefore require alternative computing technologies that replace the standard static optoelectronic convolutional processing implemented in the sensor12–15. Dynamic computing can, in particular, be implemented at the sensor level by introducing dynamic correlation between

optoelectronic devices in the array. Dim target features can then be extracted from the spatially correlated optical information. To generate dynamic correlation between optoelectronic devices in response to light stimuli, new low-dimensional materials are required16–20, and interfacing bulk materials with such two-dimensional materials can allow artificial materials to be designed with electrical transport and optoelectronic properties that are not available in conventional bulk materials21–28.

In this Article, we report in-sensor dynamic computing for intelligent machine vision. To implement dynamic computing at the sensor level, we use multiple-terminal mixed-dimensional graphene– germanium (graphene–Ge) heterostructure device arrays. We show that the approach can provide precise extraction of dim target edge features, allowing it to track targets with high recognition accuracy across contrast-varying images. We demonstrate that our in-sensor dynamic computing is more robust than conventional optoelectronic convolutional approaches.

# In-sensor dynamic computing

Figure 1 schematically illustrates the physical process of implementing in-sensor dynamic computing with an image sensor. The approach allows the extraction of edge features from an ultralow-contrast visual scene (indicated by the red rectangular in Fig. 1a). This is critical for robust tracking and recognition of target in contrast-varying visual environments. We design an optoelectronic device array such that adjacent devices are correlated to each other and thus can respond to the spatial light pattern. Figure 1b shows a dynamic kernel implementation where a sensor array includes two types of optoelectronic devices, which are labelled $\mathsf { D } _ { \mathsf { P } i }$ and $\mathbf { D _ { A } }$ , respectively. $\mathbf { D } _ { \mathsf { P } i }$ represents passive devices, which only respond to the local light intensity. The active optoelectronic device $\mathsf { D } _ { \mathsf { A } }$ is arranged at the centre of the dynamic kernel (see the top of Fig. 1b) and responds to both local and the surrounding light intensities as its optoelectronic output is correlated to the electrical output from the surrounding passive devices.

Figure 1c illustrates the full analogue domain operation of the corresponding physical process of the in-sensor dynamic computing. The eight passive devices situated at the periphery of the kernel detect local light intensities and generate corresponding electrical signal outputs. The resulting electrical outputs from the passive devices simultaneously and dynamically modulate the photoresponse characteristic of the $\mathsf { D } _ { \mathsf { A } }$ device. The electrical output from the $\mathsf { D } _ { \mathsf { A } }$ device is a correlation of both the local and the surrounding light intensities. Finally, the electrical outputs of all nine optoelectronic devices in the kernel are summed, resulting in a processed result of the input visual information. In this way, in-sensor dynamic computing can selectively amplify the minor difference between the local and surrounding light intensity, allowing for robust edge extraction from a dim target. In contrast, conventional optoelectronic convolutional processing currently deployed at the sensor level is operated in staticly, which is challenging for robust feature extraction from a dim target.

# Device photoresponse

We use multiple-terminal mixed-dimensional graphene–Ge heterostructure optoelectronic devices with top- and bottom-gate architecture to implement the in-sensor dynamic computing. Figure 2a

shows the schematic of a four-terminal heterostructure device, in which graphene and hexagonal boron nitride (h-BN) as well as graphite flakes were vertically transferred onto a pre-patterned germanium on silicon oxide insulator (GeOI). Top and bottom gates were fabricated by using graphite and bottom-doped silicon, respectively. Ti–Au form the device metal contacts of the source and drain electrodes. The corresponding optical image of the fabricated device is shown in Fig. 2b; additional details on device fabrication and material characterization are provided in Methods and Supplementary Figs. 1 and 2.

We carry out the measurement of drain–source current $( I _ { \mathrm { D S } } )$ versus drain–source voltage $( V _ { \mathrm { D S } } )$ characteristics of the device with and without the light illumination, and the corresponding results are shown in Fig. 2c,d. Under the dark condition, the device exhibits rectifying behaviour (as indicated by the black solid line), suggesting the existence of a Schottky barrier at the graphene and Ge interfac ${ \pmb { \alpha } } ^ { 2 9 - 3 1 }$ . When light illuminates the device, we observe a shift in the $I _ { \mathrm { D S } } - V _ { \mathrm { D S } }$ characteristic curve, consistent with a typical photodiode behaviour. The resulting non-zero open-circuit voltage and short-circuit current confirm that the dominant mechanism of the graphene–Ge heterostructure device arises from the photovoltaic effect. The polarity of the rectifying photodiode can be changed by varying the polarity of $V _ { \mathrm { D S } }$ (ref. 32), as shown in Fig. 2c,d. We then use the photocurrent $( I _ { \mathrm { p h } } )$ to characterize the photoresponse of the device, which is defined as the difference in device current under light illumination $( I _ { \mathrm { l i g h t } } )$ and under the dark condition $( I _ { \mathrm { d a r k } } ) { : } I _ { \mathrm { p h } } = I _ { \mathrm { l i g h t } } - I _ { \mathrm { d a r k } } . I _ { \mathrm { p h } }$ is negative when the device is biased with a negative $V _ { \mathrm { D S } } \left( \mathrm { F i g } . 2 \mathrm { c } \right)$ , while the $I _ { \mathrm { p h } }$ becomes positive when a positive $V _ { \mathrm { D S } }$ is applied to the device (Fig. 2d). For a given $V _ { \mathrm { D S } } ,$ the measured photocurrent of the device linearly increases with the light intensity $( P )$ , as shown in the inset of Fig. 2e. Note that the offset observed in the photocurrent arises from the experimental measurement error associated with the light intensity; however, it does not affect the proof-of-concept demonstration of our work. We also note that the photoresponse is fast and can be extended to near-infrared wavelengths (Supplementary Figs. 3 and 4).

The photoresponse of the device can be tailored by using the back-gate voltage $( V _ { \mathrm { B G } } )$ . As shown in Fig. $2 \mathrm { f , g . }$ Varying the back-gate voltage $V _ { \mathrm { B G } }$ from −30 V to 30 V leads to a gradual suppression of the

photocurrent for a fixed light intensity, which is a suitable response characteristic for the passive device of the dynamic kernel shown in Fig. 1. The back-gate dependence of the photocurrent in the device can be attributed to a shift in the Fermi level of the Ge and an induced increase of the Schottky barrier height at the interface between the graphene and the Ge. The photoresponse of the device can also be modulated by the top gate, since applying a top-gate voltage changes the Fermi level of the graphene and the Schottky barrier. Figure 2h shows the photocurrent mapping with respect to both back-gate and top-gate voltages. For a fixed back-gate voltage $V _ { \mathrm { B G } }$ and negative $V _ { \mathrm { D S } } ,$ we show that the $I _ { \mathrm { p h } }$ is negative and can increases when the top-gate voltage $( V _ { \mathrm { T G } } )$ is varied from −5 V to 5 V. This indicates that the photoresponsivity (R), which is defined as $R = I _ { \mathrm { p h } } / P$ of the active device, is

gate-tunable. This characteristic is ideal for the active device of the dynamic kernel (Fig. 1).

To realize the correlation between the passive devices and the active device, the electrical output from the passive devices is coupled to the top-gate terminal of the active device. The photocurrent output of the active device is thus determined by both the local light intensity and the surrounding light intensity illuminating the passive devices. The light intensity sensed by the passive devices dynamically adjusts the photoelectric response characteristics of the active device. In this sense, the $V _ { \mathrm { T G } }$ is the correlation between local and surrounding light intensity and can be tuned to selectively amplify minor local differences in the light intensity. Figure 2i shows photocurrent mapping of the active device with respect to $V _ { \mathrm { T G } }$ and the local light intensity

illuminating the active device. The local light intensity dependence of the photocurrent from the active device can be dynamically changed by the top-gate voltage. The tunable photoresponse characteristics of the mixed-dimensional graphene–Ge heterostructure make it ideal for implementing in-sensor dynamic computing.

# In-sensor dynamic computing

We experimentally implement one-dimensional in-sensor dynamic computing by utilizing the correlation characteristics between the passive and active devices. Figure 3a shows the circuit diagram used to implement one-dimensional in-sensor dynamic computing, in which three graphene–Ge heterostructure photodiode devices (labelled as $\mathrm { D } _ { \mathrm { P 1 } } , \mathrm { D } _ { \mathrm { A } }$ and $\Gamma _ { \mathrm { P } 2 } ,$ respectively) are used. The circuit is operated as follows. When the light falls on the passive devices $ { \mathbf { D } } _ {  { \mathbb { P } } 1 }$ and $\mathsf { D } _ { \mathsf { P } 2 } ,$ , voltage signal outputs are generated by connecting $ { \mathbf { D } } _ {  { \mathbb { P } } 1 }$ and $\mathsf { D } _ { \mathsf { P } 2 }$ to respective load transistors. The voltage signals are further amplified to be

$V _ { \mathsf { P 1 } }$ and $V _ { \mathsf { P } 2 }$ via amplifiers (A) to drive the functional circuits of the differentiator and threshold trigger. The differentiator circuit, includes three MOSFETs (M1, M2 and M3) and is used to calculate the absolute difference $V _ { \mathrm { G } - 1 2 }$ between signals $V _ { \mathsf { P 1 } }$ and $V _ { \mathsf { P } 2 } .$ . The signal $V _ { \mathrm { G } - 1 2 }$ is then fed into the inverter and compared with the preset threshold signal. The voltage signal output from the inverter can dynamically modulate the photoresponse characteristics o $\mathbf { \dot { D } _ { A } }$ A according to specific algorithms. When $V _ { \mathrm { G } \cdot 1 2 }$ exceeds the threshold, the output voltage signal $V _ { \mathrm { H } }$ of the functional circuit is applied to the top-gate terminal $V _ { \mathrm { T G - A } }$ of the active pixel $\mathsf { D } _ { \mathsf { A } }$ and its photocurrent output is changed. Otherwise, $V _ { \mathrm { { L } } }$ is applied to the top-gate terminal of $\mathsf { D } _ { \mathsf { A } }$ and its original photocurrent output is kept unchanged. Finally, the photocurrent outputs from the three devices are summed up, forming the processed results of the three adjacent pixel values.

Figure 3b demonstrates the processed results of three different groups of light intensity patterns by using one-dimensional in-sensor dynamic computing. For the proof-of-concept demonstration, the passive devices $\mathsf { D } _ { \mathsf { P 1 } }$ and $ { \mathbf { D } } _ {  { \mathsf { P } } 2 }$ are biased with a power supply voltage of $V _ { \mathrm { d d } } = 1$ V at the graphene terminal and $V _ { \mathrm { B G \cdot P } } { = } 0 \nu$ , while the active device $\mathsf { D } _ { \mathsf { A } }$ is biased with $V _ { \mathrm { D \cdot A } } = - 0 . 5 1$ V at the Ge terminal and $V _ { \mathrm { B G \cdot A } } = - 1 5 \mathrm { V } .$ Based on this voltage configuration, the initial photoresponsivity of $\mathrm { \Delta D } _ { \mathsf { P 1 } } , \mathsf { D } _ { \mathsf { P 2 } }$ and $\mathbf { D _ { A } }$ shows a ratio of 1:1:−2. We show that the total photocurrent output is equal to zero when the light intensity that is sensed at each passive device is identical. We note that the photocurrent output can be amplified to 18.4 nA by correlating the two passive devices to $\mathsf { D } _ { \mathsf { A } } ,$ although the intensity of the light illuminating each of the passive devices is small. This indicates that correlating active and passive devices can be used to achieve selective amplification of the local light intensity gradient, which is critical to realizing precise edge extraction of the dim target. We use conventional optoelectronic convolutional processing to process the same light patterns and the corresponding results are presented in the Fig. 3c. Due to the static nature of the conventional convolutional approach, the small gradient of the local light intensity gives rise to a corresponding small photocurrent output of 0.4 nA, which is difficult to sense and extract in complex environments.

We next implement two-dimensional in-sensor dynamic computing with a 3 × 3 device array based on the graphene–Ge heterostructure devices. The fabrication details of the array are provided in Methods. Figure 4a shows the optical image of the fabricated device array, in which active device $\mathsf { D } _ { \mathsf { A } }$ is at the centre of the array and is surrounded by eight passive devices $( \mathrm { D } _ { \mathrm { P } } \mathrm { - } \mathrm { D } _ { \mathrm { P } 8 } )$ . The array can be used to accurately extract the edge profiles of low-contrast objects in an image by implementing the in-sensor dynamic computing algorithm, as schematically shown in Fig. 4b. In this hardware algorithm, the image processing is divided into a series of cycles and each cycle corresponds to an image patch with $3 \times 3$ pixels in a spatial sequence. In each cycle, the initial photoresponsivity $( R _ { \mathrm { A } } )$ of the active device $\mathsf { D } _ { \mathsf { A } }$ is proportional to the photoresponsivity of the passive devices $( \mathrm { D } _ { \mathsf { P 1 } } , \mathsf { D } _ { \mathsf { P 3 } } , \mathsf { D } _ { \mathsf { P 6 } }$ and $\mathrm { D } _ { \mathrm { P 8 } }$ with $R _ { \mathrm { P 1 } } , R _ { \mathrm { P 3 } } , R _ { \mathrm { P 6 } }$ and $R _ { \mathrm { P 8 } } { \mathrm { , } }$ , respectively), namely, $R _ { \mathrm { P 1 } } = R _ { \mathrm { P 3 } } = R _ { \mathrm { P 6 } } = R _ { \mathrm { P 8 } } = - 1 /$ $4 \times R _ { \mathrm { A } }$ . The photoresponsivity of other passive devices $( \mathsf { D } _ { \mathsf { P } 2 } , \mathsf { D } _ { \mathsf { P } 4 } , \mathsf { D } _ { \mathsf { P } 5 }$ and $\mathsf { D } _ { \mathsf { P } 7 } \mathsf { ) }$ are set to 0 in during the whole process. Optical inputs $( P _ { m - 1 , n - 2 } ,$ $\ldots , P _ { m + 1 , n + 1 } )$ representing one patch of the image are cyclically projected onto the device array, generating the corresponding photocurrents $( I _ { \mathrm { p h \cdot P 1 } } , \ldots , I _ { \mathrm { p h \cdot P 8 } } )$ . The local image gradient $G ^ { * }$ , defined as $G ^ { ' } = | P _ { m + 1 , n + 1 } -$ $| \bar { P _ { m - 1 , n - 1 } } | + | \bar { P } _ { m + 1 , n - 1 } - \bar { P } _ { m - 1 , n + 1 } |$ , can be calculated by using $G = | I _ { \mathrm { p h \cdot P 1 } } - I _ { \mathrm { p h \cdot P 8 } } | +$ $| I _ { \mathrm { p h } \cdot \mathrm { P } 3 } - I _ { \mathrm { p h } \cdot \mathrm { P } 6 } |$ , since the photoresponsivities of all the passive devices are constant during the process. To detect the edge profile in the image, the calculated gradient G is compared to a preset threshold. If the value of G exceeds this threshold, the photoresponsivity $R _ { \mathrm { A } }$ of the $\mathsf { D } _ { \mathsf { A } }$ will be increased, otherwise $R _ { \mathrm { A } }$ remains unchanged. Finally, the total photocurrent generated by all the devices $( I _ { \mathrm { o u t } } )$ represents the detection edges from the background. Figure 4c shows the dynamic control circuit used to implement such a dynamic algorithm. The working passive devices can be selected by serial transistors and a multiplexer (MUX). We choose $\mathsf { D } _ { \mathsf { P 1 } } , \mathsf { D } _ { \mathsf { P 3 } } , \mathsf { D } _ { \mathsf { P 6 } }$ and $\mathrm { D } _ { \mathrm { P 8 } }$ for this local image gradient calculation

and proof-of-concept demonstration. Similar to the control circuit shown in Fig. 3, the photocurrent outputs of $\mathsf { D } _ { \mathsf { P 1 } } , \mathsf { D } _ { \mathsf { P 3 } } , \mathsf { D } _ { \mathsf { P 6 } }$ and $\scriptstyle \mathbf { D } _ { \mathsf { P 8 } }$ can be converted into voltage signals $V _ { \mathrm { P 1 } } , V _ { \mathrm { P 3 } } , V _ { \mathrm { P 6 } } , V _ { \mathrm { P 8 } }$ and two differentiator modules are used to calculate absolute difference between $V _ { \mathrm { { P 1 } } }$ and $V _ { \mathrm { P 8 } } ,$ and $\mathsf { V } _ { \mathsf { P 3 } }$ and $V _ { \mathsf { P 6 } } .$ The resulting voltage signals $V _ { \mathrm { G - 1 8 } }$ and $V _ { \mathrm { G } { \cdot } 3 6 }$ are summed up to generate a voltage output signal $V _ { \mathrm { { D } } } .$ The voltage is compared with the threshold of the trigger circuit to determine the modulation of the top-gate voltage of $\mathsf { D } _ { \mathsf { A } } ( V _ { \mathsf { T G - A } } )$ (see more details in Methods).

Based on the algorithm and circuit, we demonstrate the accurate detection and robust tracking of dim targets; the corresponding results are shown in Fig. 4d,e. Figure 4d shows a low-contrast image in which a person is standing in the dim corridor. Due to the ultralow contrast, the edge profile of the person is difficult to distinguish from the background. By using our in-sensor dynamic computing, we can accurately detect the edge profile, as shown in the right image of Fig. 4d. As a comparison, we also show the result of using the conventional optoelectronic convolution approach to process this image. The results show that the edge profile of the person cannot be extracted

(Extended Data Fig. 1), indicating that our proposed computing technology has promise for the application of tracking dim targets of interest in contrast-varying scenes. Figure 4e demonstrates robust tracking of an unmanned aerial vehicle (UAV) flying through an alley using in-sensor dynamic computing. In this scenario, the contrast between UAV and the background is constantly changing, making it challenging to track the target all the time by conventional approaches. We extracted three frames from a video of a UAV flying through an alley, images at $t _ { 1 } , t _ { 2 }$ and $t _ { 3 }$ shown in the upper portion of Fig. 4e. We show that the edge profile of the UAV can be accurately extracted by in-sensor dynamic computing (bottom images of Fig. 4e). In contrast, the results extracted using the conventional optoelectronic convolution approach are shown and we note that the target is lost when the contrast is low (Supplementary Video). Our proposed in-sensor dynamic computing is not limited to visible-light scenes, but could also be extended to near-infrared wavelengths (Supplementary Fig. 6). The proposed in-sensor dynamic computing can be scaled up and operated in the same way as traditional CMOS image sensors, except

for the dynamic control (more details are provided in Methods, and corresponding simulations are shown in Extended Data Figs. 2–4). These results highlight the advantage of the proposed computing technology for in situ processing of low-contrast broadband images at the sensor level and in facilitating robust recognition of targets in varying-contrast environments.

# Robust target recognition

In-sensor dynamic computing allows for achieving highly robust recognition of dim targets in complex visual scenes, where the contrast of human faces varies with lighting conditions (Fig. 5a). Recognition of these human faces can be realized by using an intelligent machine vision system, in which the sensor capable of carrying out the dynamic computing is interfaced with an artificial neural network (ANN). In this system, in-sensor dynamic computing can achieve accurate extraction of edge features of the human faces with various contrasts, as shown in the central sets of images in Fig. 5a. These enhanced features serve as a good training dataset for the ANN and facilitate a highly robust recognition of human faces.

In our proof-of-concept demonstration, we have employed the AT&T human face dataset for training and recognition, which has been widely used in computer vision. To evaluate robustness of the proposed intelligent machine vision system in high recognition accuracy of these human faces, we have expanded the original ORL (Olivetti Research Laboratory) dataset to 5,000 images and included five datasets where the averaged image contrast is gradually reduced, as schematically shown in Fig. 5b. Each dataset contains 1,000 images. The contrast of every image in each dataset is calculated and the corresponding results are presented in Fig. 5c. More details about contrast calculation are provided in Methods. The averaged contrast is gradually reduced from dataset-1 to dataset-5. By using these datasets, we have compared the recognition accuracy of human faces between our in-sensor dynamic computing and the conventional optoelectronic convolutional processing. Figure 5d shows the recognition accuracy for each dataset after 100 epochs. The in-sensor dynamic computing gives rise to a high recognition accuracy of above 90%. Moreover, the recognition accuracy is robust to contrast variations due to our extraction of edge features from each dataset with our proposed computing technology (Extended Data Fig. 5). In comparison, the recognition accuracy based on the conventional optoelectronic convolutional processing drastically varies with the average contrast of each dataset. Furthermore, the dynamic control of the active device in the kernel has the potential to incorporate in-sensor processing into a convolutional neural network’s backpropagation, making it a highly scalable technique.

# Conclusions

We have reported in-sensor dynamic computing that is based on the correlated optoelectronic characteristics of an array of multi-terminal mixed-dimensional graphene–Ge heterostructure devices. We showed that the approach can provide accurate extraction of edge features of dim targets in various visual scenarios and can provide robust tracking of dim targets. Furthermore, we showed that our in-sensor dynamic computing, when combined with an ANN, can accurately recognize human faces with a range of contrasts, which is challenging when using conventional optoelectronic convolutional processing. Our approach could be used to develop intelligent machine vision systems that can operate in complex visual environments.

# Methods

# Device fabrication

Graphene, h-BN and graphite (from HQ Graphene) were obtained through the conventional mechanical exfoliation approach. GeOI substrate (top Ge: 50 nm, P type; $\mathrm { S i O } _ { 2 } \mathrm { : }$ 300 nm; bottom silicon acts as a bottom gate) was purchased from IQE cooperation. We fabricated graphene–Ge mixed-dimensional heterostructures by using standard

electrical beam lithography, inductively coupled plasma and electrical beam evaporation. Graphite–h-BN–graphene heterostructure was transferred on top of Ge thin film by using dry transfer method (Supplementary Fig. 1). Both Ge thin film and graphene on SiO were characterized by Raman spectrum (Supplementary Fig. 2). All devices were annealed at 300 °C in an argon atmosphere for 3 hours before carrying out electrical and optoelectronic measurements. For the 3 × 3 device array, all the devices share one common back gate and the top-gate configuration of the active device was fabricated by using atomic layer deposition and metal evaporation. The optoelectronic measurements of the device with metal top gate are shown in Supplementary Fig. 5.

# Device characterization and experimental setup

Each graphene–Ge heterostructure photodiode was wire-bonded on a socket and placed on a custom-made printed circuit board (for the electrical and optoelectronic measurements. We measured the current via a data acquisition card (DAQ, National Instruments, PCIe-6351) and a current amplifier (Stanford Research Systems, model SR570). The gate voltage was applied by using a source measurement unit (Keithley, 2636B, 2635 A). A 1550 nm laser (SFL1550P, CLD1015, ThorLabs) and 640 nm laser were used for the optoelectronic measurements. A photograph of the experimental setup is shown in Supplementary Fig. 7. The acquired experimental data were processed with Igor (Wavemetrics) and MATLAB.

The image pattern generator system was built by connecting a homemade laser-pointer array to multi-terminal voltage sources, which are controlled by Python codes. First, the whole image was divided into a series of 3 × 3 subimages (patches) in a spatial sequence. The greyscale (0–255) was linearly scaled to a range (2.2–2.7 V) consistent with the voltage range for the laser, so that the output light intensity varies from 0 to 1 W cm−2. Then, the image information (spatial light intensity) of each patch was cyclically optically projected onto the device array through a voltage-driven pattern generator system in chronological order.

# Circuit operation in dynamic kernel

The operating mechanism of the circuit in Fig. 4c is similar to the circuit in Fig. 3a. As a hardware implementation example of the algorithm in Fig. 4b, we selected $\mathsf { D } _ { \mathsf { P 1 } } , \mathsf { D } _ { \mathsf { P 3 } } , \mathsf { D } _ { \mathsf { P 6 } } , \mathsf { D } _ { \mathsf { P 8 } }$ as passive pixels by switching on corresponding transistors $( \mathsf { S } _ { 1 } , \mathsf { S } _ { 3 } , \mathsf { S } _ { 6 } , \mathsf { S } _ { 8 } )$ and controlling a multiplexer (MUX). The photoresponsivities of other $\mathsf { D } _ { \mathsf { P } 2 } , \mathsf { D } _ { \mathsf { P } 4 } , \mathsf { D } _ { \mathsf { P } 5 }$ and $\scriptstyle \mathbf { D } _ { \mathsf { P 7 } }$ devices are set to 0 in the whole process. In each cycle, all the passive devices are biased with $V _ { \mathrm { d d } } = 1$ V at the graphene terminal and $V _ { \tt B G P } = 0 \vee ,$ while the active device $\mathbf { D _ { A } }$ is biased with $V _ { \mathrm { D - A } } = - 0 . 5 \ : \mathrm { V }$ at the Ge terminal and $V _ { \mathrm { B G \cdot A } } = - 3 0 \mathsf { V }$ . # The simulation of peripheral electronics for large-scale integration

Processing an image with the proposed in-sensor dynamic computing is accomplished in a single pass of the image, a single 'image capture'. This is because the sensor based on our proposed technology can be operated as presently done with a CMOS image sensor, the sole difference being the essentially invisible dynamic control of the active devices, providing the same interface as for current CMOS image sensor devices. Like the rolling exposure in a standard CMOS image sensor, the dynamic kernels at each pixel in a row operate simultaneously, pixel rows can be sequentially selected and the generated outputs can be read from all columns in parallel.

To verify the feasibility of achieving the in-sensor dynamic computing through a single image capture, we only chose a dynamic kernel and the corresponding peripheral circuit for simulation, as shown at the bottom right of Extended Data Fig. 2. We have employed the standard Semiconductor Manufacturing International Corp. 0.18 μm Bipolar-CMOS-DMOS process library in the Cadence software to simulate the operation of the dynamic kernel and the readout. To perform the simulation, we have used four voltage sources $( \boldsymbol { V } _ { \mathrm { P } 1 } , \boldsymbol { V } _ { \mathrm { P } 3 }$ , $V _ { \mathrm { P 6 } } , V _ { \mathrm { P 8 } } )$ to represent the four passive devices $( \boldsymbol { \mathrm { D } } _ { \scriptscriptstyle \mathrm { P } 1 } , \boldsymbol { \mathrm { D } } _ { \scriptscriptstyle \mathrm { P } 3 } , \boldsymbol { \mathrm { D } } _ { \scriptscriptstyle \mathrm { P } 6 } , \boldsymbol { \mathrm { D } } _ { \scriptscriptstyle \mathrm { P } 8 } )$ ) and used a current source to represent the current output from the active device $( I _ { \mathrm { l i g h t - A } } )$ and another to represent the combined four passive devices $( \sum I _ { \mathrm { l i g h t \cdot P } i } )$ under the light illumination. This can be done in this way, since each passive device in the dynamic kernel serves dual purposes: capturing images and contributing photocurrent for processing. In this sense, a voltage and a current can be generated from the passive device. Extended Data Fig. 3 shows the corresponding circuit layouts for the dynamic kernel and peripheral electronics. By using the time sequences shown at the top right of Extended Data Fig. 2, we simulate the signal input into the dynamic kernel and signal readout from the peripheral circuits. The simulation results are displayed in Extended Data Fig. 4. For the sake of simplicity, we consider the case that the light intensity shed on the passive devices $ { \mathbf { D } } _ {  { \mathbb { P } } 1 }$ and $\scriptstyle \mathbf { D } _ { \mathsf { P 8 } }$ is the same. In this way, the local intensity gradient is determined only by the absolute value of $V _ { \mathsf { P 3 } } - V _ { \mathsf { P 6 } } .$ . Extended Data Fig. 4a shows $V _ { \mathrm { T G - A } }$ as the function of $( V _ { \mathsf { P 3 } } - V _ { \mathsf { P 6 } } )$ . This result shows that the top-gate voltage $( V _ { \mathrm { T G - A } } )$ applied to the active device can be adjusted from $V _ { \mathrm { { L } } }$ to $V _ { \mathrm { H } }$ when $| V _ { \mathsf { P 3 } } - V _ { \mathsf { P 6 } } |$ exceeds a threshold, which is consistent with the operating principle of our proposed in-sensor dynamic computing in the main text of the manuscript. Furthermore, we simulate the $I _ { \mathrm { p h } } { - } t$ (the photocurrent injected into the capacitor integration circuit versus time) and $V _ { \mathrm { o u t } } { - } t$ (final output voltage of the capacitor integration circuit versus time) for two cases $( | V _ { \mathsf { P } } - V _ { \mathsf { P 6 } } |$ > threshold and $| V _ { \mathsf { P 3 } } - V _ { \mathsf { P 6 } } |$ < threshold), with the corresponding results shown in Extended Data Fig. 4b. The results show that the input light intensity either can be amplified or unchanged, which is manifested by the relative change of output voltage. These simulation results confirm the feasibility of achieving the in-sensor dynamic computing through capturing a single image.
