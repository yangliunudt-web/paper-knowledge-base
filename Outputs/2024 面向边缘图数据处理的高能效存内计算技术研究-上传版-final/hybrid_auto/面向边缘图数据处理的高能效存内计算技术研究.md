# 摘 要

随着深度学习技术的飞速发展，图数据的应用日益普遍。同时，其规模和复杂性也不断增长，使得传统深度学习方法及计算平台面临巨大挑战。尤其在边缘计算领域，针对图数据的高能效处理成为了研究的焦点。图神经网络（GNN）作为一种基于深度学习的图表示学习方法，虽然在对图数据的特征提取方面表现出色，但难以处理动态变化的图数据，并且其复杂的模型结构和对高精度权重的需求，使其难以在计算和存储资源受限的边缘设备上高效运行。此外，当前基于 CMOS 技术的硬件系统普遍采用冯·诺依曼架构，这导致图处理任务面临存储、算力和能效上的瓶颈。

为了应对上述挑战，研究者们提出了基于忆阻器的存内计算范式。该范式通过将存储和计算集成在一起，加速了神经网络中大量的矩阵向量乘操作，旨在实现更高效的神经网络硬件部署。然而，目前基于存内计算架构的图数据处理算法与硬件系统仍然处于初级阶段，面临以下关键问题：首先，在实际的边缘计算场景中，图数据往往只有有限的标注信息，针对图数据的高能效小样本学习加速系统的研究不足。其次，图神经网络具有双重运算模式和不规则的访存模式，面临着较高的存储需求和器件非理想性的挑战，难以在边缘设备中实现有效加速。再者，随着时间推移，图数据结构动态变化，属于新类的节点和边不断添加到图数据中，针对此类增量学习的算法及在硬件上的部署尚缺乏系统性研究。

本文围绕图数据的小样本学习、图神经网络加速以及图数据的小样本类增学习等关键技术问题开展深入研究，取得了以下成果：

（1）图小样本学习存内计算加速系统。有限样本下的图神经网络面临过拟合问题，难以实现高效的图表示学习。针对边缘计算环境中存储和计算资源受限的挑战，本文采用软硬件协同优化方法，成功构建了一种高准确率、高鲁棒性、低功耗的图小样本学习存内计算加速系统。算法层面，该系统利用具有随机权重的回声状态图网络和二值权重的二值神经网络，开发了记忆增强图神经网络模型（MAGNN），在引文网络 Cora 数据集的 2-way 3-shot 图小样本学习任务上取得了 68%的准确率。硬件实现方面，利用阻变存储器的阻值分布随机性和高低阻态转变特性显著加速了图嵌入和点积相似度计算，实现了约 70 倍检索延迟降低和约 250 倍的更新延迟降低。同时，推理的核心功耗相比传统 CMOS数字系统降低了约 60 倍。

（2）全二值图卷积网络存内计算加速系统。针对边缘图卷积网络的高存储需求、不规则内存访问和器件非理想性等挑战，本文设计了一种全二值图卷积

网络存内计算加速系统。该设计采用模型量化和存内计算范式，有效加速了图数据处理。算法层面，开发了全二值的图卷积网络算法模型，通过二值的聚合与组合操作，实现高效的图嵌入过程。在图分类和节点分类的基准数据集上，该模型达到了与 32 位浮点精度图卷积网络相近的准确率，同时降低了存储成本，提高了模型的运行速度和鲁棒性。硬件实现方面，采用基于阻变存储器的内容可寻址存储器（CAM）阵列和矩阵向量乘（MAC）阵列，避免了高能耗数模转换器（ADC）的使用，并在 40纳米工艺的存内计算芯片上进行硬件验证，显著降低了推理过程的核心功耗。

（3）图小样本类增学习存内计算加速系统。针对实际应用中图数据结构动态变化带来的灾难性遗忘和过拟合问题，本文开发了一种图小样本类增学习存内计算加速系统。算法层面，开发了基于知识蒸馏的元学习策略，在 5 个增量会话阶段成功实现了 1-way 5-shot 的图小样本类增学习，识别率较基线方法提升了 27.49%和 9.31%。硬件实现方面，采用基于阻变存储器的内容可寻址存储器（CAM）阵列和矩阵向量乘（MAC）阵列硬件部署了图嵌入过程和点积相似度计算。该加速系统相比传统 CMOS 数字系统实现了约 88 倍的检索延迟降低和约98倍的推理核心功耗降低。

关键词：图数据，存内计算，小样本学习，图神经网络加速，小样本类增学习

# Abstract

With the rapid advancement of deep learning technology, the graph-structured data is widespread in various applications. However, the scale and complexity of the graphs remain growing, posing great challenges to conventional deep learning methodologies and general-purpose computing platforms. Graph-structured data processing with high energy efficiency has become one of the research interests especially in the edge computing. As a graph representation learning method based on deep learning technology, the Graph Neural Networks (GNNs) exhibit excellent performance in the graph embedding. However, they struggle to handle dynamically evolving graphs. The requirement for the complex model architecture and high precision weighs to the GNNS makes it difficult to implement on edge devices with limited computational and storage resources. In addition, current hardware systems based on CMOS technology typically adopt the Von Neumann architecture, introducing bottlenecks in storage, computility, and energy efficiency in graph computing tasks. To address the aforementioned challenges, the memristor based computing-in-memory paradigm is emerging to accelerate matrix-vector multiplication operations in deep neural networks by integrating storage and computation for the data. Unfortunately, current models and hardware systems for graph-structured data processing based on computing-in-memory architecture are still in the early stages and, facing several key issues: Firstly, in practical edge computing scenarios, graph-structured data often lacks sufficient annotation information, leading to inadequate research on efficient few-shot learning acceleration architectures in GNNs. Secondly, GNNs exhibit irregular memory access patterns and hybrid execution behavior with high storage demand and low immunity to device nonidealities, making it difficult for effective acceleration on edge devices. Moreover, real-world graphs evolve with the emergence of new nodes and edges, thereby generating novel classes. The algorithms and hardware implementation for incremental learning lack sufficient research.

This paper conducts deep research in three areas: few-shot graph learning, GNNs acceleration, and graph few-shot class-incremental learning, achieving the following innovative results:

(1) Few-shot graph learning acceleration system based on computing-in-memory. GNNs are inadequate to characterize the global information and work not satisfactorily when the number of labelled nodes is especially small, which makes it difficult to implement energy-efficient graph representation learning at the edge. This paper adopts a software-hardware co-design to construct a high accuracy, high robustness, and low energy consumption computing-in-memory acceleration architecture for few-shot graph learning. Software-wise, the Memory-Augmented

Graph Neural Network model (MAGNN) is developed by utilizing the Echo State Graph Network with random weights and the Binary Neural Network with binary weights. Achieving 68% accuracy on the 2-way 3-shot few-shot graph learning task on the citation network Cora dataset. Hardware-wise, the architecture significantly accelerates the graph embedding process and dot product similarity calculation with resistive random access memory (RRAM) crossbar arrays, resulting in approximately 70 times reduction in search latency and approximately 250 times reduction in update latency. Moreover, the core energy consumption in the computing-in-memory hardware system in the inference process is reduced by approximately 60 times compared to traditional CMOS digital systems.

(2) Fully binarized graph convolutional network acceleration system based on computing-in-memory. To alleviate the high storage demand, irregular memory access and computation patterns, and low immunity to device non-idealities in GNNs at the edge, the fully binarized graph convolutional network acceleration architecture based on computing-in-memory is proposed. The architecture employs model quantization methods and computing-in-memory paradigm to effectively accelerate processing for the graph-structured data. Software-wise, a fully binarized graph convolutional network model is proposed, achieving comparable accuracies to 32-bit floating-point graph convolutional networks on benchmark datasets in graph classification and node classification tasks. Both the aggregation phase and combination phase are binarized to replace the original floating-point calculations with binary multiplication operations, leading to an efficient graph embedding process. The reduced storage demand, enhanced model execution speed, and improved robustness are also demonstrated. Hardware-wise, the architecture significantly reduces the core energy consumption in inference process by avoiding the usage of power-hungry analog-to-digital converters (ADCs) through the adoption of the resistive random access memory (RRAM) based content-addressable memory (CAM) arrays and multiply-and-accumulation (MAC) arrays. The architecture is experimentally demonstrated on a 40nm RRAM chip with significantly reduced core energy consumption in the inference process.

(3) Graph few-shot class-incremental learning acceleration system based on computing-in-memory. To address the catastrophic forgetting and overfitting problems in the dynamic evolving graph-structured data, graph few-shot class-incremental learning acceleration architecture based on computing-in-memory is proposed on the basis of above research works. Software-wise, a knowledge distillation-based metalearning strategy is developed, achieving 1-way 5-shot graph few-shot classincremental learning in 5 streaming sessions with accuracy improvements of 27.49% and 9.31% compared to baseline methods, demonstrating the feasibility of the proposed strategy. Hardware-wise, the graph embedding process in the controller and dot product similarity calculation in the explicit memory is accelerated using RRAMbased content-addressable memory (CAM) arrays and multiply-and-accumulation

(MAC) arrays. This acceleration architecture achieves approximately 88 times reduction in search latency and approximately 98 times reduction in core energy consumption in inference process compared to traditional CMOS digital systems.

Key Words: Graph-structured data, Computing-in-memory, Few-shot learning, Graph neural network acceleration, Few-shot class-incremental learning

# 1.1 前言

随着深度学习（Deep Learning，DL）技术的快速发展，人们对模式识别和数据挖掘的研究进入了新的阶段[1-2]。各种端到端的深度学习范式已经广泛应用到机器学习（Machine Learning，ML）任务中，如目标检测[3-4]，语义分割[5-6]，机器翻译[7-8]和语音识别[9-10]等。深度学习的成功可部分归功于快速发展的计算平台，如 CPU（Central Processing Unit）、GPU（Graphics Processing Unit）等，大量有效的训练数据和从欧几里得数据（Euclidean data）中提取潜在特征的能力[11]。然而，越来越多的数据产生自非欧几里得空间，采用图结构进行表示。图数据的复杂性给现有的深度学习技术带来了极大的挑战。传统的神经网络能够从规则的数据结构中提取特征信息。如图 1-1（a）所示，卷积神经网络能够从采用规则网格表示的图像中利用其平移不变性、局部连通性和组合性提取出有效的局部特征信息，以用在各种图像分析任务中。与规则的数据结构不同，图数据具有不定数量的节点，每个节点具有不定数量邻居节点。如图 1-1（b）所示。图数据的不规则性和复杂性给现有的深度学习技术带来了极大挑战。

此外，基于传统冯·诺依曼（Von Neumann）架构的计算平台在执行计算密集型和访存密集型的机器学习任务时，需要在存储器和处理器之间进行频繁的搬运数据，导致“存储墙”[12-14]和“功耗墙”[15-18]问题日益显著。“存储墙”是指数据的搬移和访问成为硬件系统计算性能的瓶颈。当运算能力不断提高时，数据访问速度无法跟上处理器的计算速度，导致整个系统的计算性能难以提升。如图 1-2所示，GPU的峰值计算能力在过去 20年中增加了 60000倍，但动态随机存取存储器的带宽仅增长 100倍，互连带宽仅增长了 30倍，存储器和处理器

之间存在巨大的性能差异。

图 1-2 存储墙[14]

Figure 1-2 Memory Wall[14]

数据在存储器和处理器之间的频繁搬运会带来巨大的能耗开销，即“功耗墙”问题。如图 1-3 所示，在 45nm CMOS 工艺下，访问静态随机存取存储器（Static Random Access Memory，SRAM）和 动态随机存取存储器（DynamicRandom Access Memory，DRAM） 操作带来的能量开销分别是算术加法操作能耗的 50 倍和 6400 倍。数据搬移带来的能量开销使得传统的冯·诺依曼架构难以满足低功耗的系统设计需求。在后摩尔时代背景下，面对晶体管尺寸接近物理极限的挑战，单纯依靠工艺微缩难以持续提升芯片性能，寻求计算架构的革新来缓解冯诺依曼瓶颈变得至关重要。

存内计算（Computing-In-Memory，CIM）[19-25]技术通过将计算逻辑集成到存储单元中，有效避免了数据在计算单元和存储单元间的频繁传输，从而降低

了系统的延时和能耗，为边缘计算环境中实现高效的机器学习任务提供了新的可能。基于忆阻器的存内计算架构不仅可以作为高容量的数据存储单元，还能在原位执行高并行度的逻辑计算。特别是加速矩阵向量乘操作，显著提高了神经网络的处理效率。因此，基于忆阻器的存内计算技术在提高边缘设备的功能性方面具有重要的研究意义和应用前景。

# 1.2 图神经网络概述

图数据在日常生活中无处不在，在推荐系统[26-27]、社交网络[28-29]、 药物发现[30-31]和电路注释[32-33]等领域中广泛应用。传统的深度学习技术可以有效地提取位于欧几里得空间的数据（如图片, 文本和视频等）的潜在特征，从而实现高效的分类或预测。但是，这些方法无法有效提取图数据特征，难以实现高效的图表示学习。图神经网络（Graph Neural Networks, GNNs）[34-37]已经成为一种处理和学习图数据有效表示的新型计算范式，在流行病研究、量子计算、芯片设计等方面具有突出的性能，如图 1-4所示。

# 1.2.2 典型图神经网络模型

由于图数据的爆发式增长和深度学习的广泛应用，各种 GNN模型被提出用于分析和学习图数据。Gori等人首次提出了 GNN的概念[38]，促进了 GNN的早期发展。Sperduti 等人[39]进一步对 GNN 进行阐述。这些工作通过迭代传播邻居上下文信息来学习节点的特征表示，直到达到一个稳定的不动点。该过程具有大量的计算开销且效率较低。受卷积神经网络在计算机视觉领域的启发，大量在图数据上定义的卷积方法被不断开发。这些方法可大致分为谱域方法和空域方法。

# 1.2.2.1 谱域方法

谱域方法利用谱图理论将空域卷积转换为谱域乘积，并在谱域设计图卷积算子，在图表示学习领域取得了许多成果。Bruna 等人[40]首次基于谱图理论开发了谱图卷积网络，通过图拉普拉斯算子的特征分解在傅立叶域定义卷积运算。但该模型计算复杂性过高，通用性差。为降低计算复杂度，Defferrard[41]等人提出了切比雪夫网络，利用切比雪夫多项式近似谱卷积核，实现了较好的局部近似，大大降低了学习参数的复杂度。此基础上，Kipf 等人[42]进一步对其进行简化，将切比雪夫多项式的阶降为 1，提出了图卷积网络（Graph ConvolutionalNetwork，GCN），节点特征迭代更新过程如图 1-6 所示。为了提高谱域方法的灵活性，Li 等[43]提出了自适应图卷积神经网络，通过设计可学习残差的图拉普拉斯矩阵，使得基于谱域的图卷积可推广至不同结构和大小的图。Zhu 等人[44]提出了简单谱图卷积，通过分析马尔可夫扩散核构建简单有效的谱域滤波器，缓解了过平滑问题。

# 1.2.2.2 空域方法

空域方法，也称为消息传递神经网络（Message-Passing Neural Networks，

MPNNs），通过直接在图上定义卷积，聚合邻域信息。Hamilton 等人[45]提出了基于空域的 GraphSAGE 模型，引起了 GNN 研究的热潮。如图 1-7 所示，该模型的核心思想是节点的嵌入表示可通过共同的聚合邻居节点信息函数计算得到，而在训练时只要得到这个聚合函数，就可以将其泛化到未知的节点上。因此，即使图的结构发生变化也可以得到新节点的特征表示。为了区别节点重要程度，Veličković 等人[46]将注意力机制引入图神经网络之中，提出了图注意力网络。Xu 等人[47] 从图神经网络的单射函数特性出发，提出了图同构网络，进一步提高了识别图数据结构的能力。

# 1.3 存内计算技术概述

存内计算作为一种新型计算范式，将处理单元和存储单元紧密的集成在一起，实现了数据的原位存储与计算，成为突破“存储墙”和“功耗墙”的关键技术。存内计算架构主要由传统的 CMOS电路和忆阻器构建。

# 1.3.1 传统 CMOS电路存内计算

静态随机存取存储器（Static Random Access Memory，SRAM）具有访问速度快，可靠性强的优势。基于 SRAM 的存内计算可以直接在高速缓存中进行数据的读写和计算，大大降低了数据访问的时间和功耗。标准的 6T-SRAM 结构如图 1-8（a）所示，由两个反相器和两个读写晶体管开关组成。位线 BL 和字线 WL 分别用于数据读取和读写控制。SRAM 具有三个基本操作，分别是读操作、写操作和空闲状态。在空闲状态下，WL 会始终处于低电平状态，两个开关晶体管 N3和 N4关闭。写入信息时，会根据数据内容使 BL和 BLB处于不同逻辑状态，然后打开 WL 将数据写入。在读取信息时，会先将位线 BL 和 BLB预充电至 VDD，然后打开 WL并根据数据将 BL或 BLB接地，释放掉预充电压。最后读取电路会判断 BL和 BLB电压关系完成 0或 1输出。由于 SRAM是逻辑

电平输出，所以非常适合进行位运算，因而具有存内计算潜力。Wu 等人[48]设计了 22 纳米 832Kb 的 SRAM 的浮点存内计算宏（macro），实现了指数和尾数运算。Song 等人[49]利用聚类结构创建转置宏，并将 8 个 6T 单元与一个电荷域计算单元（Charge-domain Computing Unit，CCU）共享，实现有效的深度神经网络部署。

相比 SRAM，动态随机存储器（Dynamic Random Access Memory，DRAM）具有更简单的结构，更小的面积消耗。基本的 1-transistor 1-capacitor （1T1C）的 DRAM 结构如图 1-8（b）所示。DRAM 具有写和读两种操作。在写入信息时，打开晶体管，在位线 BL 上施加电压。写入“ 1 ”时，则施加高电压，此时电流会通过晶体管向电容充电。写入“ 0 ”时，则让电容另一端接地。在读取存储的数据时打开晶体管，根据电容的充放电情况判断存储值。

在此基础上，基于高密度的嵌入式动态随机存取存储器（embeddedDynamic Random Access Memory，eDRAM）由 1-4 个晶体管构成一个计算单元，在 存 内 计 算 具 有 广 泛 的 应 用 前 景 。 Song[50] 等 人 提 出 了 基 于 3-transistor 1-capacitor（3T1C）的结构，利用其电流编程机制和动态共源共栅访问结构降低晶体管非理想性的影响，并且提出了电压-电流两步编程方案，提高亚微安培电流分量的写入速度。Kim 等人[51] 基于 eDRAM 提出了可重构的 DynaPlasia 架构。该架构具有三种模式的存内计算单元，可以从一个存储单元重构为存内计算处理单元或SAR-ADC的电容单元，以自适应优化系统资源利用。

忆阻器（memristor）是一种两端无源电子元器件，具有结构简单、非易失性、高密度和低功耗、与 CMOS 工艺兼容等优势，在边缘设备上具有极为广泛的用途[52-55]。针对新材料、新结构、新原理和新集成架构的忆阻器器件及其芯片的研究也逐步迈向新领域，如图 1-9[56]所示。基于忆阻器的内存计算技术有

# 1.3.2.1 阻变存储器器件

阻变存储器具有简单的金属—绝缘体—金属（Metal-Insulator-Metal，MIM）“三明治”结构，包含 2层电极层和 1层功能层，如图 1-10（a）所示[73]。它的两端是由金属构成的电极，阻变材料夹在两个电极之间。阻变器件利用阻值来表示数字信息。当在 RRAM器件两端电极施加电压时，RRAM 器件的电阻态可以在高阻态 (High Resistance State，HRS) 和低阻态 (Low Resistance State，LRS)之间进行转换。器件的电阻态由 HRS 到 LRS 的转换过程称为 SET 操作。反之，施加电压导致 RRAM器件的电阻态由 LRS 转换为 HRS 的过程称为 RESET 操作。

阻变存储器按照阻变机理可分为导电细丝型和界面型。前者依赖于阻变介质中导电通道的形成与断裂，主要包括氧空位通道型阻变器件和金属通道型阻变器件，如图 1-10（b）所示。当导电细丝形成时，器件呈低阻态，并展现出良

好的导电特性；当导电细丝断裂，在两个电极间产生间隙时，器件呈高阻态。界面型器件则依赖于阻变介质的体效应或者阻变介质与电极之间的界面效应，如图 1-10（c）所示[74] 。

根据 RRAM 器件的阻态切换行为，可以将 RRAM 分为单极性和双极性器件。其中单极性器件的高低阻态切换取决于施加的外部电压的大小（幅值），而与施加极性（方向）无关，RESET 和 SET 操作是通过施加相同方向不同大小的外部电压实现的，如图 1-10（d）所示。而双极性单元的阻态切换是有方向性的，RESET 与 SET 操作需要施加的电压极性是相反的，如图 1-10（e）所示。给器件施加一个较小的电压可以在不改变器件阻值的情况下，通过流出的电流大小分辨器件阻态，称为读操作。

# 1.4 选题意义与研究内容

在深度学习技术飞速发展的背景下，图数据的规模和复杂度持续增长，对传统的深度学习方法和硬件计算平台提出了新的挑战。特别是在边缘环境中，高效的图数据处理已成为了研究热点。基于深度学习的图神经网络在节点分类和图分类等基准任务上已经展显出了卓越的性能。但其具有复杂的模型结构和大量高精度权重，处理动态图数据的能力不足。这限制了图神经网络在计算和存储资源受限的边缘设备上的高效部署。

针对上述问题，本研究深入探讨了基于阻变存储器的存内计算技术。该技术通过并行乘累加操作原位加速神经网络的矩阵向量乘运算，有效缓解了传统冯·诺依曼架构中的“存储墙”和“功耗墙”瓶颈，显著降低了边缘图数据处理的存储与计算成本。尽管存内计算技术为边缘图数据处理提供了新的可能性，但其在计算模型与硬件实现方面仍处于探索阶段，面临许多尚未解决的关键科学问题。

# 第2章 边缘图数据处理概述

大数据时代的到来，越来越多的数据采用图结构进行表示，基于深度学习技术的图神经网络快速发展。但在边缘端针对不断变化的图数据实现快速高效的处理仍在算法模型与硬件平台方面面临挑战。本章从算法模型和硬件平台两个层面出发，分别介绍了有限样本下的图小样本学习、双重运算特性下的图神经网络加速和增量环境下的图小样本类增学习的相关研究工作，进一步阐述了边缘图数据处理的研究背景和现状。

# 2.1 图小样本学习

图神经网络（Graph Neural Network，GNN）因其优异的特征提取能力在图数据处理上得到了广泛应用。针对特定任务的高性能 GNN往往需要足够的带标签样本进行训练，但图数据的标注会消耗大量的人力物力。这种在有限图数据下的学习和分析，即图小样本学习，是目前边缘图神经网络应用面临的关键挑战之一[81-85]。如图 2-1 的引文网络所示[86]，我们给定该图数据一组固定的类别，图中每个节点表示一篇论文且属于其中的一个类别，边表示两篇论文之间存在引用关系。GNN 需要对剩余未带标签的节点进行分类。

对于包含丰富的监督信息的基类，如支持向量机、神经网络类别，GNN 能够实现优异的分类性能。然而在现实世界中，GNN 往往需要处理先前未见过的新类，并且新类只包含一个或几个带标签的节点，如人工智能、强化学习类别。

这会导致 GNN出现严重的过拟合的问题，大大降低了模型的泛化能力。因此，需要开发一种新的学习范式，使得 GNN 模型能够在有限样本下实现高效的图表示学习。

近年来，受人类学习方式启发，小样本学习（Few-Shot Learning，FSL）作为一种新的机器学习范式取得了突出进展，在文本分类、人脸识别等领域实现了广泛应用[87-96]。尽管在小样本学习范式下的神经网络具有较高的泛化能力，但该范式难以直接应用在图数据处理上 [97]。其面临的关键挑战是图数据不服从独立同分布假设。由于图数据中节点间的连接并不规则，每个节点具有不同数量的邻居节点，直接采用现有的小样本学习方法无法捕获图的底层数据结构，导致节点特征的表达能力较差。目前，小样本学习算法模型已经得到了广泛研究，并且针对图数据开展了进一步的优化和创新。这些算法模型主要可分为基于度量的方法、基于优化的方法和基于模型的方法。

# 2.1.1 基于度量的方法

基于度量的图小样本学习方法借鉴了原型网络（Prototypical Network，ProNet）[98]的思想，通过构建类原型向量和在度量空间的相似度计算实现分类任务。如图 2-2 所示，原型网络首先将每个类别中的样本映射到特征空间，计算类别的原型向量 $c _ { 1 }$ ， $c _ { 2 }$ 和 $c _ { 3 }$ 。然后使用欧式距离作为相似度度量函数，计算样本的特征向量??与每个类原型向量之间的相似度。最后根据最大的相似度得到该样本的预测类别。

一般的，基于度量的图小样本学习模型将 GNN作为编码器提取节点特征。首先，计算支持集中节点特征向量的均值为每个类别生成类原型向量。然后通过计算查询集中每个节点的特征向量到各个类原型向量的欧氏距离，对查询节点进行分类。在此基础上，许多基于度量的图小样本学习算法的变体不断涌现。GFL[99]利用了从辅助图中学习到的先验知识来提高目标图的分类精度。辅助图

和目标图之间共享一个可迁移的度量空间，该空间用节点特征函数和针对特定图的原型向量函数进行表示，实现结构化知识的迁移。考虑到图数据中每个节点的重要程度不同，GPN[100]引入了带有注意力机制的节点重要性评估器，计算支持集中属于每个类别的节点特征的加权和作为该类的原型向量。此外，通过充分利用节点间复杂多面的关系，MetaTNE[101]设计了一个特征转换函数，将与任务无关的节点特征映射为针对特定图小样本学习任务的节点特征，从而大幅度提升分类性能。

基于优化的图小样本学习是在模型无关元学习（Model-Agnostic Meta-Learning，MAML）[102]的基础上的优化。如图 2-3 所示，MAML 的目标是找到可以快速适应新任务的一组模型参数??，使得模型在解决小样本学习任务??时，能够在很少的梯度更新步数内获得任务??的最优参数 ${ \boldsymbol { \theta } } _ { i } ^ { * }$ 。通过 MAML 优化的GNN模型能够学习到任务间的先验知识，从而快速适应新的类别。

Meta-GNN[103]首次将 GNN 和 MAML 结合，实现了图小样本节点分类任务。由于图数据不服从独立同分布假设，不同任务的特征分布存在较大差异，AMM-GNN[104]引入了属性级注意力机制，更好地捕捉每个元学习任务的特性，学习有效的可迁移知识。此外，G-META[105] 从理论上证明了预测结果的证据率可以在目标节点周围的局部子图中获取，进一步利用子图实现图表示学习。此外，为了解决同一任务中不同节点间的长程依赖问题和不同任务依赖对齐问题，RALE[106]引入关键节点来捕获任务级和图级的依赖关系，通过在图上分配节点位置来改进元知识迁移过程。

# 2.1.3 基于模型的方法

基于模型的小样本学习引入了记忆模块和读写机制辅助存储任务信息。该方法从训练数据中提取知识，并存储在外部记忆中，通过从外部记忆中快速检

索信息来实现快速推理。记忆增强神经网络（Memory-Augmented NeuralNetwork，MANN）[107]使用神经图灵机（Neural Turing machine，NTM）[108]作为基本模型，通过标签偏移存储数据集的信息和最近未使用策略更新外部记忆，如图 2-4 所示。MANN 通过梯度下降获取了长期存储的有效表示。同时通过外部记忆快速将少量新的表示整合到短期存储中。元网络（Meta Networks，MetaNet）[109]进一步引入快速权重的概念。利用一个神经网络预测另一个神经网络的参数，通过快速权重和慢速权重的结合实现分类任务。

# 2.2 图小样本类增学习

尽管图小样本学习的算法模型非常丰富，但当这些模型增量地学习新类别时，会遗忘学习过的旧类别，即灾难性遗忘问题[110-111]。当旧类的所有数据都不可获取时，遗忘问题变得更加严重。小样本类增学习（Few-shot Class-Incremental Learning，FSCIL）的目标是能够从有限的训练样本中增量地学习新类[112]。FSCIL符合人类的学习模式，适合于现实世界的应用。解决 FSCIL的一种直观方法是在新的数据上对模型进行微调。但这会导致灾难性遗忘和过拟合的问题，降低模型的分类性能。FSCIL 面临的两个核心挑战是稳定性—可塑性困境和非可靠的经验风险最小化：

化（Empirical Risk Minimization，ERM）旨在优化模型在训练数据上的平均损失，大量的训练数据确保了训练时的数据一致性，使得模型可以获取有效的参数。然而，当训练样本有限时，ERM 策略可能会导致过拟合[81]，即模型在训练数据上表现良好，但在新的、未见过的数据上泛化性能较差。这是由于有限的训练数据不能完全代表整个数据生成过程的真实分布，导致模型捕获数据中的随机噪声，而不是内在的真实模式。如图 2-5（b）所示，给定一个假设空间ℋ和初始参数 $\cdot h _ { \vartheta }$ ，其中ℎ෠和 $\mid h ^ { * }$ 是使预期风险最小化的函数。 $h _ { f }$ 和 $| h _ { s }$ 分别对应在样本有限时和样本充足时的经验风险最小化函数。当具有足够的训练数据时，ERM会产生接近ℎ∗的结果。当训练样本不足时，ERM 函数不能准确逼近最优预期风险最小化函数。

与小样本学习相比，小样本类增学习需要克服以上两个挑战。除此之外，由于新旧类别之间的样本数量差别较大，模型在训练与测试中往往倾向于具有更多样本的旧类。同时基类（base class）样本与新类（novel class）样本之间的数据不平衡也使模型难以学习新类。在小样本学习的基础上，我们介绍现有的小样本类增学习方法，并将其延申到图数据处理上。

# 2.2.2 图小样本类增学习算法与模型

尽管小样本类增学习在计算机视觉和自然语言处理等领域取得了显著的进展，但是这些方法无法直接应用到图数据上。在实际生活中，图数据的结构随着新的节点和边的出现不断变化，新的节点类别不断涌现。由于对这些新类缺乏进一步的探索，新类通常只包含少量带标签的节点。

以图 2-8 中的引文网络为例。最初，迁移学习（Transfer Learning）和多任务学习（Multi-task Learning）作为基类（base class）具有丰富的带标签的节点。随着知识的不断进化，新的节点出现并引入新的引用关系，即边的连接（Edge）。一个新兴的研究课题“增量学习（Incremental Learning）”作为新类（novel class）出现，且具有少量的节点。当新类中只包含有限的带标签的样本时，如何正确分类未带标签的样本是需要解决的重要问题。这种在动态变化的图数据中针对所有类别的节点分类问题称为图小样本类增学习（Graph Few-Shot ClassIncremental learning，GFSCIL）。

在 GNN 的聚合阶段中，GNN 需要先检索目标节点的邻居节点，包括获取邻居节点的位置信息及其特征向量。由于图数据的不规则性，访问不同目标节点的结构信息以及邻居特征向量的地址都是随机的，从而导致了不规则的访存模式。同时，由于每个目标节点的邻居节点数量不同，在聚合邻居节点特征时，每个目标节点的执行时间存在差异，节点的运算负载不均衡，进而导致了不规则的运算模式。

在 GNN的组合阶段中，输入的节点特征向量维度以及权重矩阵是确定的，因此其访存和运算都是规则的。由于图数据的规模日益增大，组合阶段的运算通常是非常密集的，因此拥有规则和密集的运算模式。

聚合阶段和组合阶段的双重访存和运算模式使得 GNN难以实现高效的硬件部署。同时，由于图数据的规模增大，GNN 处理大规模图数据面临计算复杂度高，存储资源消耗大的挑战。针对以上问题，本节从算法模型优化和硬件平台优化出发，介绍GNN加速的相关研究工作。

# 2.3.1 算法与模型优化

GNN 的算法与模型优化是通过对网络结构或模型参数进行优化处理，达到降低运算复杂度和存储空间的目的。GNN 的算法与模型优化方法主要包含模型简化、模型压缩和模型权重随机化。

# 2.3.1.1 模型简化

GNN 模型简化是指通过简化网络的执行阶段，提高模型训练和推理的计算效率。组合阶段中，聚合后的节点特征经过线性变换和非线性激活实现节点特征更新。为了进一步提高 GNN 的运行效率，SGC[137]去除每个 GNN 层间的非线性激活函数来降低模型复杂性，并且仅保留输出层的归一化指数函数 Softmax生成概率输出。该模型利用轻量级的线性模型，显著加速训练过程。LightGCN[138]和 UltraGCN[139]进一步简化 GNN 模型，实现对推荐系统的用户—商品交互图的表示学习。通过对 NGCF[140]的消融实验研究，节点特征的线性变换和非线性激活并不有利于实现协同滤波。因此，LightGCN 去除了上述操作，并在邻接矩阵中去掉了自循环，简化了协同过滤中的模型结构。但是，LightGCN 通过多层叠加的方式传递信息会导致过平滑问题，降低了训练效率。因此，UltraGCN 放弃了在多层间显式的信息传递，直接获得近似的最终特征，提高了训练速度。

# 2.3.1.2 模型压缩

模型压缩是一种将复杂模型压缩为轻量级模型的方法，能够加速模型的训练和推理过程，降低运算成本。SGQuant[141]针对 GNN 不同层次开发了多粒度量化策略。并且设计了自动比特选择方法来确定适合的多粒度量化比特数。Degree-Quant[142]为 GNN 提出了一种量化感知训练方法。该方法对量化后的模型进行训练，提高了低精度模型的准确率和模型的运行速度。BGN[143]和 Bi-GCN[144]将二值量化方法引入到 GNN 中，加快模型的运行速度，进一步降低存储空间需求。

# 2.3.1.3 模型权重随机化

模型权重随机化是指利用具有随机权重的储池计算范式（Reservoircomputing，RC）实现有效的特征提取，降低了权重迭代训练过程的运算成本。Gallicchio 等人[146]首次将 RC 计算范式扩展到 GNN 中，提出了 FDGNN 模型。该模型具有随机权重的图嵌入层，通过迭代深层架构使模型构建更有效的图表示。然而，FDGNN 模型需要多层随机固定的权重递归实现特征提取，这种深层的网络架构对存储资源有较高的需求。由于在高维状态空间中的连续非线性随机投影在混沌边缘产生轨迹，有利于实现高性能的图表示学习。Wang 等人[147]在 FDGNN 的基础上开发了回声状态图网络（Echo State Graph NeuralNetwork，ESGNN），如图 2-12 所示。ESGNN 具有随机且固定的输入权重和隐藏层权重实现特征提取，以及一层全连接层实现分类。该模型在训练过程中仅分类层通过梯度下降进行迭代优化，从而大幅降低了训练成本。同时，ESGNN设计了有限迭代节点嵌入方案和任务相关分类头，更好地缓解过平滑问题。

由于 GNN 的聚合阶段和组合阶段具有不规则的访存和计算模式，CPU 和GPU 等通用硬件平台无法直接实现 GNN 的加速。同时，基于通用平台的硬件设计也会导致大量的面积和能量开销。因此，需要设计针对 GNN 的专用硬件加速硬件系统。目前，已报道的 GNN硬件加速系统主要可分为基于传统架构的方法和基于存内计算的方法。

# 2.3.2 传统架构硬件平台

用于图处理加速的传统冯·诺依曼架构的硬件系统主要包括 FPGA（FieldProgrammable Gate Array）和 ASIC（Application Specific Integrated Circuit）。在基于 FPGA 的硬件平台上，FPGP[148]设计了基于间隔分片结构的流线型节点中心图处理架构，同时提出了一种片上并行图处理器，最大限度地利用图数据的片外带宽和图处理的并行性。在基于 ASIC 的硬件平台上，HyGCN[149]研究了图卷积网络的双重执行模式，提出了一种混合架构实现硬件加速。该混合架构包含聚合引擎和组合引擎来缓解聚合阶段的不规则性，并充分利用组合阶段的规律性。通过引擎间流水线设计优化整个硬件系统，提高片外带宽利用率。AWB-GCN[150]提出了动态分布平滑、远程交换和行重映射的策略来自动调整工作负载，缓解了由于不规则的邻居节点分布导致的处理单元空转问题。EnGN[151]提出了环边归约数据流来解决局域性差的问题。同时，EnGN 提出了图分块和调度技术，结合设计的三层存储结构，高效地处理大型图数据。

# 2.3.3 存内计算系统硬件平台

忆阻器具有集成密度高和低功耗等优势，由其构成的交叉阵列能够原位、物理地实现存内计算，大大降低了数据的搬运。GNN-PIM[152]首次采用存内计算技术实现 GNN 加速。该架构开发一种优化的数据流实现 GNN 并行计算。同时，设计了分层互连网络，实现聚合阶段的高效数据移动。PIMGCN[153]提出了基于阻变存储器交叉阵列的图卷积网络加速架构, 如图 2-13所示。

PIMGCN 架构采用密集的数据映射和检索—执行结构，在有限的阵列成本下充分利用节点内并行性。此外，该架构进一步提出了并行执行和延迟匹配流水线两种调度策略，实现最大化节点间并行度和系统吞吐量。TARe[154]提出了基于阻变存储器的原位图处理加速器架构。该架构支持权重静态和数据静态的两种执行模式，可以自适应地选择原位计算模式。同时提出了一种稀疏数据映射机制来优化映射过程，缩短稀疏计算的延迟。ReGNN[155]设计了基于阻变存储器的异构存内计算架构实现 GNN 加速。该架构由模拟存内计算模块和数字存内计算模块组成，有效地处理 GNN 的不同执行阶段。同时，ReGNN 设计了节点调度程序和基于节点度和特征向量维数的不同子引擎来提高数据的并行度。

针对图小样本学习和图小样本类增学习的算法与模型已经得到了广泛研究，但这些模型具有大量高精度权重和复杂的网络结构，依赖具有高算力的传统冯·诺依曼架构的硬件平台，难以部署在计算资源和存储资源受限的边缘设备中。因此，需要设计轻量化、高能效的图小样本学习和图小样本类增学习的存内计算加速架构，实现边缘图数据处理。

# 第3章 图小样本学习存内计算加速系统

由于在真实环境中数据标注困难，有限监督信息下的图神经网络面临过拟合问题，难以实现高效的图表示学习。因此，本章采用软硬件协同优化技术，利用具有随机权重的回声状态图网络和二值权重的二值神经网络开发了记忆增强图神经网络模型，利用阻变存储器的阻值分布随机性和高低阻态转变特性实现了图嵌入和相似度计算，构建了高能效的图小样本学习存内计算加速系统。在引文网络数据集上对该加速系统进行性能评估与硬件验证。

# 3.1 引言

图数据在日常生活中无处不在，在分子预测和推荐系统等场景中广泛应用。然而，真实环境中由于数据的标注会消耗大量的人力和物力，图数据中许多节点类别只包含有限的带标签样本。如图 3-1 所示，以社交网络为例，图中的每个节点表示一个用户，如果用户间是好友关系，就表示为节点之间具有边的连接。当我们对位于中间的用户的职业进行判断时，由于该图数据中每个类别只包含 2 到 3 个样本，传统的图神经网络（Graph Neural Network，GNN）会出现过拟合的问题，无法实现正确分类。因此，需要一种新的学习范式，使得 GNN能够在有限的监督信息下，实现有效的节点特征提取。

基于传统深度学习技术的小样本学习方法层出不穷。然而，在存内计算范式下的高能效图小样本学习仍然面临以下挑战：

（1）算法模型层面上，与位于欧氏空间的文本和图像数据不同，图数据位

于非欧氏空间，数据不规则且具有噪声，节点之间的连接更加复杂，如图 3-2（a） 所示。采用传统的深度学习方法难以提取图数据的底层特征。GNN 能够实现有效的图表示学习，但其图嵌入过程包含大量的迭代操作，增加了训练过程的成本，如图3-2（b）所示。

（2）硬件层面上，基于内存可寻址存储器（Content-Addressable Memory，CAM）的记忆增强网络（Memory-Augmented Neural Network，MANN）通过存内检索操作降低了外部记忆中的延时和功耗，但 MANN 的控制器（Controller）仍在基于传统 CMOS 电路的硬件平台上部署，导致在特征提取过程面临严重的“存储墙”和“功耗墙”问题，如图 3-3所示。此外，由于控制器和 CAM的器件结构和外围电路不一致，难以将二者集成到同一芯片中，这限制了 MANN硬件部署的进一步扩展。

为了解决上述问题，我们采用软硬件协同优化技术，利用具有随机权重的回声状态图网络和二值权重的二值神经网络开发了记忆增强图神经网络模型（Memory-Augmented Graph Neural Network，MAGNN），利用阻变存储器的阻值分布随机性和高低阻态转变特性实现了图嵌入和相似度计算，构建了高能效的图小样本学习存内计算加速系统。

# 3.2 记忆增强图神经网络架构

记忆增强图神经网络 MAGNN 由三个部分构成，如图 3-4 所示：第一部分是回声状态图网络（Echo State Graph Neural Network，ESGNN）[147]，它作为控制器提取图数据特征；第二部分是二值神经网络（Binary Neural Network，BNN），它作为编码器将 32 位浮点精度的节点特征向量编码为二值特征向量；第三部分是关联存储器（Associative Memory，AM），它作为外部记忆用于节点特征向量的存储和检索。这三部分都在 40nm 256Kb 阻变存储器（ResistiveRandom Access Memory，RRAM）芯片上实现存内计算硬件部署。

基于阻变存储器的存内计算系统的延时与功耗评估参考标准阻变存内计算系统的基准测试方案[156-158]。40nm 256Kb RRAM 芯片由 RRAM 交叉阵列、线驱动器（Line driver，LD）、多路选择器（Multiplexer，MUX）和解码器（Decoder）组成。

# 3.4 随机电阻矩阵图嵌入

ESGNN 通过迭代的随机投影实现有效的图数据特征提取。ESGNN 具有随机且固定的权重，在元训练过程中无需通过反向传播进行优化，因此大大降低了训练成本。相反的，GNN 的图嵌入过程包含大量的迭代操作，并且模型中的32 比特浮点精度权重在训练过程中需要进行优化，这使得 GNN 的训练过程需要对高精度权重通过大量的迭代操作计算梯度，增加了计算成本，难以在边缘设备中实现高效部署。

# 第4章 全二值图卷积网络存内计算加速系统

上一章中，我们采用回声状态图网络作为控制器实现图嵌入。然而，回声状态图网络存在双重运算模式以及不规则访存模式，难以在边缘硬件平台上实现高效部署。本章中，我们提出了一种全二值图卷积网络存内计算加速系统。我们设计了全二值的图卷积网络算法模型，使用二值的聚合和组合操作实现高效的节点特征提取。我们利用基于阻变存储器的内容可寻址存储器阵列和矩阵向量乘阵列实现全二值图卷积网络的硬件加速。最后，我们在图分类和节点分类任务上验证了该加速系统的可行性与高效性。

# 4.1 引言

图卷积网络（Graph Convolutional Network，GCN）[42]能够有效地处理和分析图数据，实现高效的图表示学习，被广泛应用于推荐系统、社交网络、分子性质预测和交通流量预测等领域。GCN 主要包括两个执行阶段，即聚合阶段和组合阶段，聚合阶段可分为邻居检索（Neighbor searching）和特征合并（Feature merging）两个子阶段，如图4-1 所示。在邻居检索阶段，根据图数据中节点间的连接关系，通过检索操作获得每个节点的邻居节点。在特征合并阶段，为每个节点聚合来自邻居节点的特征。在组合阶段（Combination），每个节点的特征通过一层全连接层进行特征提取。聚合阶段和组合阶段交替执行，直至节点特征收敛。

随着物联网和云计算的快速发展，图数据的规模和复杂度迅速增加。基于传统 CMOS 电路的硬件系统部署 GCN 面临不规则访存和低能效计算的挑战，导致低存储带宽利用率和高访存延时。基于阻变存储器的存内计算范式已经被广泛研究来解决以上问题，然而，基于存内计算的 GCN硬件加速设计仍然面临许多挑战：

是在基于传统 CMOS 电路的 GPU 上实现的，不同节点的邻居节点的地址与特征是随机的，导致了不规则的访存模式。不同节点的邻居节点数量不同，邻居节点信息汇聚时运算负载不平衡，导致了不规则的运算模式。因此，回声状态图网络面临双重运算模式和不规则的访存模式，难以在边缘硬件平台上实现高效部署。

（3）器件的非理想特性：由于存内计算器件具有有限的电导状态、编程非线性和不对称性以及读干扰等非理想特性[166-170]，难以满足 GCN 对高精度计算的需求，严重影响了基于存内计算的 GCN 加速器的性能。

为了解决以上问题，我们采用软硬协同优化的方法设计了全二值图卷积网络存内计算加速系统，如图 4-1 所示。在算法上，我们提出了全二值图卷积网络模型（Binarized Graph Convolutional Network，BGCN），采用二值乘加操作代替原本的 32 位浮点运算，大大加快了 GCN 的运算速度，降低了存储成本，提高了鲁棒性。在硬件方面，我们采用基于阻变存储器（Resistive RandomAccess Memory，RRAM）的内存可寻址存储器（Content-Addressable Memory，CAM）和基于阻变存储器的矩阵向量乘（Multiply-and-Accumulation，MAC）阵列实现 BGCN 中二值的聚合阶段和组合阶段，大幅度降低模型的延时和功耗。

全二值图卷积网络（BGCN）采用二值的聚合阶段和组合阶段，图数据和模型权重通过 Sign()函数二值化为+1 或-1。BGCN 中前向传播的算法流程如图

然后，在二值聚合阶段（Binary aggregation phase），为节点??聚合来自邻居节点 $\eta _ { v }$ 的上下文信息，得到节点??聚合后的特征 $X _ { v }$ 。最后，通过 Sign()函数将其二值化，得到最终的二值节点特征 $a _ { v , k } ^ { b }$ 。

# 4.3 阻变存储器存内计算系统

基于阻变存储器（RRAM）的全二值图卷积网络存内计算加速系统包含检索 引 擎 （ search engine ）、 聚 合 引 擎 （ aggregation engine ） 和 组 合 引 擎（combination engine）三个部分，如图 4-1 所示。

检索引擎由基于 RRAM 的 CAM 阵列及其外围电路构成，负责图数据的遍历搜索。CAM 阵列的每一行存储边列表中目标节点的地址。因此，CAM 阵列的行数等于边列表中边的数量。通过计算查询节点的地址与 CAM 阵列中存储的节点地址之间的汉明距离，生成命中向量（hit vector）。命中向量的输出维度等于边列表中边的数量。命中向量中的每一个元素为“0”或“1”，其中“0”表示查询节点与存储的节点不同，“1”则表示二者相同。若结果为“1”，说明

该边对应的源节点为查询节点的邻居节点。

聚合引擎由基于 RRAM 的 MAC 阵列组成，负责聚合邻居节点的特征向量。MAC 阵列的一行存储边列表中源节点的特征向量。因此，该 MAC 阵列的输入维度等于边列表中边的数量，输出维度等于节点特征维度。根据检索引擎生成的命中向量激活邻居节点所在的行，得到聚合后的节点特征。

组合引擎由基于 RRAM 的 MAC 阵列组成，存储全连接层的二值权重，为聚合后的节点特征实现特征变换。

全二值图卷积网络在基于 RRAM阵列的存内计算系统上的计算流程如图 4-3 所示。首先，将图数据的边列表映射到基于 RRAM 的 CAM 阵列的检索引擎中，将二值权重矩阵映射到基于 RRAM 的 MAC 阵列的组合引擎中。然后，存储在属性 buffer（Attribute buffer）中的节点特征通过控制器（Controller）映射到基于 RRAM的 MAC阵列的聚合引擎中。在第 k个 BGCN层中，首先通过计算查询节点的地址与 CAM 阵列中存储的节点地址之间的汉明距离，生成命中向量（hit vector），并送入到聚合引擎中。然后聚合引擎根据命中向量激活邻居节点所在的行，得到聚合后的节点特征。最后，聚合后的节点特征送入到组合引擎中，实现特征变换。特征变换后的特征由控制器控制更新属性 buffer。采用相同的流程执行第 k+1 个 BGCN 层。

# 4.3.1 内容可寻址存储器检索引擎

在基于 RRAM 的全二值图卷积网络存内计算加速系统中，检索引擎由内容可寻址存储器（CAM）阵列构成，通过节点地址编码和汉明距离计算实现邻居节点检索，获得匹配“1”或不匹配“0”的二值检索结果。CAM 是一种特殊的

存储器结构，通过比较输入的查询向量与所有存储的数据，返回完全匹配的存储数据的地址，从而实现并行的存内检索操作[171-173]。如图 4-4（a）所示，由两个位于同一字线 WL的 1T1R单元构成一个 CAM单元，通过具有高低阻态的RRAM 器件 $\mathbf { M x }$ 和 $\mathbf { M } \mathrm { Y }$ 存储 1-bit 数据。当存储数据“1”时，MX器件处于低电导状态（Low Conductance State，LCS），电导值为 $G _ { L C S }$ 。MY器件处于高电导状态（High Conductance State，HCS），电导值为 $G _ { H C S }$ 。然后，输入的查询向量被编码为一对互补的电压序列，其中一条位线 BL施加高电压 $\mathrm { V } _ { \mathrm { s e a r c h } }$ ，另一条位线BLB 接地。

图数据处理任务中的应用潜力。通过整合模型量化与存内计算技术，本研究为图神经网络的硬件优化提供了一种创新途径，特别是在处理大规模图数据方面，有效应对了传统方法中遇到的存储和计算瓶颈。这部分工作发表在《AdvancedIntelligent Systems》期刊上。

# 第5章 图小样本类增学习存内计算加速系统

在上一章中，我们成功构建了全二值图卷积网络存内计算加速系统，有效缓解了图嵌入过程的不规则性。然而，由于图数据的结构不断演变，具有有限监督信息的新类不断添加到图数据中，已有的图小样本学习方法无法在动态变化的图数据下增量地学习新的类别。因此，本章提出了一种图小样本类增学习存内计算加速系统。该系统结合了基于知识蒸馏的元学习范式，利用基于阻变存储器的内容可寻址存储器阵列和矩阵向量乘阵列，加速图嵌入与相似度计算过程，实现了高能效的图小样本类增学习。我们在引文网络 Cora 数据集上验证了该加速系统的可行性与高效性。

# 5.1 引言

随着大数据时代的到来，图数据的结构日益复杂，新的节点类别不断涌现。这些新类由于缺乏足够的探索往往只包含有限的节点和边。理想的图神经网络（Graph Neural Networks，GNNs）需要准确地识别这些新出现的类别，同时能够记忆之前学习过的类别。这种图小样本类增学习问题在学术界和工业界都具有重要的研究意义。一种直观方法是在新加入的数据上微调 GNN 模型。然而，这种方法会导致严重的灾难性遗忘[132]和过拟合[81]问题，引起模型的性能下降。

如图5-1所示，在初始阶段（Base stage），图数据包含一组类别，这些类别具有大量的节点，记为 Task 1。利用当前的图数据对 GNN 模型进行训练。由于图数据集规模较大，GNN 具有良好的训练和测试性能。随着图的动态演变（Streaming session），包含少量节点和边的新类被不断添加到图结构中，记为Task 2和Task 3。当GNN模型在Task 2上进行训练时，模型的权重会被不断更新和覆盖，导致 GNN 模型在 Task 1 上的分类性能显著下降，发生灾难性遗忘。此外，该模型在 Task 2的训练性能良好，但无法泛化到 Task 2的测试数据上，导致其测试性能较差，出现过拟合现象。GNN模型在学习 Task 3时也反映了同样的问题。

第三章中，我们构建了图小样本学习存内计算加速系统实现了高效的图小样本学习，但该系统在解决图小样本类增学习问题时会面临以下挑战：

算模式，需要进一步结合上一章提出的全二值图卷积网络存内计算加速系统，实现图小样本类增学习端到端的硬件部署。

目前，研究人员提出了 Geometer[133]和 HAG-Meta[134]算法模型来尝试解决图小样本类增学习。但是这些模型采用 32 位浮点精度的图数据和模型权重实现节点的特征提取。这种高精度的数据将导致大量的存储资源消耗。此外，这些模型的硬件部署受冯·诺依曼架构限制，计算单元和存储单元之间存在频繁的数据搬运，导致大量的能量和时间开销。

为了解决上述问题，我们在第三章和第四章工作的基础上，构建了图小样本类增学习存内计算加速系统，并在基于阻变存储器的存内计算系统上实现了端到端的硬件部署与验证。

# 5.2 图小样本类增学习系统设计

如图 5-2 所示，图小样本类增学习存内计算加速系统由控制器（Controller）和外部记忆（Explicit Memory）两部分构成。其中，控制器利用全二值图卷积网络实现图嵌入，并采用基于阻变存储器（Resistive Random Access Memory，RRAM）的内存可寻址存储器（Content-Addressable Memory，CAM）阵列和基于阻变存储器的矩阵向量乘（Multiply-and-Accumulation，MAC）阵列实现加速运算。外部记忆由基于 RRAM 的 MAC 阵列构成，用于节点特征的存储和检索。控制器与外部记忆中的矩阵向量乘和激活函数 Sign()计算均在同一 RRAM 芯片

上执行，二者交互时避免了浮点数据的运算和存储，实现了图小样本类增学习系统端到端的硬件部署。我们进一步设计了基于知识蒸馏的元学习范式来优化控制器参数，缓解灾难性遗忘问题，并且利用基于 RRAM 阵列的存内计算范式降低延时和功耗。

# 5.2.2 图小样本类增学习硬件部署

我们在基于 RRAM 阵列的存内计算系统上实现了图小样本类增学习端到端的硬件部署，如图 5-3 所示。我们利用了第四章中开发的全二值图卷积网络模型作为控制器，在基于 RRAM 的 CAM 阵列和 MAC 阵列加速二值的聚合和组合阶段。其中，基于 RRAM 的 CAM 阵列作为检索引擎存储图数据的边列表，通过汉明距离计算实现邻居节点的检索，如图 4-5 所示。基于 RRAM 的 MAC阵列构成了聚合引擎和组合引擎，分别存储二值化的节点特征和模型权重，通过 MVM 操作实现节点的特征聚合和特征变换，如图 4-8 所示。外部记忆由基于 RRAM 的 MAC 阵列构成，存储来自支持集中的节点的特征向量，通过MVM 操作实现点积相似度计算，为查询集中的节点进行分类，如图 3-15 所示。

需要说明的是，控制器中的检索引擎与外部记忆都需要执行相似度计算，分别实现邻居节点的检索与查询集节点的类别预测。然而，这二者在硬件部署上存在较大差异。在控制器的检索引擎中，需要输入的待检索节点地址与存储在 CAM 阵列中的节点地址完全匹配，即查询向量与存储向量完全一致，才会在命中向量的对应位置生成“1”，否则生成“0”，如图 4-4 所示。因此，采用位于字线上的两个具有高低阻态的 1T1R单元构成一个 CAM单元，利用汉明距离实现相似度的计算。不同的是，外部记忆中存储来自支持集节点的特征向量。当查询节点到来时，会根据查询节点的特征向量与外部记忆中存储的特征向量

# 5.3.7 存内计算加速系统功耗与延时

我们评估了基于 RRAM 的 MAC 阵列与基于传统 CMOS 电路的 GPU 硬件平台的外部记忆中相似度计算延时，如图 5-10 所示。我们根据 RRAM 器件的读响应时间，计算了在 RRAM 阵列上的核心延时。由于在相似度计算中涉及大量的数据访问，基于冯·诺依曼架构的 GPU 面临严重的“存储墙”问题，无法实现快速的检索。基于 RRAM 的 MAC 阵列采用存内计算方式，避免了存储数据的搬移。因此，本文提出的图小样本类增学习存内计算加速系统相比 GPU 硬件平台在相似度计算延时上降低了约88倍的。

搬运，导致严重的“功耗墙”问题。基于 RRAM 的存内计算硬件平台能够原位实现数据的存储和计算，大幅度降低功耗。

本章聚焦于图小样本类增学习的研究。首先，我们分析了图神经网络在动态变化的图数据上面临的主要挑战，包括灾难性遗忘和过拟合问题。然后，我们设计并实现了图小样本类增学习存内计算加速系统。在算法层面，我们采用了基于知识蒸馏的元学习范式，以提高图小样本类增学习的效率。在硬件层面，我们利用基于 RRAM 的 CAM 阵列和 MAC 阵列，有效加速了节点特征提取与相似度计算，从而构建了一个高效的端到端图小样本类增学习系统。最后，我们在引文网络 Cora数据集上对该系统进行了验证。结果表明，在 5个增量会话环境下实现了约 88 倍的检索延迟降低和约 98 倍的推理核心功耗减低。研究结果不仅阐明了图小样本类增学习在动态环境下的应用潜力，而且通过实验验证了所提出系统的有效性和实用性。通过结合最新的存内计算技术和先进的元学习策略，本研究为解决图神经网络在动态图数据处理中遇到的挑战提供了一种创新的方法，为未来图数据处理技术的发展奠定了坚实的基础。本章工作正在准备投稿阶段。

# 第6章 总结与展望

# 6.1 总结

随着大数据时代的到来，越来越多的数据采用图结构进行表示。图数据通过节点和边有效描述了对象之间复杂的连接关系。近年来，深度学习技术快速发展，图神经网络因其强大的数据表征能力得到了广泛关注。然而，随着图数据的规模不断增加，图神经网络需要复杂的模型结构和高精度权重来处理动态变化的图数据，使其难以在计算和存储资源受限的边缘设备上高效运行。同时，当前基于 CMOS 电路的硬件系统通常采用传统的冯·诺依曼架构，在图处理任务中面临存储、算力和功耗上的限制。为了解决以上问题，基于阻变存储器的存内计算范式受到了广泛关注。该范式通过数据原位的存储和计算，加速了矩阵向量乘法操作，能够实现更高效的神经网络硬件部署。然而，基于存内计算范式的图数据处理的算法模型与硬件系统研究处于初级阶段，在有限样本，资源受限，类增的真实环境中仍面临关键挑战。本文围绕图数据的小样本学习、图神经网络加速以及图数据的小样本类增学习等关键技术问题开展深入研究，并取得如下成果：

# （1）图小样本学习存内计算加速系统。

针对边缘计算环境中存储和计算资源受限的挑战，本文采用软硬件协同优化方法，成功构建了一种高准确率、高鲁棒性、低功耗的图小样本学习存内计算加速系统。算法层面，该系统利用具有随机权重的回声状态图网络和二值权重的二值神经网络，开发了记忆增强图神经网络模型（MAGNN），在引文网络Cora 数据集的 2-way 3-shot 图小样本学习任务取得了 68%的准确率。硬件实现方面，利用阻变存储器的阻值分布随机性和高低阻态转变特性显著加速了图嵌入和点积相似度计算，实现了约 70倍检索延迟降低和约 250倍的更新延迟减少。同时，推理的核心功耗相比传统CMOS数字系统降低了约 60倍。

# （2）全二值图卷积网络存内计算加速系统。

针对边缘图卷积网络的高存储需求、不规则内存访问和器件非理想性等挑战，本文设计了一种全二值图卷积网络存内计算加速系统。该设计采用模型量化和存内计算范式，有效加速了图数据处理。算法层面，开发了全二值的图卷积网络算法模型，通过二值的聚合与组合操作，实现高效的图嵌入过程。在图分类和节点分类的基准数据集上，该模型达到了与 32 位浮点精度图卷积网络相近的准确率，同时降低了存储成本，提高了模型的运行速度和鲁棒性。硬件实现方面，采用基于阻变存储器的内容可寻址存储器（CAM）阵列和矩阵向量乘（MAC）阵列。此外，采用比较器作为阵列的读出电路，避免了高能耗数模转

换器的使用。并在 40 纳米工艺的存内计算芯片上进行硬件验证，显著降低了推理过程的核心功耗。

# （3）图小样本类增学习存内计算加速系统。

针对实际应用中图数据结构动态变化带来的灾难性遗忘和过拟合问题，本文开发了一种图小样本类增学习存内计算加速系统。算法层面，开发了基于知识蒸馏的元学习策略，在 5 个增量会话阶段成功实现了 1-way 5-shot 的图小样本类增学习，识别率较基线方法提升了 27.49%和 9.31%。硬件实现方面，采用基于阻变存储器的内容可寻址存储器（CAM）阵列和矩阵向量乘（MAC）阵列硬件部署了图嵌入过程和点积相似度计算。该加速系统相比传统 CMOS 数字系统实现了约88倍的检索延迟降低和约98倍的推理核心功耗降低。

# 6.2 论文的主要创新点

本文工作主要集中在面向边缘图数据处理的高能效存内计算技术，特别是在有限样本、资源受限和类增环境下图数据处理所面临的关键挑战：1）在有限样本条件下的图神经网络过拟合问题；2）在计算和存储资源受限的边缘环境下图神经网络加速面临存储需求、不规则内存访问和器件非理想性的问题；3）在类增环境下，图数据结构动态变化带来的灾难性遗忘和过拟合问题。针对这些问题，本论文从图小样本学习、图神经网络加速和图小样本类增学习三个方面进行了研究，主要创新成果如下：

# 6.3 展望

本文深入探讨了面向边缘图数据处理的高能效存内计算技术，尤其是在有限样本，资源受限，类别增加的真实环境中的应用。随着新应用、新设备和新任务的不断涌现，面向边缘图数据处理的算法模型与硬件架构仍然面临着新的

挑战，将来的研究需要在以下方面进行深入探索：

# （1）面向大规模图数据处理的研究

真实世界中的图数据往往包含数以百万计的节点和边，且具有多样的节点属性和复杂的连接结构。图神经网络为适应这些特征通常需要反复训练来调整超参数并构建最优模型结构，这不仅耗费大量的计算资源，也会增加时间成本。因此，如何利用存内计算高密度、高能效的特点实现大规模图数据的实时处理，是目前亟待解决的问题。

# （2）面向安全的边缘图数据处理系统研究

在数据爆发的大数据时代，物联网作为新一代信息技术的重要组成部分得到了快速发展。物联网所收集的海量数据，如不加保护，将面临隐私泄露风险。这些数据通常通过图结构进行有效分析与利用，如监控、调度、控制等功能。因此，设计既可以实时处理又能确保隐私安全的边缘图数据处理系统，将是重要的研究方向。

# （3）面型通用性的图数据处理架构研究

图数据处理应用已经渗透到各个领域，其作用与重要性日益凸显。面对持续涌现的不同类型的图数据，需要不断更新和适应的算法模型与硬件平台。目前的图数据处理架构难以同时满足对同构图与异构图、静态图与动态图等的实时分类与预测需求。因此，如何开发一种既高效的又能广泛支持不同应用需求的通用图数据处理系统，将是研究的热点问题。
