# Thermal Expansion-Engineered Ferroelectric Transistor Arrays for Scalable Edge AI Computing

Supporting Information

ABSTRACT: Conventional von Neumann architectures are fundamentally limited by the separation of memory and logic, leading to energy and latency bottlenecks in AI workloads. Here, we present a reconfigurable ferroelectric transistor platform based on a metal− ferroelectric−metal−insulator−semiconductor (MFMIS) structure capable of switching between volatile and nonvolatile modes via gate metal engineering. By selecting tungsten (W) or titanium nitride (TiN) as gate electrodes, we modulate interfacial strain and work function to tailor ferroelectric switching in a fixed $\mathrm { H f } _ { 0 \cdot s } \mathrm { Z r } _ { 0 \cdot s } \mathrm { O } _ { 2 }$ (HZO) layer. W-gated MFMIS-FeFETs exhibit a large memory window (∼11 V), >106 on/off ratio, 1012 endurance cycles, and excellent uniformity across 350 devices, with 22 programmable conductance states and robust synaptic behavior. Leveraging these characteristics, a hardware-aware VGG-8 convolutional neural network simulation for CIFAR-10 classification achieved 97.2% accuracy under realistic device nonidealities. Additionally, edge detection and feature extraction were experimentally realized in FeFET arrays via analog-domain convolution using differential

kernel encoding. These results validate in-memory multiply−accumulate operations, alleviating von Neumann bottlenecks while enhancing energy efficiency. This work establishes reconfigurable MFMIS-FeFET arrays as a scalable and low-power platform for neuromorphic and compute-in-memory architectures, enabling monolithic integration of memory and logic for intelligent edge systems and beyond-CMOS computing.

KEYWORDS: ferroelectric transistor, hafnium-zirconium oxide, nonvolatile memory, in-memory-computing, neuromorphic computing

The rapid expansion of artificial intelligence (AI) and Internet of Things technologies has intensified the demand for computing systems that offer both high throughput and energy efficiency.1 4 However, conventional von Neumann architectures�characterized by the physical separation of memory and logic�suffer from inherent limitations in latency and power consumption due to frequent data movement.5 In-memory computing (IMC) offers a promising alternative by enabling data processing directly within memory arrays via analog vector−matrix multiplication, governed by Ohm’s and Kirchhoff’s laws.6 Among emerging device technologies, ferroelectric field-effect transistors (FeFETs) based on doped hafnium oxide have garnered significant attention due to their nonvolatility, low-power operation, and compatibility with CMOS fabrication.7−9 The integration of amorphous oxide semiconductors further enhances their scalability, retention characteristics, and potential for monolithic 3D integration.10,11 Configured in arrays, FeFETs enable analog weight storage and tunable conductance states, supporting efficient synaptic operations and facilitating compute-in-memory architectures tailored for real-time, low-power AI processing at the edge.12,13

Ferroelectricity in HfO arises exclusively from its noncentrosymmetric orthorhombic phase $\left( \mathrm { P c a } 2 _ { 1 } \right)$ , which is

metastable relative to the monoclinic $\left( \mathrm { P } 2 _ { 1 } / \mathrm { c } \right)$ phase favored at ambient conditions and the tetragonal $\left( \mathrm { P } 4 _ { 2 } / \mathrm { n m c } \right)$ or cubic (Fm3̅m) phases stabilized at elevated temperatures.14,15 Stabilizing the orthorhombic phase in thin films has driven extensive research into strategies such as aliovalent or isovalent doping (e.g., Zr, Si, Al, Y, La), interface and surface energy engineering, and optimization of postdeposition anneal-$\mathrm { i n g . } ^ { \cup _ { 1 6 - 1 8 } }$ Extensive studies have aimed to enhance the ferroelectricity of $\mathrm { H f } _ { 0 . 5 } \mathrm { Z r } _ { 0 . 5 } \mathrm { O } _ { 2 }$ (HZO) films by stabilizing the orthorhombic phase through optimized capping layers and rapid thermal annealing (RTA) conditions.19 Metals with low thermal expansion coefficients, such as W and Mo (∼4.5 × 10−6 K−1 ),20,21 induce tensile stress during annealing, promoting orthorhombic phase formation.22−26 In metalferroelectric-metal (MFM) structures, the work function difference between asymmetric electrodes creates an internal electric field, leading to shifted and asymmetric P−E hysteresis

The electrical performance of ferroelectric transistors incorporating HZO is intimately linked to the crystallographic phase of the HZO layer, which may exist in monoclinic (m), tetragonal (t), or orthorhombic (o) forms depending on fabrication conditions and interface engineering.36−38 Only the noncentrosymmetric orthorhombic phase exhibits true ferroelectricity, enabling reversible polarization switching critical for nonvolatile memory and synaptic weight modulation.39 In contrast, the monoclinic phase is paraelectric, while the tetragonal phase may contribute to dielectric or antiferroelectric-like behavior depending on stabilization conditions.40,41 Achieving robust ferroelectric functionality in ultrathin HZO gate stacks thus requires precise control over phase composition and stabilization.42 This can be accomplished through dopant selection, thermal treatment, and electrode-induced stress engineering.4 3−45 Mastery over phase evolution is essential for optimizing key device metrics� including memory window, analog conductance linearity, and switching energy�positioning HZO-based FeFETs as scalable building blocks for IMC46,47 and neuromorphic systems.48

In this work, we present a reconfigurable ferroelectric transistor platform that supports dynamic switching between volatile and nonvolatile modes through gate electrode modulation, while maintaining a fixed ferroelectric stack based on HZO. To enable scalable integration of ferroelectric transistor arrays, we implement a lattice engineering strategy based on coefficient of thermal expansion mismatch, where tensile or compressive stress is introduced during rapid thermal annealing via metal capping layers with distinct expansion

coefficients (Figure 1a). This stress-driven lattice modulation stabilizes the ferroelectric o-phase in HZO films without altering the chemical composition, allowing precise phase control across the wafer. The resulting MFMIS-based architecture supports monolithic integration and enables inmemory computing functionality in a nonvon Neumann format (Figure 1b,c). By leveraging interfacial strain and gate work function engineering using TiN and W electrodes, the platform achieves tunable polarization characteristics and mode-specific electrical behavior. Devices with W gates demonstrate robust nonvolatile switching, exhibiting a large memory window (∼11 V), on/off ratios exceeding 106 , endurance over $1 0 ^ { 1 \dot { 2 } }$ cycles, and high array-level uniformity. Furthermore, analog programmability is realized through symmetric multilevel conductance modulation, stable longterm potentiation and depression, and low write nonlinearity. These device-level features enable accurate, hardware-aware inference in a VGG-8 convolutional neural network for CIFAR-10 classification, achieving 97.2% accuracy. We also demonstrate in situ analog convolution operations, including edge detection and feature filtering, using differential weight mapping within the FeFET array. These results highlight the potential of reconfigurable MFMIS-FeFET arrays as a unified platform for energy-efficient in-memory computing and adaptive neuromorphic hardware.

The coefficient of expansion in thermal stress for different metal electrodes can provide different crystal structures of HZO as shown in Figure 2a−c. To examine the impact of electrode configuration on the crystal structure of HZO thin films, high-resolution transmission electron microscopy (HR-

TEM) and fast Fourier transform (FFT) analyses were performed for three different capacitor structures, as shown in Figure 2a−c. As-deposited HZO films grown by ALD exhibit amorphous characteristics,49,50 as confirmed by the cross-sectional STEM image and FFT patterns shown in Supporting Information, Figure S1. Correspondingly, no hysteresis loop is observed in the P−E measurement, indicating the absence of ferroelectric behavior. When annealing is performed without metal electrodes, the lack of a capping effect allows the HZO film to expand and contract freely, resulting in the formation of nonferroelectric monoclinic and tetragonal phases. In contrast, ferroelectricity in HZO arises only from the orthorhombic phase, which requires constrained thermal expansion during crystallization. Thus, the presence of suitable electrode materials is essential to induce the necessary strain and stabilize the orthorhombic ferroelectric phase. The TiN/HZO/TiN structure in Figure 2a exhibits disordered lattice fringes and diffuse diffraction patterns in the FFT, indicating that the HZO layer is predominantly in the t phase. This is attributed to the relatively small thermal expansion mismatch between TiN $( 9 . 3 5 \times \mathrm { \dot { ~ } } 1 0 ^ { - 6 } \mathrm { K ^ { - 1 } } )$ and HZO $\left( 1 1 { - } 1 3 \times 1 0 ^ { - 6 } \mathrm { K ^ { - 1 } } \right)$ ), resulting in minimal tensile stress during the RTA process. In Figure 2b, the W/HZO/TiN structure, where the bottom electrode is replaced with W $( 4 . 5 \times 1 0 ^ { - 6 } ~ \mathrm { K ^ { - 1 } } )$ , shows partially aligned lattice fringes and the appearance of distinct FFT spots. This suggests partial stabilization of the o phase due to increased tensile stress at the HZO/electrode interface, although structural disorder and grain boundaries are still present. In contrast, Figure 2c reveals that the W/HZO/W structure exhibits highly ordered lattice fringes and sharp, symmetric diffraction spots in the FFT pattern, indicating significantly improved crystallinity and uniform o-phase formation throughout the film. This enhancement is attributed to the symmetric application of W electrodes on both sides of the HZO layer, which generates strong and uniform in-plane tensile stress during annealing, unlike the low or asymmetric stress environments in the other two configurations.

The unpoled regions are the same contrast as positively poled regions, indicating that HZO exhibits spontaneous polarization. Local PFM switching spectroscopy also confirms that phase hysteresis and amplitude as shown in Figure 2l. The asymmetric amplitude observed in the PFM measurements originates from genuine ferroelectric polarization switching within the HZO layer, rather than from charge injection artifacts. A clear ±180° phase reversal is observed, providing direct evidence of ferroelectric hysteresis; if the signal were caused by charge injection or electrostatic effects, the phase change would appear continuous or incomplete.51−54 The slight amplitude asymmetry is likely attributed to localized charge traps at the electrode−HZO interface, possibly induced by interfacial oxidation, but this effect is secondary compared to the intrinsic ferroelectric switching process. Therefore, the PFM results in Figure 2j−l confirm that the observed signal arises from true ferroelectric polarization switching, rather than from charge injection-related artifacts.

the integration of a ferroelectric HZO layer within the MFMIS stack. Cross-sectional energy-dispersive X-ray spectroscopy (EDS) mapping further confirms the spatial distribution of each constituent element across the device layers, validating the integrity and uniformity of the multilayer structure (Supporting Information, Figure S4a,b). Systematic modulation of transfer characteristics is achieved by engineering the gate electrode material, enabling reconfigurable operation modes without altering the ferroelectric stack composition (Supporting Information, Figure S5a−e). P−V hysteresis measurements reveal that devices with a W gate electrode exhibit pronounced nonvolatile switching with a wide memory window, whereas those with TiN display volatile characteristics and negligible retention. The W/HZO/TiN structure exhibited seminonvolatile behavior with a ∼5 V memory window. However, insufficient polarization retention at 0 V caused rapid current decay and asymmetric transfer characteristics. These results are newly presented in Supporting Information, Figure S6. Notably, these contrasting behaviors are realized using the same HZO-based MFMIS structure, underscoring the critical role of interfacial strain and work function in defining the ferroelectric switching mode. The Wgated MFMIS-FeFETs exhibit a memory window of approximately 11 V and an on/off current ratio exceeding $1 { \dot { 0 } } ^ { \hat { 6 } }$ at a drain bias of 0.1 V (Figure 3d), demonstrating their suitability for nonvolatile memory applications. However, the W/HZO/W capacitor, consisting of a simple MFM structure, applies the full voltage directly across the HZO layer, resulting in stable polarization at a relatively low coercive voltage (∼2 $\mathrm { V } ) . ^ { 5 5 - 5 7 }$ In contrast, the FeFET structure includes additional HfO2 (9 nm) and IGZO (15 nm) layers on top of the HZO, causing the applied gate voltage to divide across multiple layers. This voltage drop reduces the effective field on the HZO, requiring a higher external voltage (∼6 V) to achieve full polarization, as shown in Figure 3a,b. In contrast, TiN-gated devices show collapse of the memory window near 0 V gate bias, confirming their volatile response (Supporting Information, Figure S5c, e). Based on this behavior, W-gated devices were selected for further characterization and neuromorphic demonstrations. Device-to-device variation was assessed across a 350-device array, showing excellent uniformity in switching voltage and memory window (Figure 3e). Incremental programming with write voltages ranging from 0 to 5 V (0.2 V step) enabled up to 22 discrete conductance states at a fixed read bias $\left( V _ { g } = 0 \mathrm { { \bar { V } } } , V _ { \mathrm { { d s } } } = 0 . 1 \mathrm { { V } } \right)$ , demonstrating fine analog programmability (Figure 3f). When the voltage is swept back from 0 V to −5 V, the residual dipoles induce an internal bias field, causing an asymmetric switching pathway and nonreversible conductance transitions. While the conductance states can be linearly and stably modulated during the forward voltage sweep, identical values cannot be precisely reproduced during the reverse sweep. Nonetheless, periodic application of negative pulses can effectively neutralize residual polarization, improving reversibility. As shown in the additional multistate retention data (Supporting Information, Figure S7b), the device demonstrates reversible and controllable conductance switching, confirming that polarization itself is reversible but follows an asymmetric pathway that inherently limits conductance symmetry. Endurance tests under 80 ns pulse conditions confirmed reliable switching over $1 0 ^ { 1 2 }$ program/ erase cycles with an on/off ratio of ${ \sim } 1 0 ^ { \breve { 6 } }$ (Figure 3g). Synaptic functionality was further evaluated using voltage pulse trains applied to the gate terminal. To evaluate synaptic plasticity, a

pulse sequence was applied to induce long-term potentiation (LTP) and depression (LTD) in the MFMIS-FeFET device. This cycling protocol enables gradual and repeatable modulation of channel conductance, mimicking biological synaptic behavior (Supporting Information Figure S8). The resulting conductance modulation exhibited stable LTP and LTD behaviors, with nonlinearity (NL) factors of $\mathrm { N L } _ { \mathrm { L T P } } =$ 0.065 and $\mathrm { N L } _ { \mathrm { L T D } } = 0 . 3 5 2$ . The conductance parameters were $G _ { \mathrm { m a x } } = 1 0 3 8 \mu \mathrm { S } , G _ { \mathrm { m i n } } = 6 . 4 8 \mu \mathrm { S } ,$ and a $G _ { \mathrm { m a x } } / G _ { \mathrm { m i n } }$ ratio of 160.2, each measured over 100 pulses for both potentiation and depression (Figure 3h). The asymmetry ratio was 0.44, indicating that conductance modulation during LTP occurred slightly more gradually than during Ltd. Cycle-to-cycle variation analyzed over 20 consecutive cycles showed a variation of 5.255% (Supporting Information, Figure S9). Benchmarking against previously reported ferroelectric synaptic transistors reveals that the MFMIS-FeFET achieves superior performance in terms of on/off ratio and normalized memory window (Figure 3i) (The details are listed in Table S2). Importantly, the device maintained robust analog switching over more than 10,000 LTP/LTD cycles, confirming exceptional endurance and plasticity (Figure 3j). These results establish MFMIS-FeFETs as reconfigurable and highly programmable ferroelectric transistors capable of stable analog memory behavior. Their combination of high endurance, fine conductance resolution, and minimal variability offers a promising route toward energy-efficient, compute-in-memory systems for scalable neuromorphic applications.

To assess the feasibility of implementing convolutional neural networks (CNNs) in hardware, we simulated a VGG-8 network for CIFAR-10 image classification using experimentally extracted characteristics of ferroelectric synaptic transistor arrays as shown in OM image in Figure 4a. The VGG-8 architecture consisted of six convolutional layers with $3 \times 3$ kernel filters, interleaved with three max pooling layers, and two fully connected layers for classification (Figure 4b). Input images $( 3 2 \times 3 2 \times 3 )$ were processed into feature maps of increasing abstraction, from $3 2 \times 3 2 \times 1 2 8$ to $4 \times 4 \times 5 1 2 ,$ which were then flattened and passed to the dense layers. The network incorporated key nonidealities of ferroelectric transistors, including asymmetric and nonlinear weight updates, discrete conductance states, finite $G _ { \mathrm { m a x } } / G _ { \mathrm { m i n } } ,$ and both cycle-to-cycle and device-to-device variability. Simulation of the synaptic array, based on a MFMIS-FeFET configuration, achieved an inference accuracy of 97.2% (128 training epochs) (Figure 4c,d). These findings underscore the viability of ferroelectric transistor arrays for CNN inference in neuromorphic systems. Moreover, by enabling in-memory analog computation via vector-matrix multiplication, such arrays offer a scalable pathway toward energy-efficient, compute-inmemory architectures�an essential requirement for nextgeneration edge AI and embedded intelligence platforms. Trade-off between model sparsity and energy efficiency, highlighting the potential of MFMIS-FeFET arrays for lowpower AI hardware (Figure 4e).

In convolutional operations, each pixel intensity�corresponding to the local brightness in an input image�is multiplied by the associated kernel weight, and the resulting products are accumulated to generate the output feature map (Figure 4f). This process inherently requires multiply andaccumulate (MAC) operations, which can be efficiently mapped onto synaptic transistor arrays using analog voltage and current domains. In our implementation, input pixel

intensities were encoded as voltages, while kernel weights were mapped to the conductance states of ferroelectric synaptic transistors based on a MFMIS-FeFET architecture. Ohm’s law governs the multiplication via current generation through conductance-weighted synapses, while Kirchhoff’s current law enables accumulation along the bit lines, collectively enabling analog vector-matrix multiplication (VMM). To evaluate the suitability of MFMIS-FeFET arrays for convolution operations, we implemented edge-detection kernels on a 6 × 6-pixel input image using $3 ~ \times ~ 3$ convolutional filters. Since differential encoding is required to represent both positive and negative weights, each kernel was mapped onto two adjacent columns of a $9 \times 2$ synaptic array. The conductance states of devices in the first and second columns were modulated to represent the positive and negative components of the kernel weights, respectively. Precise analog programmability of synaptic conductance is thus critical to faithfully realizing kernel weights, underscoring the importance of continuous and symmetric weight modulation in FeFET-based synapses. Four distinct image-processing filters�vertical edge, horizontal edge, sharpen, and embossed�were implemented by column-wise programming of the FeFET array (Figure 4g). The ability to modulate conductance values with high fidelity enabled accurate realization of these filters, highlighting the capability of ferroelectric transistor arrays to perform analogdomain convolution for feature extraction. These results establish the feasibility of edge-aware image processing using ferroelectric synaptic devices and further support their potential as a hardware substrate for energy-efficient, compute-in-memory convolutional operations in neuromorphic vision systems.

# Conclusions

In summary, we demonstrate a reconfigurable MFMIS-FeFET architecture that enables dynamic switching between volatile and nonvolatile modes via gate metal selection, without altering the ferroelectric stack. By leveraging thermal expansion-induced lattice engineering, we stabilize the ophase in HZO films, achieving high-performance ferroelectric switching with a wide memory window, excellent endurance, and fine analog programmability. These characteristics support both classification and analog-domain convolution tasks, validated through hardware-aware CNN simulations and experimental edge detection. The demonstrated integration of reconfigurability, analog synaptic behavior, and compute-inmemory functionality establishes ferroelectric transistors as a scalable platform for energy-efficient neuromorphic computing and edge AI systems.

# METHODS

# MFMIS-FeFET Array Fabrications

The MFMIS-FeFET arrays were fabricated on p-type Si substrates with a 300 nm thermally grown SiO2 layer. Prior to film deposition, the substrates were sequentially cleaned using ultrasonic agitation in acetone, ethanol, and isopropyl alcohol for 5 min each, followed by deionized water (DI) rinse and drying with $\Nu _ { 2 }$ gas. A remote $\mathrm { O } _ { 2 }$ plasma ashing step (100 W, 5 min) was conducted to remove residual organic contaminants and improve film adhesion. The back-gate electrode was defined by photolithography using a positive photoresist (AZ 5214E), followed by RF sputtering of 50 nm W or TiN under 3 mTorr Ar pressure, and lift-off in acetone. Subsequently, an 8 nm ferroelectric HZO layer was deposited by ALD at 200 $^ { \circ } \mathrm { C }$ using alternating cycles of tetrakis(dimethylmethylamido)hafnium (TDMA-Hf) and tetrakis(dimethylamido)zirconium (TDMA-Zr) with $\mathrm { H } _ { 2 } \mathrm { O }$ as

the oxygen precursor. The cycle ratio of Hf:Zr was maintained at 1:1 to ensure stoichiometric control of the HZO composition. A second photolithography step was used to define the middle metal electrodes, followed by RF sputtering of 35 nm W or TiN and lift-off to complete the top electrode of the MFM structure. To crystallize the HZO into the ferroelectric orthorhombic phase, the W/HZO/W, TiN/HZO/ TiN, and W/HZO/TiN capacitor stacks were subjected to RTA at 400 °C for 30s under a pure Ar atmosphere. An additional 9 nm HfO insulating layer was deposited via ALD at 200 °C to electrically isolate the MFM capacitor from the channel layer. For the semiconductor channel, a 15 nm IGZO film was deposited by RF magnetron sputtering at room temperature. The IGZO film was patterned via photolithography and lift-off to form the active channel regions directly above the MFM capacitor. Source and drain electrodes were defined using photolithography, followed by electron beam evaporation of a bilayer 5 nm Cr/95 nm Au stack and lift-off. The completed MFMIS FeFET devices were finally annealed at 350 °C for 1 h in ambient air to activate the sputtered IGZO and improve interfacial contact between the semiconductor and dielectric layers.

# Atomic-Resolution Structural Analysis

The atomic structure and elemental analyses of the neuromorphic devices were conducted using HR STEM (JEM ARM 200F) and EDS mapping with an accelerating voltage of 200 kV. To investigate the cross-section of MFM structure, FIB (Helios 5 UX, Thermo Fisher) is Ga + liquid metal ion source with 2.5 nm at 30 kV beam were utilized to fabricate thin-film specimen preparation.

# Piezoresponse Force Microscopy

PFM measurements were carried out using a commercial atomic force microscope (NX-10, Park Systems, Republic of Korea) to investigate the ferroelectric domain structure and polarization switching behavior of the fabricated devices. An ElectriMulti75-G conductive cantilever (tip radius: 25 nm; length: 225 μm; width: 28 μm; height: 17 μm; nominal spring constant: 3.3 N/m; resonance frequency: 60.8 kHz) was employed to ensure high spatial resolution and stable electromechanical response. To facilitate vertical charge injection, a silver paste electrode was selectively applied to the edge of the sample, providing robust electrical contact with the bottom electrode. Both domain imaging and local switching spectroscopy were conducted by applying an AC voltage of 5 V at the contact resonance frequency of the cantilever. The PFM response was captured via lock-in detection of the amplitude and phase signals, enabling quantitative analysis of ferroelectric switching and domain evolution under bias.

# MFMIS-FeFET Electrical Characterizations

Polarization−electric field (P−E) hysteresis and polarization-voltage (P−V) measurements were performed on metal−ferroelectric−metal (MFM) capacitors with a radius of 100 μm using a Precision Multiferroic II Ferroelectric Analyzer (Radiant Technologies). P−V measurements and P−E hysteresis loops were performed on identically sized capacitors using a bipolar triangular voltage waveform.

The voltage was linearly swept from 0 V to +5 V (+VMAX), then to −5 V (−VMAX), and finally returned to 0 V, resulting in a total period of 2 ms, corresponding to a 1 kHz measurement frequency. The voltage pulses were applied to the bottom electrode, while the induced current was measured from the top electrode to minimize parasitic capacitance effects. The measured current was integrated to obtain the transient charge, which was normalized by the capacitor area to calculate the polarization. This method enables reliable extraction of the full ± 2Pr polarization associated with saturated domain switching. Current density-electric field (J−E) characteristics were extracted by numerically differentiating the polarization with respect to time, and the electric field was calculated by dividing the applied voltage by the thickness of the ferroelectric layer. Electrical measurements of fabricated devices, including I−V characteristics, were conducted using a Keithley 4200 semiconductor parameter analyzer in conjunction with the 4225-PMU ultrafast current−voltage module. To ensure a fair and reliable comparison with the FeFET endurance test, the endurance characteristics of the same W/HZO/W

ferroelectric capacitor were evaluated using a B1500A Semiconductor Parameter Analyzer (Keysight Technologies) under identical pulse conditions of ±5 V with an 80 ns pulse width. The measurements were conducted at room temperature in air.

# Ferroelectric Synaptic Device Based Convolutional Neural Network

To evaluate the system-level applicability of ferroelectric transistors in neuromorphic computing, we performed hardware-aware simulations of a VGG-8 CNN for CIFAR-10 image classification. The VGG-8 architecture consisted of six convolutional layers using 3 × 3 kernels, three interleaved max pooling layers, and two fully connected layers. Input images were processed into a hierarchy of feature maps and flattened into dense layers for final classification. The synaptic weights were modeled using experimentally extracted characteristics of MFMIS-based FeFET arrays, including asymmetric and $\mathrm { N L } _ { \mathrm { L T P } } /$ ${ \mathrm { N L } } _ { \mathrm { L T D } } ,$ discrete conductance levels, finite $G _ { \mathrm { m a x } } / G _ { \mathrm { m i n } }$ ratio, and measured device-to-device and cycle-to-cycle variability. The network was trained using stochastic gradient descent over 32 epochs, with conductance updates constrained to match real device behavior. Simulation accuracy was benchmarked using 10,000 test images from the CIFAR-10 data set. To demonstrate analog-domain MAC operations in hardware, we implemented image convolution using a 9 × 2 synaptic FeFET array. Input pixel values from a 6 × 6 grayscale image were encoded as analog voltages and applied across rows of the array. Kernel weights were programmed into synaptic transistors as discrete conductance states, with differential encoding used to represent both positive and negative values. Each 3 × 3 kernel was mapped to two adjacent columns: one for the positive and one for the negative components. Output currents were collected along columns to realize MAC operations, governed by Ohm’s and Kirchhoff’s laws. Edge-aware convolution filters�vertical edge, horizontal edge, sharpen, and embossed�were evaluated by programming the corresponding kernel conductance patterns into the FeFET array. Synaptic devices were programmed using pulse trains calibrated from experimental LTP/LTD characteristics to match the target weight profiles. Resulting output feature maps were compared against ideal digital convolutions for validation of analog accuracy.
