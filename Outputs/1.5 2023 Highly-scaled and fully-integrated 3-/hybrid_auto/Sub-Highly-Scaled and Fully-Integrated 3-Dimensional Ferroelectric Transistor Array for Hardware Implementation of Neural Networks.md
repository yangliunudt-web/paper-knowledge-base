Supplementary Figure 1. Fabrication process of the 3D ferroelectric NAND (FeNAND). After the deposition of TiN WLs and $\mathrm { S i O } _ { 2 }$ layers, the etching process was done to form trench structures. Then, the $\mathrm { H f Z r O _ { x } }$ gate insulator, Mo SL/BL, and $\mathrm { { I n Z n O _ { x } } }$ channel were deposited. Finally, annealing was done to induce ferroelectricity in the $\mathrm { H f Z r O _ { x } }$ layer. 3D FeNAND is composed of three vertically stacked WLs.
