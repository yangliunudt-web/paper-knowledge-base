# Organic Ferroelectric-Based 1T1T Random Access Memory Cell Employing a Common Dielectric Layer Overcoming the Half-Selection Problem

Qiang Zhao, Hanlin Wang, Zhenjie Ni, Jie Liu, Yonggang Zhen, Xiaotao Zhang, Lang Jiang,* Rongjin Li, Huanli Dong, and Wenping Hu*

Organic electronics based on poly(vinylidenefluoride/trifluoroethylene) (P(VDF-TrFE)) dielectric is facing great challenges in flexible circuits. As one indispensable part of integrated circuits, there is an urgent demand for low-cost and easy-fabrication nonvolatile memory devices. A breakthrough is made on a novel ferroelectric random access memory cell (1T1T FeRAM cell) consisting of one selection transistor and one ferroelectric memory transistor in order to overcome the half-selection problem. Unlike complicated manufacturing using multiple dielectrics, this system simplifies 1T1T FeRAM cell fabrication using one common dielectric. To achieve this goal, a strategy for semiconductor/insulator (S/I) interface modulation is put forward and applied to nonhysteretic selection transistors with high performances for driving or addressing purposes. As a result, high hole mobility of 3.81 cm2 V−1 s−1 (average) for 2,6-diphenylanthracene (DPA) and electron mobility of 0.124 cm2 V−1 s−1 (average) for N,N′-1H,1Hperfluorobutyl dicyanoperylenecarboxydiimide (PDI-FCN ) are obtained in selection transistors. In this work, we demonstrate this technology’s potential for organic ferroelectric-based pixelated memory module fabrication.

Memory units can be classified into capacitor-type or transistor-type (nonvolatile), and transistor-type device senjoyssignificant advantages of nondestructive readout, no refresh operation, less crosstalk within adjacent memory cells and less polarization disturbance. However, ferroelectric RAM (FeRAM) of conventional transistor-type memory module sufsfers frm the so-called half-selection problem (see Figure S1 and Figure S2 for more details), leaving adjacent memory transistors slightly programmed during the writing operation of a target memory transistor. To solve this problem, a selection transistor needs to be integrated with the ferroelectric field-effect transistor (FeFET) to form a 1T1T FeRAM cell.[25] An extra layer of non-ferroelectric gate dielectric for the selection transistor is needed in addition to the FeFET’s ferroelectric gate dielectric, thereby requiring external wiring or secondary dielectric engineering during device fabrication.[30,31] In order to simplify the manufacturing process, here we propose a novel strategy featuring a common dielectric for both selection and ferroelectric transistors. Unlike a simple interfacial passivation strategy,[26,34] an isolation layer of polystyrene (PS) electret, sandwiched between the semiconductor and ferroelectric layers, is applied to reduce hysteresis behavior and enhance the selection OFET’s carrier mobility. Our method possesses

several advantages: i) simplified 1T1T FeRAM cell fabrication; ii) higher pixel density per unit area due to a compact structure; iii) high operational stability due to crosstalk and polarization disturbance reduction. Sharing one common dielectric, a 1T1T FeRAM cell is integrated by a parallel stack of a bottomgate selection transistor and a top-gate ferroelectric memory transistor. As a result, complicated manufacturing methods for organic FeRAM are not necessary, and only one type of dielectric layer can be employed in this FeRAM cell. To achieve this, a strategy featuring interface modulation of the OFET is applied to the selection transistor, which proves to be effective for both p-type and n-type high performance OFETs. These efforts present a universal protocol for organic memory circuit simplification.

A FeFET can be converted into a non-ferroelectric OFET simply by an isolation layer of a PS electret between the semiconductor layer and the ferroelectric dielectric. This technology facilitates the fabrication of 1T1T FeRAM cell without any sophisticated dielectric handling. The selection transistor adopts a bottom-gate/top-contact (BG/TC) configuration. OFETs of p-channel and n-channel are fabricated using 2,6-diphenylanthracene (DPA) and N,N′-1H,1H-perfluorobutyl dicyanoperylenecarboxydiimide (PDI-FCN2), respectively (see Supporting Information Figure S3 for molecular structure). DPA (highest occupied molecular orbitals or HOMO level of −5.6 eV with a band gap of 3.0 eV) showed mobility over 10 cm2 $\mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ on octadecyltrichlorosilane modified $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ deposited at $5 0 ~ ^ { \circ } \mathrm { C } ,$ , suggesting potential uses in circuit driving.[3,4] Due to a deep lying lowest unoccupied molecular orbitals (LUMO), PDI-FCN allows air-stable electron transport and exhibits the highest electron mobility of 0.53 $\mathrm { c m } ^ { 2 } \ \dot { \mathrm { V } } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ when deposited at $1 3 0 ~ ^ { \circ } \mathrm { C }$ on hexamethildisilazane modified $\mathrm { S i O } _ { 2 }$ substrate.[8] In our system, these two materials were thermally evaporated as OFET active layer and $\mathrm { P D I - F C N } _ { 2 }$ layer requires additional

annealing to achieve high crystallinity and device performance. Poly(vinylidenefluoride/trifluoroethylene) (P(VDF-TrFE)) with a VDF/TrFE ratio of 7:3 was chosen as the main dielectric layer. A 680-nm-thick P(VDF-TrFE) thin film is obtained via spincoating from its methyl ethyl ketone (butanone or MEK) solution (concentration of 65 mg L−1 ) on glass substrate followed by an annealing process at $1 3 5 ~ ^ { \circ } \mathrm { C }$ for 2 h. PS solution in toluene (8 mg L−1 ) is subsequently spin-coated on P(VDF-TrFE) to form the isolation layer due to the orthogonal rule requiring P(VDF-TrFE) insoluble against toluene. Unlike the selection OFET, a top-gate/bottom-contact (TG/BC) configuration is applied to the FeFET in this FeRAM cell, which effectively avoids performance degradation due to the relatively rough interface of P(VDF-TrFE).

Both DPA and PDI-FCN2 are evaporated on PS isolation layer with a thickness of 50 nm. Scanning electron microscopy (SEM) is used to study the surface morphology of PS (Figure 1b) and P(VDF-TrFE) (Figure 1c). Though P(VDF-TrFE) shows a relatively rough surface with rod-like crystalline grains with a size scale ranging from 20 to 40 nm, a subsequent spin-coated PS layer flattens these uneven regions to provide a smooth interface prior to DPA and $\mathrm { P D I - F C N } _ { 2 }$ deposition. As a result, the evaporated semiconductor thin films on P(VDF-TrFE)/ PS bilayer exhibit comparable crystallinity to that on silica, as can be inferred from their out-of-plane X-ray diffraction results shown in Figure S4. In Figure 1d, a cross-sectional SEM image of P(VDF-TrFE)/PS bilayer is obtained. After annealing at $1 1 0 ^ { \circ } \mathrm { C } ,$ PS retains a highly continuous and uniform coverage on P(VDF-TrFE), implying reliable isolation of semiconductor materials from P(VDF-TrFE). Moreover, thermal stability of this bilayer is investigated to evaluate its compatibility in a wide temperature range (see Supporting Information Figure S5).

Capacitors are fabricated to identify the dielectric characteristic of the P(VDF-TrFE)/PS bilayer (Figure 2a, inset). In order to mimic the actual condition in a selection transistor, bottom Al and top Au electrodes are deposited. Alternating current (AC) impedance spectroscopy is measured, demonstrating that the device functions as a typical thin film capacitor (Figure 2b). The phase degree data as a function of test frequency from 104 to 0.01 Hz maintains a relatively small range from 86° to 89°, which indicates good intactness and stability of this dielectric layer. The capacitance per unit area of this dielectric remains above 10 nF $\bar { \mathrm { c m } } ^ { - 2 }$ within the whole test frequency range (Figure 2 a). In general, OFET characterization can be considered as a quasi-static process. For instance, a typical transfer characteristic sweeping cycle is commonly performed

on a second scale (about 0.1 Hz). Hence, the corresponding capacitance characteristic for this bilayer dielectric should be 12 nF $\mathrm { c m } ^ { - 2 }$ (at 0.01 Hz) when it comes to the selection OFET mobility extraction. Similarly, capacitance versus voltage (C–V) measurement for this capacitor device shows almost the same capacitance characteristic in a voltage scanning range between −30 and 30 V (Figure 2c). However, the capacitance per unit area decays rapidly beyond 100 kHz, leading to a weak high frequency response performance. To verify the ferroelectricity of P(VDF-TrFE)/PS bilayer, the Al/P(VDF-TrFE)/Ps/Au configuration is applied to the capacitor and its displacement (D)–electric field (E) loop is shown in Figure 2d. Hysteretic polarization induced by cyclic electric field determines the presence of remanent polarized intensity (6.77 µC cm−2) and

its coercive field is estimated to be around 55 $\mathrm { M V ~ m ^ { - 1 } } .$ . Ferroelectric polarization plays a key role in memory FeFET where the two opposite remanent polarization-induced carrier density in the conducting channel show two diverse conditions at zero gate bias during a clockwise gate voltage sweeping. When a direct current (DC) scanning voltage bias is applied to this capacitor device, the switched I–V characteristic can be obtained as shown in Figure 2e. Two sharp current peaks appear at around ±60 V which suggests the presence of a discharge process, which is likely to be attributed to ferroelectric inversion occurring at the coercive field (about 55 MV m−1 for P(VDF-TrFE)). It is noteworthy that P(VDF-TrFE)/PS proves to be a robust dielectric for OFET without breaking down. To further confirm the P(VDF-TrFE)’s ferroelectricity, temperaturedependent X-ray diffraction pattern is investigated in Figure 2f. P(VDF-TrFE) film is annealed prior to sampling. At room temperature, two pronounced peaks at 19.8° are assigned to (110) and (200) ferroelectric β-phase diffraction, indicating a high degree of crystallinity. As temperature rises, the peak at 19.8° (β-phase) declines notably and almost disappears at $1 0 5 \ ^ { \circ } \mathrm { C } .$ . Instead, a high-intensity (001) mixed paraelectric phase diffraction peak appears at $1 8 ^ { \circ }$ and eventually vanishes due to melting at $1 4 5 ~ ^ { \circ } \mathrm { C }$ . Due to P(VDF-TrFE)’s Curie temperature at around

${ 9 0 } \ { ^ { \circ } } \mathrm { C } ,$ organic FeFET’s memory operation is well maintained at room temperature.

Selection OFETs based on this bilayer dielectric are fabricated via a solution-processed method and vacuum thermal deposition. These OFETs exhibit saturated output and transfer characteristics (Figure 3a–c). In Figure 3d, high hole mobility up to 3.81 $\mathrm { c m } ^ { \dot { 2 } } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ (average for DPA) and electron mobility of 0.124 cm2 V−1 s−1 (average for PDI-FCN2) were obtained. To be specific, the output characteristics of the n-type (Figure 3a) and p-type (Figure 3c) OFETs exhibited excellent performance with only slight contact resistance, which is attributed to a contact barrier between the gold electrode (work function is −4.7 eV in air) and the semiconductor (HOMO level of DPA is −5.6 eV, and LUMO level of PDI-FCN is −4.5 eV). Regarding their transfer characteristics as shown in Figure 3b, although P(VDF-TrFE) in these OFETs is highly poled with ferroelectricity, due to a PS isolation layer, both of these OFETs exhibit a quite limited hysteresis window within an operational gate voltage from 0 to ±30 V. In Figure 3b, the threshold voltage of DPA (p-type) OFETs stays at a high level of −23 V, providing sufficient room for noise margin. Due to its wide band gap, DPA shows an ultralow off-current (pA level at zero gate bias).

The highest hole mobility of $6 . 7 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ , together with an on/off ratio over 108, renders DPA a qualified selection transistor for 1T1T FeRAM cell addressing.

To account for the suppression of hysteresis behavior or ferroelectricity in our bilayered OFETs, we put forward an “offset” hypothesis. PS is found to be an electret for charge storage; however, electret-type memory OFETs exhibit an inverse direction in the transfer hysteresis loop upon programming

operations when compared to FeFETs.[32,35,36] To illustrate, a negative gate bias serves as programming for p-type FeFETs, however, erasing for electret ones. As a result, electret and ferroelectricity present opposite effects in our bilayered-dielectric OFETs, leading to a negligible hysteretic behavior. Taking advantage of this property, though with poled P(VDF-TrFE), we manage to fabricate common OFETs for selection or driving purposes.

Figure 4a displays the schematic structure of 1T1T FeRAM cell, in which one selection transistor and one ferroelectric memory transistor are integrated to form a memory unit with four wire access to the memory matrix. As mentioned above, TG/BC configuration is applied to the ferroelectric memory transistor (FeFET) and BG/TC is simultaneously applied to selection transistor, which is compatible with our memory cell employing one common dielectric. A copolymer with an alternating unit of diketopyrrolopyrrole (DPP) and naphthalene (Naph) (PDPP-Naph) served as the semiconductor layer of the ferroelectric memory transistor (molecular structure is shown in Figure S3 in the Supporting Information). Figure 4b shows a photograph of the as-fabricated FeRAM cell devices on a glass substrate. The ferroelectric memory transistor exhibits a typical FeFET hysteretic transfer behavior by a memory window of 20 V under a clockwise gate voltage sweeping, whereas the selection transistor exhibits non-hysteretic transfer characteristic as displayed in Figure 4c. In ferroelectric memory transistor, two resistance states with conductance change by two orders of magnitude at zero gate bias after clockwise gate voltage sweeping, can be differentiated as “0” state (high resistance state) and “1” state (low resistance state) respectively. Due to this memory window induced by ferroelectric, the ferroelectric memory transistor displays a good data storage performance. Compared with the ferroelectric memory transistor, the selection transistor with the same dielectric shows a negligible hysteretic transfer characteristic in the same gate voltage sweeping region, indicating two distinctive working mechanisms governing their transport characteristics. The memory retention behavior of the FeFET device, as displayed in Figure 4d, shows persistant memory performance with 1/0 (on/off) ratio more than 102 over a period of 1000 s. The Gaussian distribution of 1/0 ratio of 24 memory cells is shown in Figure 4e. The inset displays the mapping statistics of 1/0 ratio of these memory cells on the same substrate after being polarized for three times in advance. A narrow distribution of these devices’ memory performance with 1/0 ratio ranging from 200 to 500 is obtained. Positive and negative source–drain voltage biases are applied to investigate the transfer characteristic of the selection transistor in order to simulate the erasing and writing operation process of this FeRAM cell, as shown in Figure 4f. In detail, the depletion mode of selection transistor can be used for performing the erasing operation of FeFET via applying a positive source– drain bias. Figure 4g demonstrates the writing process of this memory cell. A short gate-line (GL) voltage pulse of −60 V is applied to turn on the selection transistor. Subsequently, the potential drop between select-line (SL) and source–drain-line (SDL) goes up to nearly −60 V to cause the ferroelectric polarization inversion, thus increasing the channel carrier density by several orders of magnitude (a “1” state can be obtained). Once under the reading process, the selection transistor maintains off by applying a zero GL bias. Figure 4h illustrates its corresponding erasing process where a short SL voltage pulse of +90 V makes the FeFET turn to high resistance state (a “0” state can be obtained).

Now, we want to understand how the PS isolation layer contributes to isolating the hysteretic transfer behavior in the selection transistor. Based on the I–V measurement in Figure 2e, the existence of two sharp discharging peaks suggest that the

P(VDF-TrFE) dielectric remains its ferroelectricity even though it is coated by the PS layer. We suppose that the induced polarization within a limited spatial scale upon the ferroelectric interface adjacent to semiconductor layer plays a key role in modulating the carrier transport process in FeFET. Besides the abovementioned effect of PS electret, a thin insertion layer of PS prevents direct contact between polarized CF dipole moment and semiconductor, thereby weakening ferroelectric modulation on channel transport characteristics to give a nonhysteretic OFET for selection purposes. It is well-known that a BG/TC configuration is not advantageous for high-performance OFETs using P(VDF-TrFE) as dielectric due to its large surface roughness and high surface polarization degree. As an alternative, a PS isolation layer addresses these ferroelectric interfacial problems and high carrier mobility can be achieved in selection transistors.

In conclusion, using PS as isolation layer, we have developed a novel ferroelectric RAM cell (1T1T FeRAM cell) employing one common dielectric. An effective interface modulation strategy for reducing the hysteretic characteristic of ferroelectric OFET is successfully carried out. As a result, these “passivated” transistors with the bilayer dielectric exhibit high performance and negligible hysteresis, making them suitable for selection purposes and simplifying 1T1T cell fabrication. This work has great potential in the field of organic memory technology based on ferroelectric in flexible organic circuits.

# Experimental Section

Materials: P(VDF-TrFE) powder (VDF/TrFE mole ratio of 7:3) was purchased from Piezotech Co., Ltd., France. PS powder was purchased from Sigma-Aldrich. Butanone (analytic reagent (AR)), toluene (AR), and dichlorobenzene (AR) were purchased from Beijing Chemical Co., China. PDPP-Naph copolymer was synthesized via Suzuki-coupling polymerization in the lab. DPA and PDI-FCN2 were synthesized in the lab. All of the chemicals were directly used without further purifications except semiconductor materials. Deionized water (18.2 MΩ cm−1 ) was made by a Milli-Q (Millipore) water purification system.

Capacitor Device Fabrication and Characterization: P(VDF-TrFE) powder was dissolved in butanone solvent at the concentrations of 80 and 65 mg mL−1 . PS powder was dissolved in toluene with the concentration of 8 mg mL−1 . The capacitor device for dielectric characteristic measurement was prepared as follows: The P(VDF-TrFE) solution (65 mg mL−1 ) was filtered with 0.45 µm polytetrafluoroethylene (PTFE) syringe filter before use. Then, the solution was spin-coated at 3000 rpm for 60 s on glass substrate with Al bottom electrode which was deposited through ULVAC vacuum thermal evaporation system. The unfinished capacitor device with P(VDF-TrFE) film was annealed at 135 °C for 2 h and then cooled to room temperature. The PS solution was spin-coated on P(VDF-TrFE) at 3900 rpm for 30 s to form a thin layer. A 20 -m -hick gold electrode was subsequently thermally evaporated on it. The capacitance characteristic was measured with Autolab Electrochemical Workstation and Keithley 4200-SCS analyzer. The capacitor device for D–E loop and switched I–V curve measurements was prepared in the same procedure as done with P(VDF-TrFE) solution (80 mg mL−1 ) being used. The D–E loop of P(VDF-TrFE)/PS film was characterized with Radiant Ferroelectric Material Tester Premier II-100 V in ambient atmosphere. Its switched I–V curves were measured with Keithley 4200-SCS analyzer.

Transistor and 1T1T FeRAM Cell Device Fabrication and Characterization: The bottom-gate electrode of the selection transistor and source–drain electrode of FeFET were deposited on the glass substrate. Then, the PDPP-Naph solution (dissolved in dichlorobenzene with concentration

of 5.5 mg mL−1 ) was filtered and spin-coated at 1000 rpm for 20 s on $\mathsf { O } _ { 2 }$ plasma treated Au/glass substrate. Then, P(VDF-TrFE) and PS solutions were spin-coated to form a dielectric layer and DPA (50 nm) was evaporated to form a semiconductor layer subsequently. Finally, the top Au gate (FeFET) and source–drain electrode (selection transistor) were deposited. All these devices were measured with a Keithley 4200-SCS analyzer.
